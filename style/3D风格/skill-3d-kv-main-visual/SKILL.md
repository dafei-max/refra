# 设计 KV 主视觉

把任务理解为“设计一个 KV 主视觉”，不要理解为“把 brief 中的名词逐项画出来”。先建立主体、陪体、环境、装饰之间的大小、方向、间隔、层级、遮挡和留白，再生成具体物体。

## 工作流程

1. 读取 brief 与参考图，区分内容信息和设计语法。
2. 判断任务是否为 3D。若是，读取 [references/3d-material-routing.md](references/3d-material-routing.md)，确定一个主材质和最多一个辅助材质；用户明确指定材质时直接锁定，不自动覆盖。
3. 需要从用户的风格库匹配参考图时，读取 [references/style-library-matching.md](references/style-library-matching.md)，形成检索条件并选择 1–3 张职责明确的参考图。
4. 提炼一条可执行的“关系骨架”：主焦点、主动作轴、最大体块、陪体嵌入位置、留白区。
5. 设计主体外轮廓和比例跳跃，再处理五官、服装与材质分配。
6. 让动物、商品或道具参与主体轮廓，不要并排陈列。
7. 把环境压缩为承托色块；装饰默认不加，确有构图职责时才保留。
8. 选择能放大动作关系的镜头；镜头服务于造型，不用鱼眼替代设计。
9. 组装生成提示词，调用图像生成工具直接出图；若用户只要提示词，则只交付提示词。
10. 对照自检清单判断是否仍然“普通”，只做单一、针对性的迭代。

需要详细比例、环境和配色规则时，读取 [references/design-rules.md](references/design-rules.md)。需要编写或改写生图提示词时，读取 [references/prompt-template.md](references/prompt-template.md)。

## 提炼参考图

把参考图拆成以下五层，不复制具体人物、服装、文字、品牌或装饰：

- **轮廓语法**：头身大小、肢体跨度、整体外形、局部裁切。
- **关系语法**：谁嵌入谁、谁遮挡谁、负空间由谁填补。
- **动作语法**：方向数量、伸展幅度、扭转、倾斜、重心。
- **空间语法**：前中后景体块、近大远小、留白位置。
- **色彩语法**：主色数量、面积占比、跳色焦点、背景纯净度。

不要把“3D、软陶、可爱、圆润、夸张比例”当成充分描述。这些泛化词会触发模型的普通大头 Q 版先验。必须明确说清楚放大什么、缩小什么、哪里连接、谁占据负空间。

## 先写关系骨架

在生成前，用一句内部设计判断明确：

> `<主体>` 通过 `<2–3 条方向轴>` 形成 `<整体轮廓>`；`<陪体>` 嵌入 `<负空间>` 并与主体互相遮挡；环境仅用 `<承托色块>` 平衡重心；`<区域>` 留白。

关系骨架必须回答：

- 谁是唯一主焦点，约占画面多少？
- 最大、次大、最小体块分别是什么？
- 动作至少向哪两个不同方向展开？
- 陪体若移走，主体轮廓是否明显变弱？若不会，关系还不够紧。
- 哪块空间必须保持干净，供标题或呼吸感使用？

## 造型人物和动物

优先使用非写实、软雕塑式体块：

- 避免标准 Q 版“大头、小身体、正常四肢”。
- 用小头或克制头部、短躯干、巨大或不对称肢体形成比例跳跃。
- 把手臂和腿设计为连续管状或块状体，弱化真实肩、肘、膝、腕、踝。
- 局部放大手掌、鞋、膝、道具等近端体块；不要平均夸张所有部位。
- 让身体表现为压、撑、顶、伸、扭、倾、陷，而不是端正摆拍。
- 动物同样抽象：先是色块、大小、方向和依附关系，其次才是品种与完整解剖。
- 保持识别性，但删除无助于轮廓和情绪的内部结构。

## 设计动作与镜头

- 让动作形成两到三条清晰且不同方向的轴线，例如“手臂上拉 + 腿部横展 + 支撑腿下落”。
- 让手脚或道具真正远离躯干，扩大整体轮廓；不要只写“抬手”“抬脚”。
- 使用不对称重心、肩髋高低差和互相遮挡制造张力。
- 需要强化近大远小时，选轻广角、低机位或斜俯视；避免默认正视中焦陈列。
- 不默认使用鱼眼。只有关系骨架需要强烈空间拉伸时才用轻鱼眼，并约束边缘畸变。
- 镜头不能补救平庸姿势；先设计姿势，再选镜头。

## 处理环境和装饰

环境只承担承托、平衡、分层与留白功能：

- 背景默认使用干净纯色或轻微柔和渐变。
- 将草地、树木、水面、人群、地平线、光影等概括为方向、密度、间隔、层级、运动和色彩关系。
- 不要求每个物体轮廓完整；允许合并、遮挡、裁切或只保留色块。
- 装饰默认数量为 0。只有当它能连接方向、平衡重量或建立焦点时，才加入 1–2 个节点。
- 不自动添加环绕曲线、轨迹线、星星、花朵、泡泡、粒子或漂浮小物。
- 若删除某装饰后构图仍成立，就删除它。

## 控制颜色与材质

- 使用 2–3 个主色建立大面积关系，最多加 1 个小面积跳色。
- 颜色干净、明亮、多巴胺，但避免每个对象各用一种高饱和色。
- 3D 任务必须记录 `primary_material`；未明确材质时按 brief 自动路由，不把“3D 卡通”默认等同于软陶。
- 主材质控制画面约 70%–100% 的视觉面积；只有功能上确有需要时才加入一个辅助材质，面积通常不超过 30%。
- 黏土是人物、动物、商品与混合场景的通用兜底；糖果软胶优先用于物品、商品、图标和抽象画面；其他材质按主题语义、形体精度与表面线索选择。
- 不把材质理解为表面贴图。针织方向、毛发长度、软胶高光和黏土手作痕迹必须随体块结构变化。
- 避免脏灰、复杂反光、过多纹理和强戏剧光抢走造型关系。

## 生成与迭代

调用图像生成工具时：

- 把每张参考图标注为“设计语法参考”“材质参考”“构图参考”或“编辑目标”，除非用户明确要求编辑原图，不得复制参考图的具体人物、商品、文字和品牌。
- 3D 任务先写明 `primary_material`、可选 `secondary_material` 和材质分配，再描述表面、光照与负向约束。
- 风格库可检索时，先按材质过滤，再按主体类型、构图和情绪排序；不要混用材质语法冲突的参考图。
- 先写场景/背景，再写主体和关系，再写造型、镜头、颜色、材质、约束。
- 明确禁止普通 Q 版、标准解剖、道具列队、完整场景和无职责装饰。
- 若用户给出的信息足够，直接生成，不重复确认。
- 首轮失败时，找出一个最大结构问题，例如“腿部跨度不足”或“陪体没有嵌入”，只针对该问题迭代；不要堆更多形容词。
- 精确局部编辑时，列出严格不变量，避免整图漂移。

## 自检

生成前后逐项检查：

- 画面是否只有一个明确主视觉，而不是多个完整物体并排？
- 缩成缩略图后，主体轮廓是否仍然独特、可读？
- 体块是否有“小—大—超大—小”的跳跃，而不是平均分配？
- 动作是否真正拉开，手脚是否远离躯干？
- 人物和陪体是否通过遮挡、接触或负空间互相依存？
- 环境是否可以再减？装饰是否都有明确构图职责？
- 颜色是否由少量大色块控制，而不是鲜艳颜色平均撒布？
- 3D 材质是否与主体类型、主题语义和所选参考图一致？主材质是否占绝对优势？
- 针织、毛绒、软胶或黏土是否真正影响了几何、边缘、光照，而不是只贴了一层纹理？
- 画面是否仍像“普通可爱角色换衣服”？若是，回到关系骨架和比例设计。

最终标准：**主体复杂，环境简单；关系明确，物体概括；轮廓可以舍弃，节奏不能舍弃；宁可比例有意失真，也不要安全普通。**
