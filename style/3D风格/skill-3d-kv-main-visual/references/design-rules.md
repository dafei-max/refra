# KV 关系与造型规则

## 优先级

按以下顺序做判断，低层级不得破坏高层级：

1. 主焦点及画布占比
2. 主体与陪体的咬合关系
3. 动作方向和外轮廓
4. 前后层级、遮挡和负空间
5. 环境承托与留白
6. 装饰节点
7. 五官、服装和局部细节

## 推荐占比

这些是起点，不是硬模板：

- 主体组合占画面约 60%–80%。
- 最大体块的视觉面积可达到头部的 1.5–3 倍。
- 前景手、脚或道具可达到头部的 1–2 倍，但只选择一个主要近端焦点。
- 环境承托集中在底部或一侧，不要包围主体。
- 至少保留约 20%–35% 的连续干净留白；有文字版式时按标题区调整。

## 比例节奏

不要平均放大。使用有停顿的比例序列，例如：

- 小头 → 中躯干 → 超大手臂 → 大裤腿 → 小陪体
- 小脸 → 大道具 → 超大前脚 → 收缩的背景色块
- 短躯干 → 粗管状手臂 → 巨大腿部 → 厚重鞋底

至少包含一次显著比例跳跃和一次收缩。若所有部位都一样圆、一样粗、一样可爱，结果仍会普通。

## 人物造型

- “丰满”解释为几何体块的饱满，不解释为写实肥胖。
- 删除肌肉、骨骼和关节信息，保留弯曲方向和支撑逻辑。
- 把服装当成大色块和轮廓工具。例如阔腿裤优先形成巨大连续体块，不优先表现褶皱。
- 五官只承担情绪和视线；不要让脸成为唯一设计来源。
- 发型概括为少量大体块，避免大量发丝。

## 动物与陪体

- 动物首先承担一个颜色、一个方向、一个大小和一个情绪关系。
- 用大头小身、短腿、合并躯干、夸张耳朵或鼻子等少量特征建立识别。
- 通过靠、抱、顶、钻、跨、夹、压等动词定义其与主体的关系。
- 优先放入人物肢体产生的负空间，或让道具穿插主体轮廓。
- 若动物和人物可各自单独裁出且不影响构图，说明仍是拼装式关系。

## 环境概括

把常见环境翻译为抽象关系：

| 原始内容 | 保留 | 舍弃 |
| --- | --- | --- |
| 草地 | 底部绿色承托、疏密起伏 | 每根草、完整草坪边界 |
| 树木 | 竖向节奏、深浅层级、团块密度 | 树干枝叶的完整轮廓 |
| 花朵 | 少量跳色节点、放射方向 | 花海和品种细节 |
| 水面 | 横向层次、冷色面积、轻微波动 | 真实岸线和每条水纹 |
| 人群 | 密度、朝向、色块节奏 | 每个完整人物 |
| 光影 | 明暗分区和焦点方向 | 写实光斑与复杂反射 |

## 镜头选择

| 目标 | 优先镜头 | 注意事项 |
| --- | --- | --- |
| 强气势、大开大合 | 低机位轻广角 | 放大一个近端肢体，不要全部畸变 |
| 图形化、俏皮构成 | 斜俯视轻广角 | 保持主体轮廓，不把人物压扁 |
| 关系咬合、稳态 KV | 轻微仰视或平视 | 靠姿态与比例出设计，不依赖镜头特效 |
| 极强冲击 | 斜构图、有限鱼眼 | 仅在需要时使用，保护脸和关键道具 |

## 常见失败与修正

| 失败 | 根因 | 结构性修正 |
| --- | --- | --- |
| 普通 Q 版 | 泛化的“可爱、圆润、夸张” | 指定小头/短躯干/巨大局部和关节弱化 |
| 动作没张力 | 手脚仍靠近躯干 | 拉远端点，形成两到三条不同方向轴线 |
| 人物与动物拼装 | 只描述“在旁边” | 把动物嵌进负空间并产生遮挡/接触 |
| 背景碎 | 每个名词都完整生成 | 合并为一到两块承托关系，删除对象轮廓 |
| 画面空 | 只做减法，没有结构 | 用主体占比、方向和负空间重建平衡 |
| 鱼眼仍普通 | 镜头替代了姿态设计 | 先做轮廓和比例，再限制性使用广角 |
| 多巴胺变杂乱 | 每个物体都抢色 | 2–3 个主色控制面积，只留一个跳色 |
| 装饰喧宾夺主 | 为“丰富”自动加元素 | 装饰默认 0，每个元素说明构图职责 |
