# KV 参考图不变项契约

有参考图时，先分析、再写契约、最后生成。不得一边生成一边临时猜测要参考什么。

## 1. 为每张图分配职责

最多选一张主版式参考，再按需增加一张字体关系参考、一张材质或配色参考。不要把多个冲突版式平均融合。

```text
Image 1: layout reference
Image 2: typography-relationship reference
Image 3: material or palette reference
```

一张图可以承担多个职责，但要逐项声明。若用户明确说“只参考构图”，不得迁移字形、颜色或材质。

## 2. 写 `reference_contract`

```text
reference_contract:
  locked:
    frame_topology: <上中下 / 左右 / 叠压 / 中心辐射>
    visual_weights: <标题 : 主视觉 : 行动信息>
    alignment_axis: <左 / 中 / 右，以及共享边线或基线>
    reading_path: <第一落点 -> 第二落点 -> 行动落点>
    anchors: <标题、主体、日期/Logo/CTA 的锚点>
    overlap_crop: <谁遮挡谁、哪些元素出血或裁切>
    negative_space: <必须保留的连续空白>
    type_relationship: <中英文、括号、标签、日期的关系>
    palette_relationship: <同色 / 相邻 / 互补及面积关系>
  replaceable:
    <主体、商品、具体文案、颜色值、背景内容、道具、装饰等>
  forbidden_to_copy:
    <参考图人物身份、商品结构、品牌、原文案、Logo、独特装饰>
```

`locked` 锁定设计语法，不锁定参考图内容；`replaceable` 必须真正替换，不能只换标题而保留原人物和商品。

## 3. 判断不变项

优先按以下顺序锁定：

1. 空间拓扑：上中下、左右分栏、叠压或环绕。
2. 视觉权重：主视觉 60、标题 30、行动 10，或参考图中的等价关系。
3. 对齐关系：左/中/右对齐，边线、基线、中心线和间距节奏。
4. 阅读路径：标题首先、主体其次、日期或 CTA 最后。
5. 穿插规则：标题是否压住背景、主体是否进入标题区、标签是否贴边。
6. 色彩关系与材质关系：迁移色彩逻辑和表面语法，不默认复制精确色值。

## 4. 横版参考的常见提炼

- 左标题 + 右主体：锁定左右咬合、标题轴和主体朝向；替换人物、商品、文字与具体背景色。
- 顶部大标题 + 下方主体：锁定顶部 30% 标题主权、中部 60% 视觉区和边角 10% 日期/CTA。
- 左文字块 + 右故事场景：锁定文字块面积、主体承托面和边角标签；不要复制场景对象。
- 中英文色块穿插：锁定共享边线、错位节奏、字体对比和括号附着方式；替换具体中英文内容。

## 5. 失败判断

- 只复制了颜色和材质，版式仍回到居中人物：构图不变项未写清。
- 文字内容换了，但仍复制参考品牌和角色：可变项没有真正替换。
- 多张参考互相打架：减少到一张主版式参考，并为其余参考限定单一职责。
- 写了“参考排版”但没有轴线、占比和锚点：描述不可执行，必须改成位置与关系。
