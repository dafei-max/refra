# 3D 材质自动路由

仅在任务要求 3D、C4D、三维卡通、潮玩、软雕塑或参考图明显为 3D 时读取。目标是根据 brief 自动选出一个主材质，并为风格库检索生成稳定的 `material_id`。

## 目录

- 决策输出
- 选择顺序与快速路由
- 适配矩阵
- 材质规则
- 混合材质规则

## 决策输出

在组装提示词前先形成内部记录：

```text
subject_type: character | animal | product | object | abstract | mixed
material_mode: explicit | reference-led | inferred
primary_material: <material_id>
secondary_material: <material_id 或 none>
material_reason: <一句可执行理由>
reference_query: <material_id + subject_type + 构图/情绪标签>
```

最终提示词必须包含主材质名称、几何影响、表面特征、光照方式和材质专属负向词。不要只写一个材质名。

## 选择顺序

1. 用户明确指定材质时直接锁定，除非用户要求推荐或纠正；不要擅自换材质。
2. 用户明确要求参考某图的材质时，以参考图的主视觉面积判断主材质，不被少量金属、纸张或塑料配件误导。
3. 用户未指定时，依次判断主体类型、主题语义、形体精度、表面线索和风格库覆盖。
4. 多种材质都可行时，优先选择能强化主体语义、轮廓与情绪的材质；仍无明显倾向时使用 `clay`。
5. 选择一个主材质。辅助材质最多一个，且必须承担识别、功能或对比职责；不要为了丰富而混材质。

## 快速路由

按顺序匹配最明确的线索：

1. 出现“针织、毛线、编织、针脚、织物包覆、布艺手作” → `knit-textile`
2. 出现“毛绒、长绒、蓬松、毛茸茸、玩偶、绒毛字形” → `plush-fur`
3. 出现“糖果、果冻、Y2K、光滑软胶、潮玩塑料、充气感、霓虹渐变”，且主体以商品、物品、图标或抽象体块为主 → `soft-vinyl-jelly`
4. 出现“搪胶玩具＋局部植绒、森林玩具、温暖收藏玩具、软塑与短绒混合” → `soft-vinyl-flocked`
5. 出现“手捏、橡皮泥、软陶、手工塑形”，或主体为人物/动物/商品混合且没有更明确材质倾向 → `clay`

不要只凭颜色选择材质。高饱和不必然是软胶，低饱和也不必然是黏土。

## 材质规则

### `clay` — 手捏软陶/橡皮泥

适合：人物、动物、商品、道具与混合场景；作为没有明确材质线索时的通用兜底。

提示词核心：

> 使用统一的手捏软陶或橡皮泥材质，体块圆润厚实，表面哑光柔软，保留轻微揉压、指腹和手工塑形的不规则痕迹；边缘圆钝，复杂结构被概括为连续块面，使用柔和棚拍光和干净软阴影。

避免：光滑注塑感、镜面高光、均匀程序噪点、写实皮肤、每个物体使用不同材质。

### `soft-vinyl-jelly` — 糖果软胶/搪胶果冻塑料

适合：商品、物品、设备、图标、抽象角色与多巴胺潮玩画面。人物和动物可用，但不作为无条件默认。

提示词核心：

> 使用光滑糖果软胶与搪胶玩具材质，圆润充气体块和大圆角，表面干净、半亮面、呈宽而柔和的高光；局部可使用乳白半透明果冻塑料，带轻微次表面散射、内部透光和糖果渐变。保持主体以不透明软塑为主，透明果冻只用于少量焦点。

避免：橡皮泥手捏痕迹、粉质哑光、所有物体完全透明、硬玻璃折射、尖锐工业边、镜面塑料。

### `soft-vinyl-flocked` — 搪胶软塑＋局部植绒

适合：IP、机器人、动物、玩具商品和温暖的收藏玩具场景。

提示词核心：

> 主体使用不透明搪胶软塑或缎面 ABS 玩具材质，表面平滑、圆角厚实；只在地面、树木、动物局部或承托体块加入细密短绒植绒，形成软塑与绒面之间的触感对比。控制植绒区域，不让毛绒覆盖全部主体。

避免：全画面统一毛绒、果冻式强透明、黏土指纹、随机混合多种绒毛长度、植绒覆盖精密标签。

### `plush-fur` — 毛绒玩偶/长短绒

适合：吉祥物、动物、Logo 字形、柔软商品和治愈主题。

提示词核心：

> 主焦点覆盖浓密柔软的人造毛绒，毛发沿体块表面自然生长并具有明确方向；焦点使用中长绒形成蓬松轮廓，辅助物体使用短绒、毛毡或细密植绒。接触处产生压陷、毛流变化和柔和阴影，轮廓略带自然毛躁感。

避免：塑料高光、表面贴噪点、毛发长度完全一致、湿漉结块毛发、所有物体统一长绒、细小文字和标签被毛发破坏。

### `knit-textile` — 针织布艺/织物包覆

适合：人物、动物、服装、民俗造型、手作物件和需要文化感的主题。

提示词核心：

> 使用针织织物包覆主体，呈现规律、连续且尺度统一的纱线线圈；针织方向沿体块曲面弯曲，在凸起处轻微拉伸、褶皱处压缩，保留织物厚度、接缝、包边和缝合逻辑。表面哑光柔软但轮廓清晰，不出现长绒毛。

避免：长毛绒、植绒毛躁边缘、橡皮泥纹理、针脚大小混乱、织物纹理像平面贴图、所有道具统一针织化。

## 混合材质规则

- 主材质决定整体视觉语法和参考图类别，必须占绝对优势。
- 辅助材质只用于现实功能或焦点对比，例如软胶设备上的少量金属镜头、毛绒画面中的塑料杯、针织角色的软胶皮肤。
- 使用 `soft-vinyl-flocked` 时已包含“软塑为主、短绒为辅”的固定关系，不再叠加第二套大面积材质。
- 不把服装颜色、背景颜色或光效误判为材质。
- 精密文字、Logo、条码和标签不要交给毛绒或针织表面承载；需要准确时保留为平滑可读区域或后期排版。
