# 版式概述

竖向 3:4 画幅，主标题横跨画面顶部，以两组或两行圆润粗手写字组成。顶部中间可放置一个小型标签式辅助信息。画面中部保留最大面积主视觉区域，底部左侧放置副标题或短句，右侧放置活动时间，形成双端锚点。顶部标题下方至底部之间的连续空白是主视觉核心区，不应被额外文字拆分。

# 文字视觉系统

## 主标题

- 位置：画面顶部，横跨接近整幅宽度。
- 区域坐标：[0.06, 0.05, 0.88, 0.22]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：8-15个中文字符，最多 18个中文字符。
- 字号与画布关系：单行字高约占画布高度的 9%-14%，两行总高约占 18%-22%，整体宽度约占画布宽度的 84%-88%。
- 字体类型：圆润粗手写体、亲和展示字、略带毛边的生活方式字体。
- 字形特征：笔画圆厚、转折柔和、字腔开阔，字形大小略有变化；括号和点状笔画可增强口语感，但不使用尖锐几何字。
- 排列方式：左右两组或上下两行拼接，主语义块较大，次语义块略小；整体保持横向延展。
- 对齐方式：以顶部中轴为基准，内部自由错位。
- 与其他信息的比例：主标题字号约为底部副标题的 3.0-4.0 倍，为活动时间的 3.2-4.2 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面左下角，一条生活方式短句。
- 区域坐标：[0.07, 0.90, 0.55, 0.06]
- 相对主标题字号：约为主标题字号的 22%-30%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐，字体使用较规整的手写体或圆体。
- 缺失规则：删除左下短句，底部保留留白；时间保持右下。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右下角，横向日期范围。
- 区域坐标：[0.76, 0.90, 0.19, 0.06]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 20%-28%。
- 与主标题的关系：与顶部标题分离，作为右下角锚点。
- 缺失规则：删除右下时间，主视觉向右下扩展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：标题上方或两组标题之间，以小标签、类别或短说明出现。
- 区域坐标：[0.49, 0.05, 0.22, 0.07]
- 建议行数：1 行，最多 2 行。
- 相对主标题字号：约为主标题字号的 16%-22%。
- 对齐关系：居中，可使用圆角底形；仅承载用户明确提供内容。
- 缺失规则：删除标签及底形，不保留空框。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：标签底形、括号和点状符号用于亲和感，不自动生成城市名、搭子或生活口号。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部的大面积连续区域。
- 区域坐标：[0.05, 0.30, 0.90, 0.55]
- 区域形状：完整纵向矩形，从顶部标题下方延伸到底部信息上方。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.58] 附近。
- 建议主体占比：单人或双人占画布面积的 32%-48%；城市生活场景占 40%-58%。
- 与文字的避让关系：主体不得进入 y=0.27 以上标题区，底部 y=0.87 以下避让副标题和时间。
- 可否延伸至文字背后：环境光影、天空或统一背景可延伸至文字背后；人物面部不得进入标题区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部横向手绘主标题。
2. 第二视觉：中部主视觉主体。
3. 第三视觉：底部左侧副标题与右侧时间。
4. 主视觉主体与文字的观看关系：文字先建立主题，中部主体承载主要故事，底部信息完成收束。

# 内容适配规则

## 主标题长度变化

- 短标题：4-7 个字时可使用一行或左右两块放大。
- 中等标题：8-15 个字时两行或两组拼接，为最优状态。
- 长标题：16-18 个字时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简，禁止向下侵入主视觉。

## 信息缺失

- 无副标题时：主视觉向左下扩展。
- 无活动时间时：主视觉向右下扩展。
- 无辅助信息时：删除顶部标签，不补文案。
- 只有主标题时：主标题可置于 [0.05, 0.06, 0.90, 0.24]，略放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：城市生活、社交搭子、旅行、咖啡、海边、日常记录。
- 不适合：高端奢华、科技硬核、密集信息或正式政务。
- 推荐主题：生活美学、城市、相遇、日常、海边、社交。
- 推荐信息量：低至中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物、朋友互动、城市街景、咖啡、海边、生活方式产品。
