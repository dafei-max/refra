# 版式概述

竖向画幅，整体采用“上部信息区 + 下部主视觉区”的二段式结构。文字组集中在画面上半部，主标题位于左上至中上区域，占据最强视觉权重；次级信息分散在主标题下方与右侧，通过左右分栏形成不对称平衡。下半部为大面积连续可生成区域，是明确的主视觉画面区，不是普通留白。阅读顺序从左上主标题开始，随后转向左下副标题，再跳读右侧时间与辅助信息，最后落入下半部主视觉区域。

活跃文字组（主标题、副标题、活动时间）的整体水平中心应接近画布中心，不得整组向左或向右漂移。主标题和活动时间共用右边界对齐轴，副标题则与主标题左边界对齐。

# 文字视觉系统

## 主标题

- 位置：画面上半部偏左，贴近左侧安全边界，顶部留有明显呼吸空间。
- 区域坐标：`[0.10, 0.14, 0.77, 0.11]`
- 信息层级：最高层级，整张版式的主导信息。
- 建议行数：1 行优先，最多 2 行。
- 建议字数：4-10 字，最多不超过 14 字。
- 字号与画布关系：字高约占整张画布高度的 10%-14%，标题整体宽度可覆盖画布宽度的 55%-70%。
- 字体类型：无衬线黑体系统，偏几何结构。
- 字形特征：高字重、粗笔画、字面大、转角利落、横竖对比弱、整体紧凑但不拥挤。
- 排列方式：横向排布，单行优先；如换行为人工控制的均衡断行，不应形成过碎节奏。
- 对齐方式：标题内部左对齐；主标题整体右边界固定在画布宽度约 87% 处，与右下方活动时间的右边界共用同一条垂直对齐轴。
- 与其他信息的比例：显著大于副标题、时间、辅助信息；副标题与时间约为主标题字号的 25%-40%。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：是
- 位置：主标题左下方，独立成组，不与右侧时间区共用对齐轴。
- 区域坐标：`[0.10, 0.27, 0.31, 0.07]`
- 相对主标题字号：约为主标题的 22%-30%。
- 建议行数：0-2 行，单行或双行短信息均可。
- 对齐关系：左对齐，并与主标题左边界基本对齐或轻微内缩。
- 缺失规则：删除该模块后，主标题与下方主视觉区之间留白保持不变；不自动上移右侧时间模块补位。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：是
- 位置：主标题右下侧，位于上半部右中区域，承担右侧视觉支点。
- 区域坐标：`[0.61, 0.28, 0.26, 0.06]`
- 排列方向：横向单行优先，可包含数字与分隔符。
- 相对主标题字号：约为主标题的 30%-38%。
- 与主标题的关系：作为右侧次主信息，其右边界必须与主标题右边界对齐，共用画布宽度约 87% 处的垂直对齐轴，允许偏差不超过画布宽度的 2%。
- 缺失规则：删除后，右侧辅助信息可单独保留在原位；不建议让主标题横向扩张去填满右侧空位。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：是
- 位置：时间信息右侧或其邻近区域，形成右侧补充说明块。
- 区域坐标：`[0.86, 0.28, 0.10, 0.11]`
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题的 18%-24%。
- 对齐关系：左对齐或紧凑分行；与时间模块组合后形成右侧信息列。
- 缺失规则：删除后仅保留时间模块，不需要额外添加占位信息。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：仅用于顶部边缘的小体量标识与版式平衡，不参与主信息传达。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面下半部的大面积连续区域，为唯一主视觉区。
- 区域坐标：`[0.00, 0.34, 1.00, 0.66]`
- 区域形状：横向展开的整块矩形区域。
- 建议主体位置：主体应布置在下半部中部、偏下中或下中偏左/偏右，不可侵入上半部文字安全区。
- 建议主体占比：主体视觉实体建议占画布面积的 30%-50%，占主视觉区面积的 45%-70%。
- 与文字的避让关系：主体、人物、产品、道具、强对比光源和高密度纹理均需避开上半部文字组及其周边缓冲区。
- 可否延伸至文字背后：不建议。即使允许背景渐变或低对比纹理延伸，也不得影响文字识别。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：左上大字号主标题。
2. 第二视觉：主标题下方的副标题信息。
3. 第三视觉：右侧时间与辅助信息模块。
4. 主视觉主体与文字的观看关系：先读文字，再进入下半部主视觉；主视觉作为承接信息后的视觉落点，不能反向压过主标题。

# 内容适配规则

## 主标题长度变化

- 短标题：保持单行，优先放大字号，维持左上强势占位。
- 中等标题：保持单行优先，必要时微缩字距或字号，但不改变左对齐关系。
- 长标题：允许分成 2 行，第二行宽度不宜明显短于第一行，避免头重脚轻。
- 超出容量时：优先压缩字号，其次控制为两行；仍超出则需要用户精简文案，禁止挤占右侧时间区或下压覆盖主视觉区。

## 信息缺失

- 无副标题时：保留主标题下方留白，增强极简感；右侧时间与辅助信息维持原有位置。
- 无活动时间时：右侧可仅保留辅助信息，整体仍保持右轻左重的结构，不建议将其移到左侧。
- 无辅助信息时：时间模块单独成立，作为右侧唯一支点。
- 只有主标题时：主标题保留左上区域，其他文字模块全部删除，下半部主视觉区完整保留，形成“强标题 + 大画面”结构。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：发布会海报、展会 KV、品牌活动预告、论坛峰会、主题宣传主画面。
- 不适合：信息密集型长文案海报、商品详情页、多卖点卡片、强表格型版面。
- 推荐主题：高端活动、科技感传播、品牌发布、趋势论坛、概念主题海报。
- 推荐信息量：1 个主标题 + 1 组副标题 + 1 组时间信息 + 0-1 组辅助信息。
- 推荐主体类型：单一主体、大体块产品、人物半身或群像、抽象装置、场景化主视觉。
