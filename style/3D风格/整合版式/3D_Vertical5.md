# 版式概述

竖向 3:4 画幅，上半部保持大面积连续主视觉区域；文字组集中在画面下半部。主标题由两行高对比中文衬线字与一条英文短语混排，形成偏右的标题块。日期和时段位于标题左侧，小型外文或辅助短语位于日期上方或标题左侧。底部居中放置一条副标题。整体阅读顺序从上方主视觉下落到标题，再向左读取时间，最后看底部短句。

# 文字视觉系统

## 主标题

- 位置：画面下半部偏右，主标题中心位于 y=0.66 左右。
- 区域坐标：[0.25, 0.50, 0.62, 0.32]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-11个中文字符，最多 14个中文字符。
- 字号与画布关系：最大中文单字字高约占画布高度的 14%-20%，两行总高约占 27%-32%，标题宽度约占画布宽度的 58%-62%。
- 字体类型：高对比现代宋体、时尚杂志衬线体、窄长中文展示字。
- 字形特征：竖画修长、撇捺外伸、粗细对比明显；可与中性无衬线或高对比英文衬线体混排，整体不使用粗糙手绘感。
- 排列方式：两行错位，第一行较短并偏上，第二行向右下延展；英文可横向嵌入两行之间。
- 对齐方式：整体偏右，内部采用左对齐与视觉居中结合。
- 与其他信息的比例：主标题字号约为底部副标题的 3.0-4.0 倍，为日期的 2.8-3.6 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面底部居中，位于标题组下方。
- 区域坐标：[0.23, 0.85, 0.56, 0.07]
- 相对主标题字号：约为主标题字号的 20%-28%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：居中对齐，使用规整无衬线或细黑体。
- 缺失规则：删除底部短句，标题组可整体下移约 0.02。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：主标题左侧，以日期和时段形成小型信息块。
- 区域坐标：[0.14, 0.64, 0.17, 0.12]
- 排列方向：左侧大日期，右侧或下方为上下两行时段。
- 相对主标题字号：日期约为主标题字号的 30%-40%，时段约为 16%-22%。
- 与主标题的关系：与主标题并列，作为左侧平衡点。
- 缺失规则：删除时间块，主标题可向左扩展约画布宽度 0.05。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：时间上方或标题左侧，用于一至两行英文、翻译或理念短语。
- 区域坐标：[0.13, 0.72, 0.20, 0.11]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 22%-32%。
- 对齐关系：左对齐，字体可使用高对比斜体或衬线体。
- 缺失规则：删除小型英文，时间和主标题保持原有关系。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：下划线、圆环或延伸笔画可用于加强编辑感，不自动生成英文理念。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面上半部的大面积连续区域。
- 区域坐标：[0.05, 0.05, 0.90, 0.42]
- 区域形状：完整纵向矩形，从顶部延伸至文字组上缘。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.28] 附近。
- 建议主体占比：单人或产品占画布面积的 28%-44%；场景或多人组合占 36%-54%。
- 与文字的避让关系：主体核心不得下压至 y=0.48 以下；文字组上方至少保留画布高度 0.03 的缓冲。
- 可否延伸至文字背后：柔和渐变、光晕或背景纹理可延伸至文字后方，但高对比主体不得进入。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：上半部主视觉主体。
2. 第二视觉：下半部偏右的主标题。
3. 第三视觉：标题左侧时间和底部副标题。
4. 主视觉主体与文字的观看关系：主视觉先吸引视线，再落到下方标题，形成由画面到信息的编辑式阅读。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可使用一至两行并放大。
- 中等标题：6-11 个字时两行错位，为最优状态。
- 长标题：12-14 个字时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简，禁止向上侵入主视觉核心。

## 信息缺失

- 无副标题时：标题组略下移。
- 无活动时间时：主标题向左扩展，保留整体居中。
- 无辅助信息时：删除小型英文，不自动补理念。
- 只有主标题时：主标题可置于 [0.17, 0.57, 0.70, 0.31]，整体居中放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：生活方式、松弛主题、运动恢复、女性力量、时尚专题。
- 不适合：密集促销、儿童卡通、复杂数据或流程。
- 推荐主题：放松、力量、自由、自洽、平衡、轻运动。
- 推荐信息量：中低信息量，核心模块 3-4 组。
- 推荐主体类型：人物、瑜伽、服饰、家居、香氛或柔和场景。
