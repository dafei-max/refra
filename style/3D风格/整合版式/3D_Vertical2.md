# 版式概述

竖向 3:4 画幅，文字组集中在上半部。中文主标题使用大尺度细线书写字分两行铺开，长收笔、圆环和弧线共同形成标题外轮廓；一条英文或短副标题叠置在标题右下侧，辅助短句位于标题下方偏左。活动时间独立放置在右下角，上下两层排列。主要主视觉位于下半部左侧至中部，右下角必须避让时间模块；上半部标题内部的空隙仅是字形留白，不是主体区域。

# 文字视觉系统

## 主标题

- 位置：画面顶部偏左，横跨上半部约三分之二宽度。
- 区域坐标：[0.10, 0.05, 0.64, 0.42]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-10个中文字符，最多 12个中文字符。
- 字号与画布关系：最大单字字高约占画布高度的 15%-21%，两行总高约占 34%-42%，标题宽度不超过画布宽度的 64%。
- 字体类型：现代行书、细线书写体、时尚签名字体或高挑手写展示字。
- 字形特征：笔画偏细，粗细变化克制，长横、弯钩、圆环和收笔可明显外伸；字面修长、留白充足，允许局部连写，但核心字形必须清晰。
- 排列方式：两行自由错位，上行略靠左，下行向右延伸；长笔画可包围英文副标题，但不得遮挡。
- 对齐方式：以左侧起笔位置为锚，内部采用自由居中和错位，不使用严格齐边。
- 与其他信息的比例：主标题字号约为英文副标题的 1.8-2.4 倍，为辅助短句的 3.0-4.2 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题右下方，嵌入书写笔势形成的空隙。
- 区域坐标：[0.48, 0.28, 0.39, 0.16]
- 相对主标题字号：约为主标题字号的 42%-58%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：沿轻微上扬或水平基线排列，可使用高对比衬线体、细罗马体或连笔斜体，与中文形成字体反差。
- 缺失规则：删除英文或短副标题及其专属下划线，中文标题下行可向右补位约画布宽度 0.04。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右下角，靠近右侧与底部安全边距。
- 区域坐标：[0.62, 0.84, 0.33, 0.12]
- 排列方向：上下两层；上层为日期或主时间，下层为星期、时段或补充时间。
- 相对主标题字号：主日期约为主标题字号的 30%-42%，下层信息约为 18%-26%。
- 与主标题的关系：与顶部标题分离，作为右下角稳定锚点。
- 缺失规则：删除整个右下时间组，主视觉可向右下扩展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题下方偏左，以一条短句、活动类型或计划名称出现。
- 区域坐标：[0.12, 0.46, 0.36, 0.07]
- 建议行数：优先 1 行，最多 2 行。
- 相对主标题字号：约为主标题字号的 18%-26%。
- 对齐关系：左对齐，字距可略疏，保持轻盈和呼吸感。
- 缺失规则：删除该行，主视觉上边界可上移约 0.03；不自动生成计划名或口号。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：长曲线、圆环、纸飞机或小型图形用于延续书写动势，不承担文字信息；英文式装饰只在用户明确提供时启用。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面下半部左侧至中部的大面积连续区域。
- 区域坐标：[0.05, 0.52, 0.56, 0.42]
- 区域形状：下方偏左的近矩形区域，可向中部延伸；右下角因时间模块形成局部避让。
- 建议主体位置：主体视觉中心建议位于 [0.32, 0.72] 附近。
- 建议主体占比：单人或产品占画布面积的 28%-43%；场景或多人组合占 36%-52%。
- 与文字的避让关系：主体核心不得进入 y=0.50 以上的标题区域；右下角 [0.60, 0.81, 0.37, 0.17] 必须留给时间。
- 可否延伸至文字背后：允许低对比天空、渐变、柔光或统一纹理延伸至文字背后；人物面部和产品核心不得进入。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：上半部细线中文主标题。
2. 第二视觉：标题右下的英文或短副标题。
3. 第三视觉：标题下方辅助信息与右下活动时间。
4. 主视觉主体与文字的观看关系：先读顶部文字，再向下进入主视觉，最后落到右下时间；主体应位于标题下方并避免与长笔画冲突。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可分为 1-2 行并放大，保留长收笔。
- 中等标题：6-10 个字时采用两行自由错位，为最优状态。
- 长标题：11-12 个字时使用 3 行，缩小字号 8%-12%，减少外伸笔画。
- 超出容量时：优先精简；禁止压缩字宽或侵入右下时间区。

## 信息缺失

- 无副标题时：中文标题下行向右补位，保持上半部重心。
- 无活动时间时：主视觉向右下扩展，底部不保留空时间框。
- 无辅助信息时：删除标题下方短句，主视觉上移。
- 只有主标题时：主标题可置于 [0.10, 0.12, 0.72, 0.43]，整体放大约 5%-8%。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：夏日活动、见面会、生活方式、轻户外、社交活动。
- 不适合：密集促销、复杂流程、严肃政务或长篇正文。
- 推荐主题：夏季、清新、相遇、出行、社交、轻浪漫。
- 推荐信息量：低至中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物、双人互动、夏日产品、户外场景、花草或轻盈静物。
