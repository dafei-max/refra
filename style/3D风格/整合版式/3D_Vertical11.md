# 版式概述

竖向 3:4 画幅，顶部使用一行超大、细长、结构化的中文标题，几乎横跨整幅画面。标题下方设置一条细分隔线，分隔线下方左侧为活动时间，右侧为副标题或主题说明。画面中下部保留大面积连续主视觉区域，适合人物、穿搭、产品或趋势场景。分隔线只承担结构划分，不是额外文字。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中，横跨约 86% 画布宽度。
- 区域坐标：[0.07, 0.08, 0.86, 0.23]
- 信息层级：一级核心信息。
- 建议行数：优先 1 行，最多 2 行。
- 建议字数：4-8个中文字符，最多 10个中文字符。
- 字号与画布关系：单行字高约占画布高度的 17%-23%，标题宽度约占画布宽度的 82%-86%。
- 字体类型：细长异形宋体、结构化展示字、具有现代书写骨架的时尚标题字体。
- 字形特征：字身高挑、横画细长、竖画和弧线具有明显伸展，局部结构可压缩或重组；笔画保持纤细，不使用厚重黑体。
- 排列方式：优先单行横排；较长内容可拆为两行，但第二行不得只剩单字。
- 对齐方式：整体居中，对齐画面水平中轴。
- 与其他信息的比例：主标题字号约为副标题的 3.0-4.0 倍，为时间主数字的 3.2-4.2 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：分隔线下方右侧，单行主题说明。
- 区域坐标：[0.45, 0.34, 0.45, 0.06]
- 相对主标题字号：约为主标题字号的 23%-31%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：右对齐或左对齐均可，但整体靠右；使用细黑体或现代无衬线体。
- 缺失规则：删除右侧说明，时间可向右扩展至宽度 0.40，或保持左侧独立。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：分隔线下方左侧，以标签和日期组成小型信息块。
- 区域坐标：[0.07, 0.32, 0.27, 0.08]
- 排列方向：上下两层；上层为小型标签，下层为日期范围。
- 相对主标题字号：日期约为主标题字号的 24%-32%，标签约为 14%-20%。
- 与主标题的关系：与主标题共用左侧视觉边界，通过分隔线形成层级。
- 缺失规则：删除左侧时间块，副标题可向左扩展；分隔线可缩短或保留。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：不支持。
- 位置：不设置固定辅助信息区。
- 区域坐标：无。
- 建议行数：0 行。
- 相对主标题字号：不适用。
- 对齐关系：不适用。
- 缺失规则：默认删除，不使用外文、品牌或标签填补。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：分隔线用于建立编辑式层级；不得自动生成标签名或英文。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中下部的大面积连续区域。
- 区域坐标：[0.05, 0.42, 0.90, 0.53]
- 区域形状：完整纵向矩形，从信息带下方延伸至底边。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.68] 附近。
- 建议主体占比：单人或产品占画布面积的 32%-48%；场景或多人组合占 40%-58%。
- 与文字的避让关系：主体不得进入 y=0.40 以上文字和分隔线区域。
- 可否延伸至文字背后：低对比背景、材质或渐变可延伸至标题背后；主体核心不得进入。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部超大单行主标题。
2. 第二视觉：分隔线下方右侧副标题。
3. 第三视觉：左侧活动时间。
4. 主视觉主体与文字的观看关系：顶部信息读取完成后向下进入主视觉，形成清晰的上文下图结构。

# 内容适配规则

## 主标题长度变化

- 短标题：2-4 个字时可扩大字距并放大字号。
- 中等标题：4-8 个字时单行横排，为最优状态。
- 长标题：9-10 个字时拆为 2 行，字号缩小 8%-12%。
- 超出容量时：优先精简；禁止压缩字宽或向下侵入主视觉。

## 信息缺失

- 无副标题时：时间保持左侧，主视觉可向右上轻微延伸。
- 无活动时间时：副标题向左扩展，分隔线仍维持结构。
- 无辅助信息时：本版式默认无辅助信息，不做补位。
- 只有主标题时：主标题可置于 [0.07, 0.12, 0.86, 0.24]，分隔线与信息带删除。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：时尚趋势、年度主题、穿搭报告、美妆、潮流发布。
- 不适合：儿童活动、粗粝街头、复杂流程或长篇正文。
- 推荐主题：时尚、关键词、趋势、年度风格、审美、穿搭。
- 推荐信息量：低至中等信息量，核心模块 2-3 组。
- 推荐主体类型：时装人物、产品、配饰、秀场场景或趋势静物。
