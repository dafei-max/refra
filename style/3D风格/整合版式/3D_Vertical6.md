# 版式概述

竖向 3:4 画幅，顶部约三分之一由多字号主标题群占据。主标题可分为左右两个大字块，通过粗粝、撕纸或印刷感字体形成强烈节奏；小型英文或类别信息位于两块之间或右上。副标题和日期依次放在主标题下方，均采用横向单行。画面下半部为主要主视觉区域，适合假日人物、旅行产品或活动场景。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中偏左，横跨约 80% 宽度。
- 区域坐标：[0.12, 0.08, 0.80, 0.26]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-12个中文字符，最多 15个中文字符。
- 字号与画布关系：最大字高约占画布高度的 15%-21%，标题总高约占 22%-26%，整体宽度约占画布宽度的 76%-80%。
- 字体类型：粗粝展示黑体、拼贴字、手刻字、具有纸张磨损的假日活动字体。
- 字形特征：笔画宽厚、边缘不规则、局部有颗粒或缺口；不同语义单元可使用不同字号和明度，但字体风格必须统一。
- 排列方式：两至三块横向拼接，左侧字块较大，右侧字块稍小或颜色不同；上下可轻微错位。
- 对齐方式：整体居中偏左，内部以字块边缘对齐。
- 与其他信息的比例：主标题字号约为副标题的 2.6-3.4 倍，为日期的 2.8-3.8 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题正下方，横向单行短句。
- 区域坐标：[0.12, 0.34, 0.78, 0.06]
- 相对主标题字号：约为主标题字号的 26%-36%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐或居中，使用粗体无衬线或与标题一致的轻粗糙字体。
- 缺失规则：日期上移至 y=0.35 左右，主视觉上边界上移约 0.03。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：副标题下方，横向日期范围。
- 区域坐标：[0.12, 0.40, 0.55, 0.06]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 23%-31%。
- 与主标题的关系：与标题组左边界对齐，作为顶部信息区底部收束。
- 缺失规则：删除日期，主视觉上移；不保留连接符。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题内部或右上侧，用于短英文、活动类别或阶段信息。
- 区域坐标：[0.55, 0.10, 0.28, 0.10]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 18%-27%。
- 对齐关系：左对齐，与右侧标题块共用边界。
- 缺失规则：删除小型信息，右侧标题块自然扩展或保持留白。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：竖色块、连接符和短英文只为用户提供内容服务，不自动生成假日口号。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面下半部的大面积连续区域。
- 区域坐标：[0.05, 0.50, 0.90, 0.45]
- 区域形状：完整纵向矩形，从顶部信息区下方延伸至底边。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.70] 附近。
- 建议主体占比：人物或产品占画布面积的 30%-46%；旅行或假日场景占 40%-58%。
- 与文字的避让关系：不得进入 y=0.48 以上文字区；标题与主体之间至少保留画布高度 0.03 的缓冲。
- 可否延伸至文字背后：天空、渐变、假日光影可跨越全画面；主体面部和产品核心不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部粗粝主标题群。
2. 第二视觉：标题下方副标题。
3. 第三视觉：日期和顶部辅助信息。
4. 主视觉主体与文字的观看关系：读完顶部信息后向下进入假日主视觉，形成明确的上文下图结构。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可使用单一大字块并放大。
- 中等标题：6-12 个字时分成左右或上下两块，为最优状态。
- 长标题：13-15 个字时使用 3 行，整体缩小 8%-12%。
- 超出容量时：优先精简，禁止向下侵入主视觉。

## 信息缺失

- 无副标题时：日期上移并与标题保持较小间距。
- 无活动时间时：主视觉上移，副标题作为顶部信息区末端。
- 无辅助信息时：删除英文或类别，不自动补充。
- 只有主标题时：主标题可置于 [0.10, 0.10, 0.82, 0.29]，略放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：节假日、旅行、促活活动、品牌假期主题、户外娱乐。
- 不适合：新中式、奢华静态、高密度参数或长文。
- 推荐主题：假期、快乐、旅行、放松、亲子、玩乐。
- 推荐信息量：中低信息量，核心模块 3-4 组。
- 推荐主体类型：人物、旅行箱、户外场景、休闲产品、亲子或多人互动。
