# 版式概述

横向 16:9 画幅，文字组位于左侧约 48% 宽度内，自上而下依次为小型辅助信息、两行超大主标题、多行副标题。活动时间脱离主文字组，独立放置在右下角。右侧上部至中部为主要主视觉区域，右下角需为时间模块保留安全区。整体留白宽阔，文字组与主视觉形成清晰左右分区，阅读节奏偏文艺、克制、编辑化。

# 文字视觉系统

## 主标题

- 位置：画面左侧中上部，位于辅助信息下方。
- 区域坐标：[0.04, 0.32, 0.47, 0.31]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：8-14 个中文字符，最多 18 个中文字符。
- 字号与画布关系：单行字高约占画布高度的 11%-15%，两行总高约占 24%-31%；整体宽度控制在画布宽度的 40%-47%。
- 字体类型：高对比现代宋体、细长展示衬线体、具有书刊气质的中文标题字体。
- 字形特征：竖画较直、撇捺舒展、粗细对比明显，字形偏修长；可有轻微书写感，但不使用厚重黑体。
- 排列方式：两行横排，上下行中心对齐；行距紧凑但不发生笔画碰撞。
- 对齐方式：以左侧文字组中轴线居中对齐。
- 与其他信息的比例：主标题字号约为顶部辅助信息的 2.4-3.0 倍，为副标题的 2.2-2.8 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题正下方，位于左侧文字组底部。
- 区域坐标：[0.11, 0.65, 0.31, 0.16]
- 相对主标题字号：约为主标题的 34%-44%。
- 建议行数：优先 2 行，最多 3 行；短副标题可单行。
- 对齐关系：与主标题中轴线居中；多行时允许首尾长度不同，但整体轮廓应呈稳定倒梯形或紧凑块面。
- 缺失规则：无副标题时，主标题可整体下移约 0.02，或保持原位并扩大主标题下方留白；时间位置不变。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右下角，与左侧文字组分离。
- 区域坐标：[0.85, 0.84, 0.13, 0.12]
- 排列方向：上下两层；上层可放年份、阶段或短时间标识，下层可放日期范围。
- 相对主标题字号：上层约为主标题的 24%-32%，下层约为主标题的 16%-22%。
- 与主标题的关系：不与主标题同轴，通过右下角锚点平衡左侧大文字重量。
- 缺失规则：无活动时间时，右侧主视觉可延伸至右下角，禁止保留空描边框或空标签。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题上方，左侧文字组顶部。
- 区域坐标：[0.10, 0.18, 0.34, 0.12]
- 建议行数：1 行，最多 2 行。
- 相对主标题字号：约为主标题的 34%-42%。
- 对齐关系：与主标题中轴线居中；字体可采用斜体衬线或轻盈书刊体，但不得自动生成英文。
- 缺失规则：无辅助信息时，主标题整体上移至 y=0.23-0.27，保留顶部呼吸空间。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：顶部小型外文样式用于强调招募属性，属于可选辅助信息而非固定装饰。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面右侧上部至中部的大面积连续区域。
- 区域坐标：[0.52, 0.06, 0.44, 0.75]
- 区域形状：竖向近矩形，右边缘开放；下方因时间模块形成局部避让。
- 建议主体位置：主体视觉中心建议位于 [0.73, 0.45] 附近。
- 建议主体占比：单人或产品主体占画布面积的 28%-44%；场景类可占 38%-55%。
- 与文字的避让关系：主体不得进入 x=0.50 左侧；右下角 [0.83, 0.81, 0.17, 0.18] 必须为时间模块保留。
- 可否延伸至文字背后：不建议。仅允许低对比背景色、光影或纹理延伸。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：左侧两行大主标题。
2. 第二视觉：主标题上方辅助信息。
3. 第三视觉：主标题下方副标题与右下角活动时间。
4. 主视觉主体与文字的观看关系：文字先建立主题，视线随后向右进入主视觉，最后落到右下角时间锚点。

# 内容适配规则

## 主标题长度变化

- 短标题：4-7 个字时可拆为两行，每行 2-4 个字，适度放大字号。
- 中等标题：8-14 个字时按语义拆为两行，为最优状态。
- 长标题：15-18 个字时拆为 3 行，并缩小字号 8%-12%。
- 超出容量时：优先精简文案；不得压缩字宽，不得将主标题延伸到右侧主视觉区。

## 信息缺失

- 无副标题时：主标题保持居中，文字组下方留白扩大。
- 无活动时间时：主视觉区域可下延至 [0.52, 0.06, 0.45, 0.90]。
- 无辅助信息时：主标题上移，避免文字组整体下坠。
- 只有主标题时：主标题放置于 [0.06, 0.25, 0.44, 0.40]，保持两行或三行居中结构。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：城市活动招募、展览征集、文化节、公共空间项目、品牌开放报名。
- 不适合：密集促销信息、复杂产品参数、多价格、多二维码并列。
- 推荐主题：城市文化、艺术、夜间活动、街区更新、创意招募。
- 推荐信息量：中低信息量，核心模块 3-4 组。
- 推荐主体类型：人物肖像、城市街景、建筑、艺术装置或单一产品。
