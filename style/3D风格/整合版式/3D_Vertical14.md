# 版式概述

竖向 3:4 画幅，顶部使用两行像素化中英混排主标题，字形具有明显低分辨率阶梯边缘。主标题下方设置一条横向信息带：左侧为数字、面积或简短参数，右侧为副标题或关键词标签。画面中部保留最大面积主视觉区域，底部居中放置活动时间。文字区集中在顶部和底部，主体区保持完整连续。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中偏左，横跨约 84% 画布宽度。
- 区域坐标：[0.08, 0.07, 0.84, 0.24]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：2-5个短语单元，最多 14个中文字符或18个拉丁字母。
- 字号与画布关系：最大行字高约占画布高度的 12%-18%，两行总高约占 20%-24%；标题宽度约占画布宽度的 80%-84%。
- 字体类型：像素字体、低分辨率无衬线、8-bit 或早期数字界面风格的中英文字体。
- 字形特征：边缘呈阶梯状像素块，笔画由方形模块构成，内部负形明确；少量异色像素可作为非文字点缀。
- 排列方式：两行横排，上行英文或短词，下行中文或第二语义块；两行左边界接近并保持紧凑。
- 对齐方式：整体左对齐或居中偏左，严格遵循像素网格。
- 与其他信息的比例：主标题字号约为副标题标签的 2.4-3.2 倍，为底部时间的 3.0-4.0 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题下方信息带右侧，以一至两个标签承载关键词或短副标题。
- 区域坐标：[0.38, 0.31, 0.45, 0.07]
- 相对主标题字号：约为主标题字号的 28%-38%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐，文字可置于矩形色块中；标签之间可轻微错位。
- 缺失规则：删除右侧标签和底形，左侧辅助信息可向右扩展。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面底部居中，横向日期范围。
- 区域坐标：[0.36, 0.91, 0.28, 0.05]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 22%-30%。
- 与主标题的关系：与顶部文字组分离，作为底部中心锚点。
- 缺失规则：删除底部时间，主视觉向下扩展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题下方信息带左侧，用于面积、规模、场地参数或简短数字信息。
- 区域坐标：[0.19, 0.31, 0.18, 0.05]
- 建议行数：1 行，最多 2 行。
- 相对主标题字号：约为主标题字号的 22%-32%。
- 对齐关系：左对齐，保持像素网格；数值与单位视为同一信息组。
- 缺失规则：删除左侧参数，副标题标签可向左移动至 x=0.20 左右。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：异色像素、矩形标签和网格边缘用于数字潮流感，不自动生成面积、场地或品牌数据。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部的大面积连续区域。
- 区域坐标：[0.05, 0.39, 0.90, 0.48]
- 区域形状：完整纵向矩形，从顶部信息带下方延伸至底部时间上方。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.64] 附近。
- 建议主体占比：人物、产品或装置占画布面积的 30%-46%；公园、潮流场景或多人组合占 40%-58%。
- 与文字的避让关系：主体不得进入 y=0.37 以上标题和信息带区域，底部 y=0.88 以下需避让时间。
- 可否延伸至文字背后：低对比网格、像素纹理或数字渐变可跨越全画面；主体核心不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部两行像素主标题。
2. 第二视觉：标题下方左侧参数与右侧副标题标签。
3. 第三视觉：中部主视觉与底部活动时间。
4. 主视觉主体与文字的观看关系：顶部信息建立数字主题，中部主体展示公园或潮流场景，底部时间完成行动指引。

# 内容适配规则

## 主标题长度变化

- 短标题：1-2 个短语时可放大为两行。
- 中等标题：2-5 个短语单元时使用两行，为最优状态。
- 长标题：超过 5 个短语或 14 个中文字符时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简；禁止压缩像素字宽或向下侵入主视觉。

## 信息缺失

- 无副标题时：辅助参数可向右扩展，删除标签底形。
- 无活动时间时：主视觉向下扩展。
- 无辅助信息时：副标题标签向左补位。
- 只有主标题时：主标题可置于 [0.08, 0.10, 0.84, 0.25]，略放大并保留像素网格。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：数字公园、潮流市集、青年活动、科技娱乐、城市空间。
- 不适合：古典文化、浪漫书法、正式政务或长篇正文。
- 推荐主题：数字、潮流、公园、年轻人、城市更新、科技娱乐。
- 推荐信息量：中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物、数字装置、城市公园、潮流产品、互动空间或多人场景。
