# 版式概述

竖向画幅，整体为“文字主视觉优先”的海报型版式。主标题不是标准横排信息块，而是位于画面上中部的大面积自由排布文字团，承担主视觉角色。画面右上角有一组小型辅助信息，用于补充标识或系列信息；左下角有一组较小副标题/说明信息，形成对角呼应。中下部到下半部保留大面积连续留白，可作为主视觉延展区或背景呼吸区，但本参考中真正的视觉核心仍然是标题文字团本身。阅读顺序为：中央主标题文字团 → 右上辅助信息 → 左下副标题/说明信息。

# 文字视觉系统

## 主标题

- 位置：画面上中部偏左至中部，整体形成一个近似竖向聚合的大文字团。
- 区域坐标：`[0.13, 0.12, 0.72, 0.48]`
- 信息层级：最高层级，同时兼任主要视觉主体。
- 建议行数：4-6 行优先，最多 8 行。
- 建议字数：8-20 字，最多不超过 30 字。
- 字号与画布关系：标题整体高度约占画布高度的 38%-50%，宽度约占画布宽度的 55%-72%；单字尺寸变化明显，形成不规则节奏。
- 字体类型：手写感强烈的无衬线标题字或拟手绘字。
- 字形特征：粗笔触、边缘不规则、重心跳跃、字面夸张、疏密变化明显，具有情绪化和态度化表达。
- 排列方式：自由换行、非严格网格排布，可通过字距、倾斜、局部放大形成整体块面感。
- 对齐方式：整体居中偏左的自由构图，对内部单行不要求严格齐头齐尾。
- 与其他信息的比例：远大于副标题和辅助信息；右上辅助信息约为主标题字号的 10%-16%，左下副标题约为主标题字号的 14%-20%。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：是
- 位置：左下角，靠近底部边缘，用作补充说明或短句承接。
- 区域坐标：`[0.06, 0.82, 0.38, 0.10]`
- 相对主标题字号：约为主标题的 14%-20%。
- 建议行数：0-2 行。
- 对齐关系：左对齐，整体保持紧凑，可附带少量装饰性笔触但不扩展为独立装饰文案。
- 缺失规则：删除后保留左下留白，不用其他信息补位。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：否
- 位置：本参考图中无独立活动时间模块。
- 区域坐标：`[0.00, 0.00, 0.00, 0.00]`
- 排列方向：不适用
- 相对主标题字号：不适用
- 与主标题的关系：若项目必须加入时间信息，建议并入左下副标题区或右上辅助信息区，不新增独立大模块。
- 缺失规则：默认不设置该模块。
- 颜色规则：若启用，应与主标题保持一致。

## 辅助信息

- 是否支持：是
- 位置：右上角，小面积角标型信息区。
- 区域坐标：`[0.79, 0.03, 0.16, 0.16]`
- 建议行数：1-3 行。
- 相对主标题字号：约为主标题的 10%-16%。
- 对齐关系：右上区域内可居中或左对齐，但整体应保持角落收束感，不可扩展过大。
- 缺失规则：删除后右上保留空白，不移动主标题去填补。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：参考图包含少量角落型标识与笔触性辅助线，用于强化版式风格和边角平衡，不属于必须继承的信息模块。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：本版式为“文字即主视觉”的结构，非文字主视觉生成区主要位于中下部至下半部连续留白区域。
- 区域坐标：`[0.00, 0.42, 1.00, 0.58]`
- 区域形状：纵向延展的大矩形连续区域。
- 建议主体位置：如需加入插画、产品、材质或抽象元素，应优先放在中下部或下半部，并控制为陪衬型主体。
- 建议主体占比：非文字主体建议占画布面积的 15%-30%，避免压过标题文字团。
- 与文字的避让关系：必须避开中央大标题区、右上辅助信息区和左下副标题区；任何主体只能作为背景承托，不可与标题争抢第一视觉。
- 可否延伸至文字背后：仅允许低对比、低细节、低干扰的背景纹理或轻体积元素延伸至文字背后，不可影响识别。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：中央大面积主标题文字团。
2. 第二视觉：右上角辅助信息。
3. 第三视觉：左下角副标题/说明信息。
4. 主视觉主体与文字的观看关系：文字本身即主视觉核心，其他图像元素只能作为辅助氛围，不可夺取主导权。

# 内容适配规则

## 主标题长度变化

- 短标题：可通过放大单字、增加字间错落和行间变化来维持块面张力，避免标题团过小。
- 中等标题：最适合该版式，保持 4-6 行自由编排即可。
- 长标题：允许分成 6-8 行，但需确保整体仍形成紧凑的中心块，不可松散摊开。
- 超出容量时：优先拆分为多行并控制字形疏密；如仍超出，应由用户精简内容，禁止挤占右上和左下信息区。

## 信息缺失

- 无副标题时：保留左下留白，整体更偏极简实验海报。
- 无活动时间时：无需补位，本版式默认无独立时间模块。
- 无辅助信息时：右上留白保留，主标题仍然成立。
- 只有主标题时：可直接成立完整海报，中央标题团作为唯一核心视觉。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：态度海报、情绪表达型传播、品牌主题 KV、青年文化视觉、生活方式宣传、实验型海报。
- 不适合：强商务会议主 KV、严格企业发布会主视觉、需要大量规范信息的活动页头图。
- 推荐主题：情绪表达、生活态度、品牌主张、创意 campaign、文化表达。
- 推荐信息量：1 组主标题 + 0-1 组副标题 + 0-1 组辅助信息。
- 推荐主体类型：无主体纯文字海报、轻插画背景、抽象纹理、低干扰静物、轻量产品陪衬。
