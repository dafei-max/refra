# 版式概述

竖向 3:4 画幅，顶部以两行粗线手写中文构成主标题，整体居中。主标题下方可放置一条阶段日期或短活动时间。画面中部至下部保留大面积主视觉区域；底部居中放置副标题，并在其下方设置主活动时间。若用户只提供一个时间段，默认使用底部主时间，不重复生成标题下方日期。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中，横跨约八成宽度。
- 区域坐标：[0.10, 0.08, 0.80, 0.23]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：8-14个中文字符，最多 17个中文字符。
- 字号与画布关系：单行字高约占画布高度的 10%-15%，两行总高约占 19%-23%；标题宽度约占画布宽度的 76%-80%。
- 字体类型：粗线手写体、现代篆写体、带织线或压印质感的东方展示字。
- 字形特征：笔画宽度相对均匀，转折略圆，字形横向舒展；边缘可有织线、印章或手工纹理，但结构必须清晰。
- 排列方式：两行居中堆叠，上行略短，下行更宽；行距紧凑但不相碰。
- 对齐方式：整体严格居中，内部可轻微错位。
- 与其他信息的比例：主标题字号约为底部副标题的 3.0-4.0 倍，为时间的 3.2-4.2 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面底部居中，一条情绪或主题短句。
- 区域坐标：[0.22, 0.88, 0.56, 0.06]
- 相对主标题字号：约为主标题字号的 20%-28%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：居中对齐，使用细宋体、书写体或轻衬线体。
- 缺失规则：删除底部短句，主时间上移至 y=0.90 左右。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：主时间位于底部副标题下方；可选阶段时间位于主标题下方。
- 区域坐标：底部主时间 [0.33, 0.93, 0.34, 0.04]；可选标题下时间 [0.29, 0.26, 0.50, 0.05]。
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 18%-26%。
- 与主标题的关系：底部时间作为正式信息收束；标题下时间仅在用户提供独立阶段或预热周期时启用。
- 缺失规则：删除全部时间模块；不得保留空徽章、连接符或时间标签。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：不支持。
- 位置：不设置固定辅助信息区。
- 区域坐标：无。
- 建议行数：0 行。
- 相对主标题字号：不适用。
- 对齐关系：不适用。
- 缺失规则：默认删除，不使用外文或徽章补位。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：标题下方的小徽章或印章仅可作为非文字图形；不得自动生成品牌、期次或机构名称。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部至下部的大面积连续区域。
- 区域坐标：[0.05, 0.35, 0.90, 0.49]
- 区域形状：完整纵向矩形，底部因居中信息形成窄幅避让。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.62] 附近。
- 建议主体占比：单人或产品占画布面积的 30%-45%；艺术场景或多人组合占 38%-55%。
- 与文字的避让关系：主体不得进入 y=0.33 以上标题与阶段时间区，底部 y=0.86 以下需避让副标题和主时间。
- 可否延伸至文字背后：低对比纸张、展墙、秋日光影可跨越全画面；主体核心不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部双行手写主标题。
2. 第二视觉：标题下方可选阶段时间。
3. 第三视觉：中部主视觉与底部副标题、主时间。
4. 主视觉主体与文字的观看关系：顶部标题建立文化主题，中部主体展开，底部信息完成展览式收束。

# 内容适配规则

## 主标题长度变化

- 短标题：4-7 个字时可一至两行放大。
- 中等标题：8-14 个字时使用两行，为最优状态。
- 长标题：15-17 个字时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简；禁止向下侵入主视觉。

## 信息缺失

- 无副标题时：主时间上移并保持居中。
- 无活动时间时：删除标题下和底部全部时间。
- 无辅助信息时：本版式默认无辅助信息，不做补位。
- 只有主标题时：主标题可置于 [0.09, 0.11, 0.82, 0.25]，略放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：秋季活动、东方艺术、展览、文化品牌、生活方式专题。
- 不适合：科技、运动、密集促销、复杂数据。
- 推荐主题：秋日、东方、诗意、艺术、未定义、展览。
- 推荐信息量：低至中等信息量，核心模块 2-4 组。
- 推荐主体类型：人物、艺术装置、秋日静物、建筑、展览空间或东方器物。
