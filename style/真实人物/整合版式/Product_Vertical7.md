# 版式概述

竖向 3:4 画幅，主标题位于顶部，以两行超大几何无衬线字组成，上行略靠左、下行向右展开。小型辅助信息贴附在上行右侧，细线、叶片和小花等非文字装饰穿过标题外围，形成轻盈的出行动势。画面中部至下部是主要主视觉区域；底部左侧放置副标题，右侧放置活动时间，构成双端锚点。标题内部的线条空隙仅用于装饰和呼吸，不可放置主体核心。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中偏左，横跨约四分之三画布宽度。
- 区域坐标：[0.14, 0.06, 0.74, 0.28]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-10个中文字符，最多 12个中文字符。
- 字号与画布关系：单行字高约占画布高度的 10%-15%，两行总高约占 22%-28%；标题宽度约占画布宽度的 70%-74%。
- 字体类型：宽体几何黑体、现代展示无衬线体、圆角或轻方角中文标题字。
- 字形特征：笔画粗、字面宽阔、内部负形清晰，边角略圆润；字形稳定规整，可有轻微外扩或切角，但不使用书法笔触。
- 排列方式：两行错位排列，上行较短并偏左，下行更宽并向右延展；辅助短词贴附在第一行右侧。
- 对齐方式：整体以画面中轴偏左为基准，内部采用左对齐和视觉居中结合。
- 与其他信息的比例：主标题字号约为底部副标题的 3.2-4.2 倍，为活动时间的 3.0-3.8 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面左下角，以一条横向短句收束。
- 区域坐标：[0.05, 0.90, 0.50, 0.05]
- 相对主标题字号：约为主标题字号的 22%-30%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐，使用较规整的粗体无衬线或轻圆体。
- 缺失规则：删除左下短句，主视觉可向左下扩展，右下时间保持原位。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右下角，靠近底部和右侧安全边距。
- 区域坐标：[0.72, 0.90, 0.24, 0.05]
- 排列方向：横向单行，适合日期范围或短时间段。
- 相对主标题字号：约为主标题字号的 24%-32%。
- 与主标题的关系：与顶部标题分离，作为右下角平衡锚点。
- 缺失规则：删除右下时间，主视觉可延伸至右下角。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：第一行主标题右侧，用于短英文、活动类别或翻译。
- 区域坐标：[0.66, 0.14, 0.26, 0.08]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 18%-25%。
- 对齐关系：左对齐，宽度不超过主标题总宽度的三分之一。
- 缺失规则：删除小型辅助信息，第一行标题可向右扩展约画布宽度 0.04，或保持原位。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：穿行于标题外围的曲线、叶片、小花和色点用于建立春日动势，不承担额外文案。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部至下部的大面积连续区域。
- 区域坐标：[0.05, 0.34, 0.90, 0.52]
- 区域形状：纵向完整近矩形，底部因左右信息形成窄幅避让。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.61] 附近。
- 建议主体占比：单人或产品主体占画布面积的 30%-46%；多人、出行场景或产品组合占 38%-56%。
- 与文字的避让关系：主体不得进入 y=0.32 以上标题区；底部 y=0.87 以下需避让副标题和时间。
- 可否延伸至文字背后：低对比天空、渐变、柔光或统一纹理可延伸到文字背后；人物面部和产品核心不得进入标题区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部两行巨型主标题。
2. 第二视觉：标题右侧的小型辅助信息。
3. 第三视觉：底部左侧副标题和右侧活动时间。
4. 主视觉主体与文字的观看关系：顶部文字先建立主题，视线向下进入主视觉，最后由底部双端信息收束。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可使用一至两行，并放大字形、扩大行间错位。
- 中等标题：6-10 个字时使用两行，为最优状态。
- 长标题：11-12 个字时使用 3 行，字号缩小 8%-12%，减少外伸装饰线。
- 超出容量时：优先精简；禁止向下侵入主视觉或压缩字宽。

## 信息缺失

- 无副标题时：主视觉向左下扩展。
- 无活动时间时：主视觉向右下扩展。
- 无辅助信息时：删除小型短词，标题保持完整。
- 只有主标题时：主标题可置于 [0.12, 0.08, 0.78, 0.30]，整体放大约 5%-8%。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：春日活动、出行招募、旅行搭子、生活方式、轻户外品牌。
- 不适合：密集促销、复杂流程、严肃政务或大量正文。
- 推荐主题：春天、旅行、相遇、出行、自然、轻社交。
- 推荐信息量：低至中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物、双人互动、旅行产品、花草、户外或城市出行场景。
