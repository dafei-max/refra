# 版式概述

竖向 3:4 画幅，上半部至中部保持大面积连续主视觉区域。主标题位于画面下半部中央，以两行粗粝手写中文构成，部分英文或短词叠置在标题下沿，形成实验编辑感。底部左侧放置副标题，右侧放置活动时间。主标题周围的小空隙属于字形结构留白，不适合放置人物面部或产品核心。

# 文字视觉系统

## 主标题

- 位置：画面下半部中央，整体略偏左。
- 区域坐标：[0.17, 0.61, 0.68, 0.25]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-10个中文字符，或2-4个短语单元，最多 13个中文字符。
- 字号与画布关系：最大单字字高约占画布高度的 12%-18%，两行总高约占 21%-25%；标题宽度约占画布宽度的 64%-68%。
- 字体类型：炭笔手写体、粗粝铅笔字、手刻字与简洁无衬线英文混排。
- 字形特征：中文边缘粗糙、线条密度不均、字形略有摇摆；英文可使用干净无衬线或机械字体形成材质反差。
- 排列方式：两行自由错位，上行字数较少、下行横向展开；英文或短词可嵌入下行下方，但不得遮挡。
- 对齐方式：以画面中轴偏左为基准，内部采用自由居中和错位。
- 与其他信息的比例：主标题字号约为底部副标题的 3.2-4.2 倍，为活动时间的 3.0-4.0 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面左下角，一条短句或活动说明。
- 区域坐标：[0.06, 0.91, 0.53, 0.05]
- 相对主标题字号：约为主标题字号的 20%-28%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐，使用较规整的手写体、宋体或轻无衬线体。
- 缺失规则：删除左下短句，主视觉可向左下延伸。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右下角，横向日期范围。
- 区域坐标：[0.74, 0.91, 0.22, 0.05]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 20%-28%。
- 与主标题的关系：与主标题分离，作为右下角锚点。
- 缺失规则：删除右下时间，主视觉向右下扩展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题下沿或两行之间，用于短英文、翻译或类别信息。
- 区域坐标：[0.34, 0.72, 0.42, 0.12]
- 建议行数：1 行为主，最多 2 行。
- 相对主标题字号：约为主标题字号的 28%-42%。
- 对齐关系：围绕主标题中轴居中或轻微右偏，保持与手写中文的层级差异。
- 缺失规则：删除英文或类别短词，中文标题下行自然补位。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：手写噪点、铅笔纹理和注册符号仅用于风格，不自动生成品牌或机构名称。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面上半部至中部的大面积连续区域。
- 区域坐标：[0.05, 0.05, 0.90, 0.53]
- 区域形状：完整纵向矩形，从顶部延伸至主标题上缘。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.32] 附近。
- 建议主体占比：人物或产品占画布面积的 30%-45%；生活场景或多人组合占 38%-54%。
- 与文字的避让关系：主体下缘不得压入 y=0.58 以下标题区；标题上方至少保留画布高度 0.03 的缓冲。
- 可否延伸至文字背后：低对比背景、纸纹、空间光影可跨越全画面；高对比主体不得进入标题安全区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：上半部主视觉主体。
2. 第二视觉：下半部粗粝主标题。
3. 第三视觉：标题内辅助短词与底部左右信息。
4. 主视觉主体与文字的观看关系：先看上方主体，再落到下方标题，底部副标题和时间完成信息闭环。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可使用一至两行并放大。
- 中等标题：6-10 个字或 2-4 个短语时使用两行，为最优状态。
- 长标题：11-13 个字时使用 3 行，缩小字号 8%-12%。
- 超出容量时：优先精简；禁止向上侵入主视觉或极度压缩字距。

## 信息缺失

- 无副标题时：主视觉向左下扩展。
- 无活动时间时：主视觉向右下扩展。
- 无辅助信息时：删除英文短词，不使用无关内容填充。
- 只有主标题时：主标题可置于 [0.15, 0.65, 0.72, 0.24]，略放大并居中。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：生活方式、创意社群、日常灵感、实验专题、品牌内容。
- 不适合：严肃公文、密集数据、复杂流程或高端古典主题。
- 推荐主题：灵感、日常、热爱、实验、工作室、青年文化。
- 推荐信息量：低至中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物、创作空间、日常产品、工作台、城市或静物。
