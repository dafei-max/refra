# 版式概述

竖向 3:4 画幅，主标题位于顶部，以粗粝中文、衬线英文和长连笔字形成两行多语种混排。标题右侧可放置一个小型椭圆时间标签，左下可放置地点或短翻译。画面中部是主要主视觉区域，底部居中放置副标题与活动时间。若用户仅提供一个时间段，默认只在底部展示，不重复生成标题侧时间标签。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中，横跨约九成画布宽度。
- 区域坐标：[0.06, 0.06, 0.90, 0.31]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：5-9个中文字符，或2-4个中英短语，最多 12个中文字符。
- 字号与画布关系：最大中文单字字高约占画布高度的 13%-19%，两行总高约占 25%-31%；标题宽度约占画布宽度的 86%-90%。
- 字体类型：粗粝手写衬线体、炭笔中文、长连笔英文与高对比罗马体混排。
- 字形特征：中文边缘带颗粒与手写抖动，英文可使用细长衬线或连笔字；不同语种字号差异明显，但整体笔触和粗糙度一致。
- 排列方式：两行自由拼接，上行英文与中文并置，下行使用更大的中文和长英文；短地点可放在标题左下。
- 对齐方式：整体居中偏左，内部采用自由错位与叠置。
- 与其他信息的比例：主标题字号约为底部副标题的 3.2-4.2 倍，为底部时间的 3.5-4.8 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面底部居中，以一条横向短句出现。
- 区域坐标：[0.27, 0.91, 0.50, 0.05]
- 相对主标题字号：约为主标题字号的 18%-25%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：居中对齐，使用较规整的衬线体、宋体或轻无衬线。
- 缺失规则：删除底部短句，时间可向左移动并居中。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：默认位于底部副标题右侧或下方；标题右侧可选小型椭圆时间标签。
- 区域坐标：底部主时间 [0.65, 0.91, 0.12, 0.05]；可选标题侧时间 [0.84, 0.23, 0.12, 0.06]。
- 排列方向：底部横向单行；标题侧为椭圆单行短日期。
- 相对主标题字号：底部时间约为主标题字号的 17%-24%，标题侧标签约为 20%-28%。
- 与主标题的关系：底部时间与副标题共同收束画面；标题侧标签仅在用户提供独立阶段时间时启用。
- 缺失规则：删除全部时间模块，底部副标题保持居中；不得保留空椭圆。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：标题左下或中英混排空隙，用于地点、翻译或类别短词。
- 区域坐标：[0.04, 0.31, 0.18, 0.05]
- 建议行数：1 行，最多 2 行。
- 相对主标题字号：约为主标题字号的 16%-23%。
- 对齐关系：左对齐，贴附标题左下轮廓。
- 缺失规则：删除地点或短词，不自动生成城市名。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：椭圆标签、圆点和手写长线用于编辑感，不自动生成地点、日期或英文。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部的大面积连续区域。
- 区域坐标：[0.05, 0.39, 0.90, 0.48]
- 区域形状：完整纵向矩形，上下分别被标题组和底部信息夹持。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.64] 附近。
- 建议主体占比：单人、产品或旅行静物占画布面积的 28%-44%；场景或多人组合占 36%-54%。
- 与文字的避让关系：主体不得进入 y=0.37 以上标题区，底部 y=0.88 以下避让副标题和时间。
- 可否延伸至文字背后：低对比城市、天空、胶片纹理可延伸至标题后方；人物面部不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部多语种主标题。
2. 第二视觉：标题侧地点与可选时间标签。
3. 第三视觉：中部主视觉和底部副标题、时间。
4. 主视觉主体与文字的观看关系：先读顶部标题，再进入中部旅行场景，底部信息完成情绪收束。

# 内容适配规则

## 主标题长度变化

- 短标题：2-4 个短语时可使用两行并放大。
- 中等标题：5-9 个中文字符或 2-4 个中英短语时两行混排，为最优状态。
- 长标题：10-12 个中文字符时使用 3 行并减少英文插入。
- 超出容量时：优先精简；禁止压缩字宽或覆盖标题侧时间。

## 信息缺失

- 无副标题时：底部时间居中。
- 无活动时间时：删除底部和标题侧时间，不重复占位。
- 无辅助信息时：删除地点或翻译，不改变主标题。
- 只有主标题时：主标题可置于 [0.05, 0.09, 0.91, 0.32]，略放大并居中。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：旅行、城市专题、毕业季、告别主题、文艺活动、文化内容。
- 不适合：硬核科技、密集促销、儿童卡通或正式公文。
- 推荐主题：旅行、告别、城市、青春、记忆、远方。
- 推荐信息量：中低信息量，核心模块 3-5 组。
- 推荐主体类型：旅行人物、城市、车站、行李、胶片场景或文艺静物。
