# 参考图 08｜UI 界面拼贴的穿搭清单海报

- **对应原图**：Destination 标签页 / 人物 cutout / 单品物件平铺
- **预设定位**：穿搭清单海报 / UI 拼贴视觉 / 社媒穿搭卡片

## 这张图具体能解决什么问题

这张图解决的是“如何把人物穿搭、搭配单品和数字产品界面感组合成一张清晰、可分享、可收藏的轻信息海报”的问题。

它不是传统意义上的人物大片，而更像“穿搭截图”“搭配看板”“社媒模板”。通过 UI 栏、分栏卡片和人物 cutout，把人物与单品关系讲得非常直接，适合 AI 学习结构化穿搭内容表达。

## 人物与环境的关系

- 人物与真实环境关系极弱，几乎没有真实场景。
- 人物被当成一个 cutout 角色，置于一个界面卡片系统中。
- 单品静物和人物并列，像“穿搭说明图”一样共同组成内容。
- 环境本身就是简化的数字界面与信息容器。

## 画面版式

- 竖版，采用上导航栏 + 下双卡片的 UI 布局。
- 顶部像 app 标签页，定义内容类型和浏览方式。
- 左侧卡片放单品静物拼贴，右侧卡片放完整人物穿搭。
- 大面积浅灰留白保证内容清晰、轻盈。
- 整体是非常强的“产品界面式版式”，而不是传统海报版式。

## 造型语言

- 人物穿搭偏甜酷休闲，蓝白黄配色明确。
- 左侧单品以“切片式平铺”呈现，强调搭配关系。
- 人物保留完整全身比例，像购物页面中的穿搭模特。
- 所有元素轮廓清晰、抠图干净，强调卡片化。

## 动势与姿态

- 人物采用轻转身站姿，姿态自然、友好。
- 动势很弱，重点是“展示穿搭整体轮廓”。
- 左侧单品则通过高低排布形成图面节奏。
- 这种海报不依赖动作冲击，而依赖“信息组织的轻快感”。

## 表现手法

- 人物抠图 + 静物抠图 + UI 合成。
- 画面更接近设计模板和社媒内容卡，而非摄影大片。
- 非常适合作为“推荐、分享、收藏、搭配指南”类内容形式。
- AI 生成时关键在于版式、留白和元素清晰分区。

## 色彩逻辑

- 整体底色为浅灰白中性。
- 主强调色为蓝色，贯穿导航栏、人物穿搭和静物手套。
- 黄色墨镜与米黄色包包形成第二层呼应。
- 绿色柠檬是单个跳色，用于增强搭配趣味。
- 色彩柔和、轻快、清晰，非常适合生活方式内容。

## 光影

- 物件和人物都采用相对均匀的抠图光。
- 阴影非常弱或几乎被移除，强化数字界面感。
- 不是强调真实空间，而是强调清爽、规整、易读。
- 适合“伪 UI”“数字看板”类内容表达。

## 空间复杂度

- **低复杂度**。
- 没有真实深空间，只有卡片与留白层级。
- 信息简单清晰，便于快速阅读。
- 特别适合移动端内容海报。

## 情绪

- 轻松、可爱、分享感、穿搭灵感、数字生活方式。
- 带有“收藏夹”“清单”“模板”的轻产品感。
- 比传统海报更像内容组件。

## 适用主题

- 穿搭清单、OOTD 推荐、单品组合、旅行行李灵感、社媒内容页。
- 服饰、配饰、鞋包、电商内容、时尚博主模板。
- 适合做系列化、模块化视觉。

## 禁用场景

- 不适合大气电影感、强情绪人物大片。
- 不适合复杂背景和真实场景叙事。
- 不适合承载大量硬广促销信息。
- 不应使用过多颜色和物件，否则会失去“清单感”。

## 可共享的视觉规则

1. 把版式当作 UI，而不是普通海报。
2. 人物和单品分栏并列，清楚建立搭配关系。
3. 留白要大，信息块要清晰。
4. 抠图边缘与卡片阴影质量决定整体高级感。
5. 适合系列化输出和模板化复用。
