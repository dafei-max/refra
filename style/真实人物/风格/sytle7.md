# 参考图 07｜窗景拼接室内外的人物叙事海报

- **对应原图**：室内空间 / 窗中山野景 / 坐姿女性人物
- **预设定位**：叙事型人物海报 / 室内外拼接视觉 / 服饰生活方式海报

## 这张图具体能解决什么问题

这张图解决的是“如何在人物海报中，把室内陈设、穿搭和远方目的地想象放进同一画面，并保持整体自然成立”的问题。

它通过“室内白墙与窗框 + 室外山野景观”的拼接，让人物像坐在一个能够通往远方的生活场景中。人物既像处于一个展厅，也像已经进入目的地情境，因此特别适合旅行感、秋冬氛围和生活方式叙事。

## 人物与环境的关系

- 人物与环境关系较强，人物坐在室内结构上，真正“占据了空间”。
- 背后的大窗景不只是背景图，而是人物情绪的外部延伸。
- 室内空间提供人设和穿搭的现实落点，山野环境提供想象、情绪和故事。
- 环境整体服务于人物气质：安静、略冷、带有远行感。

## 画面版式

- 竖版海报，主体人物位于中下部偏中位置。
- 后方大型竖向窗框构成视觉主骨架。
- 室外山景充满窗内区域，形成明确的“景框”。
- 左下保留少量实景家具，右侧保留极简室内线稿式结构，增加空间延展。
- 文字信息极少，主要靠图像叙事。

## 造型语言

- 人物穿搭为宽松外套、牛仔裤、帽饰，偏户外休闲与秋冬城市混合风。
- 坐姿放松但不松散，具有模特式控制感。
- 室内家具极简，人物服装承担主要造型细节。
- 背景风景宏大，人物前景却安静，形成内外尺度反差。

## 动势与姿态

- 人物为坐姿与轻微前倾组合，动态较弱。
- 动势更多体现在头部角度、腿部摆放和视线方向。
- 与上一类强动作海报不同，这类图依赖“静态里的情绪张力”。
- 窗景的纵深感替代了动作感，成为画面的流动来源。

## 表现手法

- 室内搭景 + 风景拼接 / 合成。
- 具有“展览装置感”“画框感”和“生活方式叙事”三重属性。
- 人物真实、环境半真实、空间带有轻超现实感。
- 属于适合 AI 学习的“环境叙事型人物海报”。

## 色彩逻辑

- 室内为白灰中性，人物穿搭为深蓝牛仔色系。
- 室外山景为金黄草地、深蓝山体，形成冷暖交错。
- 整体色彩克制而有层次，不追求高饱和。
- 人物与窗景颜色互相呼应，不会被环境吞没。

## 光影

- 人物光线柔和自然，适合服装质感展示。
- 室外景色自带日照层次，形成景深和空间远近。
- 室内空间保持干净明亮，光影不复杂。
- 重点是“让人物和拼接环境仍然看起来在一个世界里”。

## 空间复杂度

- **中等复杂度**。
- 前景是人物和家具，中景是室内框体，远景是山野。
- 画面叙事明确，但元素数量不多。
- 适合单人物 + 场景想象型海报。

## 情绪

- 安静、远行、松弛、秋冬、生活方式、轻文艺。
- 带有“在城市里向往远方”的情绪投射。
- 比纯时装海报更有叙事，比纯风景图更有人物入口。

## 适用主题

- 秋冬穿搭、旅行主题、城市与自然、lookbook、生活方式服饰。
- 户外休闲品牌、文艺企划、店铺内容海报。
- 适合“空间故事”型人物视觉。

## 禁用场景

- 不适合强促销、强价格信息、短平快流量海报。
- 不适合运动爆发感或高能量主题。
- 不适合背景风景过于复杂凌乱。
- 不建议加入过多额外人物，会破坏独处感。

## 可共享的视觉规则

1. 用“窗景/画框”连接现实空间与情绪空间。
2. 人物要真实占据前景结构，不能像简单贴图。
3. 室内环境尽量简洁，让风景成为情绪背景。
4. 动势可以弱，但情绪和空间层次必须清楚。
5. 适合做单人叙事，不适合高密度商业信息。
