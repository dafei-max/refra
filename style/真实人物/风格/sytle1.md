# 参考图 01｜城市潮流跃动的人物街景海报

- **对应原图**：城市高楼 + 橙色公交 / 跃起人物 / REDVibe
- **预设定位**：都市潮流人物海报 / 街头生活方式广告 / 城市主题 KV

## 这张图具体能解决什么问题

这张图解决的是“如何把一个相对抽象的城市生活方式概念，转化成一个第一眼就能成立的潮流人物海报”的问题。

它并不是单纯拍一个人站在街上，而是通过“跃起动作 + 城市交通载体 + 高楼背景 + 大字品牌词”共同建立“城市活力、年轻社交、流动中的潮流感”。人物是画面的绝对焦点，公交和写字楼不是写实背景，而是帮助定义“城市气质”的场景装置。

## 人物与环境的关系

- 人物是主角，环境是“城市身份说明器”。
- 背后的公交不是纯背景，而是为人物提供运动感、速度感和街头生活语境。
- 高楼与蓝天建立“现代城市”框架，让人物像是从通勤秩序中跳脱出来的潮流个体。
- 人物动作明显脱离地面，使其与环境形成戏剧性反差：环境稳定、人物轻盈。
- 手中的球拍、腰间呼啦圈等配件，不是功能道具，而是“生活兴趣标签”。

## 画面版式

- 标准竖版海报，采用**上环境—中人物—下大标题**的三段式结构。
- 人物位于中轴略偏上位置，形成单一核心主体。
- 上方留有窄条信息区，用于放置年份、活动名和英文信息。
- 底部超大 “REDVibe” 文字承担第二视觉中心，既是标题也是地面层的一部分。
- 搜索框和品牌标签压在底部信息区，形成商业落点。
- 整体阅读顺序：顶部小信息 → 中部人物 → 底部大标题 → 搜索与品牌信息。

## 造型语言

- 人物穿搭采用混搭式学院街头风：帽子、领带、外套、短裙、条纹袜、皮鞋。
- 配饰具有玩具感和运动感，强化轻松、不按常规的潮流语义。
- 人物姿态不是标准时装 pose，而是接近“空中抓拍”的生活剧照。
- 背景建筑和公交以大面积简单几何面出现，人物服装承担更多细节信息。

## 动势与姿态

- 采用单脚后抬、身体悬空、手臂外展的跳跃姿态。
- 姿态方向向右前方展开，制造“正在城市里移动”的运动趋势。
- 呼啦圈与球拍共同构成圆形节奏，增加弹跳和玩乐气质。
- 动势大但并不激烈，更像“轻松地跳入镜头”。

## 表现手法

- 偏商业摄影 + 后期排版合成。
- 具有明显“杂志封面”和“潮流 campaign”融合感。
- 公交的运动模糊增强速度感，但人物保持清晰，形成动静对比。
- 环境写实，人物表演性强，整体不是纪实摄影，而是高度策划后的情境式海报。
- 底部标题带有立体厚重效果，使画面更具广告完成度。

## 色彩逻辑

- 以天空蓝、建筑蓝灰、公交橙为主环境色。
- 人物服装中的紫色与粉色形成潮流感强调。
- 底部标题白色高亮，作为强对比的落版中心。
- 整体色彩鲜明但不杂乱，依靠“蓝橙对比 + 紫粉点缀”建立年轻感。

## 光影

- 采用明亮日景光线，人物面部和服装被均匀照亮。
- 背景建筑和公交反射清晰，具有真实街景的硬朗感。
- 人物主体的光线干净直白，不强调复杂情绪阴影。
- 适合表现“白天、城市、潮流、活力”的广告氛围。

## 空间复杂度

- **中等复杂度**。
- 远景是高楼天空，中景是公交，前景是人物和底部装置文字。
- 元素较多，但视觉中心清晰，不会分散焦点。
- 适合做人物主视觉海报，不适合承载太多辅助故事线。

## 情绪

- 年轻、活力、潮流、城市、社交、轻松。
- 带有“我在城市里玩出自己的风格”的表达。
- 比纯时尚更轻松，比纯运动更生活方式。

## 适用主题

- 城市生活节、街头潮流、兴趣社交、青年文化、品牌 campaign。
- 时尚穿搭、城市探索、都市漫游、兴趣运动、生活方式平台海报。
- 适合表达“城市 vibe”“年轻人生活方式”“兴趣社区”。

## 禁用场景

- 不适合严肃商务、专业功能型产品说明。
- 不适合需要强烈情绪深度或戏剧叙事的题材。
- 不适合过于传统、正式、复古的品牌视觉。
- 不建议替换成低饱和灰暗环境，会削弱“城市活力”。

## 可共享的视觉规则

1. 人物必须是唯一主角，环境只负责定义“城市气质”。
2. 通过腾空动作制造人物从现实街景中跳出的戏剧性。
3. 采用大面积城市交通或建筑体块，快速建立地点属性。
4. 底部标题可作为视觉落点和品牌符号，不只是文字信息。
5. 道具要服务兴趣身份，而不是纯装饰堆砌。
