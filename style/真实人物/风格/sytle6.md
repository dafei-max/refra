# 参考图 06｜拼贴式时装 Lookbook 的人物编辑海报

- **对应原图**：白边照片框 / 皮衣男模 / 小样张与饰品拼贴
- **预设定位**：时装 lookbook / 品牌编辑海报 / 拼贴式人物展示页

## 这张图具体能解决什么问题

这张图解决的是“如何在一张人物海报里，同时展示品牌调性、穿搭主体、细节局部和辅助物件，而不显得像电商详情页”的问题。

它采用编辑拼贴思路，把主人像照片、局部特写、小尺寸 look 图和品牌物件组合在一起，使整张图更像一本时装手册中的页面，而不是单一商业大海报。

## 人物与环境的关系

- 人物与环境关系较弱，主人物本身处于近乎纯背景的人像状态。
- 真正的“环境”是由纸张、相片框、灰度底纹和小道具拼贴出来的版面空间。
- 人物不需要进入真实场景，而是被放进一个品牌视觉系统中。
- 小图和局部特写承担“补充环境和穿搭信息”的作用。

## 画面版式

- 竖版拼贴版式。
- 中央偏右是最大的人物主图，带有白边照片框效果。
- 左上是局部特写，左下是完整小 look，右侧是品牌挂件与徽章。
- 顶部有弱化信息头栏，形成 lookbook 页面感。
- 整体像“杂志页 / 档案页 / moodboard 页面”。

## 造型语言

- 人物穿搭强调秋冬质感与复古皮革气质。
- 主图使用半身偏全身 pose，突出外套体积与肩部轮廓。
- 配色偏棕、黑、米白，形成成熟稳定的时装语言。
- 小物件与局部图共同强化品牌故事感。

## 动势与姿态

- 人物姿态偏静态，主要依靠眼神和身体扭转形成张力。
- 动势不大，更适合展示穿搭质感和人物气质。
- 小图位置的高低错落形成版面上的流动，而非人物动作本身。

## 表现手法

- 典型的 lookbook / 编辑拼贴手法。
- 通过照片框、纸张层叠、夹子、便签式安排制造手工编辑感。
- 主图与辅图并行存在，形成“主视觉 + 参考页”的阅读体验。
- 不是强广告促销，而是品牌内容型表达。

## 色彩逻辑

- 大面积灰白、黑、棕色，整体色彩克制。
- 黄色腰带成为小面积跳色，增加焦点。
- 辅助小图和金属物件维持综合色彩统一。
- 整体配色偏高级、复古、秋冬时装感。

## 光影

- 主图采用柔和受控人像光。
- 服装皮质反光是重要质感细节。
- 整体阴影克制，不追求强戏剧对比。
- 版面本身需保持柔和、平整，避免杂乱硬阴影影响拼贴质感。

## 空间复杂度

- **中等复杂度**。
- 真实空间少，版面层次多。
- 视觉信息丰富，但秩序清楚，适合品牌 lookbook 参考。
- 重点在“信息组织”，不在“场景叙事”。

## 情绪

- 编辑感、品牌感、复古、成熟、克制、高级。
- 偏内容种草和 lookbook，不偏促销。
- 适合强调“品牌品味”和“穿搭体系”。

## 适用主题

- 时装 lookbook、秋冬新品、品牌月刊、风格企划、搭配档案。
- 男装、女装、中性时装、复古品牌视觉。
- 适合做系列化页面。

## 禁用场景

- 不适合强折扣、强活动节点、强传播短效海报。
- 不适合需要一眼即懂的单主题爆款主视觉。
- 不适合过多花哨颜色和道具。
- 不适合节奏强烈的运动或青春题材。

## 可共享的视觉规则

1. 主图必须最大，辅图服务于主图而不是并列竞争。
2. 用拼贴方式补充穿搭细节和品牌故事。
3. 背景可以弱化，版面系统本身就是环境。
4. 小物件只需少量，重点在强化品牌语境。
5. 整体要像“编辑页”，而不是“素材堆叠页”。
