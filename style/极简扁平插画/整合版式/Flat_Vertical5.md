# 版式概述

竖向 3:4 画幅，主标题位于顶部中央，以两行粗头手绘字构成宽阔标题块。日期与短类别信息贴附在标题右上角，副标题置于标题正下方，整体构成紧凑的顶部信息区。画面下半部保留大面积连续主视觉区域，适合展品、人物、空间或叙事场景。主标题两侧的斜线或括号属于非文字装饰，不能自动写入内容。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中，略偏左。
- 区域坐标：[0.15, 0.06, 0.70, 0.35]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：7-13个中文字符，最多 16个中文字符。
- 字号与画布关系：单行字高约占画布高度的 13%-19%，两行总高约占 27%-35%，整体宽度约占画布宽度的 66%-70%。
- 字体类型：粗头手绘体、童趣展示体、略带毛边的文化活动标题字。
- 字形特征：笔画粗细轻微变化，转折圆润，字面大小不完全一致；可有手绘抖动和纸张颗粒，但必须清晰易读。
- 排列方式：两行紧凑堆叠，上行较宽，下行居中；局部图形化字腔可强化主题。
- 对齐方式：整体居中，内部允许轻微错位。
- 与其他信息的比例：主标题字号约为副标题的 2.5-3.2 倍，为右上时间的 2.8-3.8 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题正下方，单行横向短句。
- 区域坐标：[0.20, 0.39, 0.63, 0.08]
- 相对主标题字号：约为主标题字号的 28%-38%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：居中对齐，使用较规整的手写体或圆体。
- 缺失规则：删除标题下方短句，主视觉上边界上移约 0.03。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：标题右上侧，靠近上行右边缘。
- 区域坐标：[0.65, 0.07, 0.25, 0.08]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 24%-34%。
- 与主标题的关系：贴附标题上行右侧，但保持独立可读。
- 缺失规则：删除日期，右上角辅助信息可上移或保持原位。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：时间下方或标题右上侧，用于地点、类别、翻译或短说明。
- 区域坐标：[0.66, 0.13, 0.24, 0.09]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 16%-23%。
- 对齐关系：左对齐，形成小型信息块。
- 缺失规则：删除小型说明，时间保持单独存在；不自动生成外文。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：括号、斜线和图形化眼睛等只用于装饰主标题，不生成新的文字。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面下半部的大面积连续区域。
- 区域坐标：[0.06, 0.49, 0.88, 0.46]
- 区域形状：完整纵向矩形，从标题下方延伸至底边。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.70] 附近。
- 建议主体占比：单一展品或人物占画布面积的 30%-45%；空间或场景组合占 38%-56%。
- 与文字的避让关系：不得进入 y=0.46 以上顶部文字区；标题下方至少保留画布高度 0.03 的缓冲。
- 可否延伸至文字背后：低对比展墙、空间光影或纸张纹理可延伸至文字后方；清晰展品和人物面部不得进入。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部两行手绘主标题。
2. 第二视觉：标题右上的时间和辅助信息。
3. 第三视觉：标题下方副标题。
4. 主视觉主体与文字的观看关系：顶部信息读完后向下进入展品或场景主视觉，形成海报式导览顺序。

# 内容适配规则

## 主标题长度变化

- 短标题：4-6 个字时可放大为一至两行。
- 中等标题：7-13 个字时使用两行，为最优状态。
- 长标题：14-16 个字时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简，禁止压缩字宽或向下侵入主视觉。

## 信息缺失

- 无副标题时：主视觉上移，顶部信息组保持紧凑。
- 无活动时间时：辅助信息可上移至原时间位置。
- 无辅助信息时：仅保留标题和时间，右上角不补文案。
- 只有主标题时：主标题可置于 [0.14, 0.09, 0.72, 0.36]，略放大并居中。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：博物馆、展览、文化活动、儿童艺术、公共教育。
- 不适合：奢华时尚、硬核科技、复杂数据或长文说明。
- 推荐主题：博物馆、展览、文化故事、探索、亲子、公共艺术。
- 推荐信息量：低至中等信息量，核心模块 3-4 组。
- 推荐主体类型：展品、空间、人物参观、文化器物、插画场景。
