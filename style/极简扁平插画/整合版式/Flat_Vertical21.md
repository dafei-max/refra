# 版式概述

竖向画幅，采用“上部大字标题区 + 中部大面积主视觉留白区 + 底部信息分栏区”的结构。主标题位于上方，横跨大部分画面宽度，以强字形构成形成第一视觉；标题左右两侧各有一列细长辅助信息，起到边界框定和节奏补充作用。中部至下半部为大面积连续空白，是明确的主视觉生成区域。底部信息采用左右分栏：左下放时间，右下放副标题与说明信息。整体阅读顺序为上部主标题 → 两侧辅助信息 → 左下时间 → 右下副标题/说明 → 中部主视觉区域作为视觉承接。

# 文字视觉系统

## 主标题

- 位置：画面上部中央，略偏左展开，横向占据主要宽度。
- 区域坐标：`[0.08, 0.05, 0.80, 0.28]`
- 信息层级：最高层级。
- 建议行数：2 行优先，最多 3 行。
- 建议字数：4-10 字，最多不超过 14 字。
- 字号与画布关系：标题整体高度约占画布高度的 20%-28%，宽度约占画布宽度的 70%-82%。
- 字体类型：几何感强的无衬线标题字，可接受一定设计化变形。
- 字形特征：笔画粗细相对均一、轮廓干净、局部可有夸张比例或结构变化，整体强调图形化而非标准正文识别。
- 排列方式：以 2 行横向编排为主，单字大小可有轻微变化，但整体应组成完整块面。
- 对齐方式：整体左对齐或块面左对齐，保持上部稳定横向展开。
- 与其他信息的比例：显著大于时间、副标题和辅助信息；底部信息约为主标题字号的 18%-28%，侧边辅助信息约为主标题字号的 16%-22%。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：是
- 位置：画面右下区域，与时间形成底部分栏结构。
- 区域坐标：`[0.48, 0.84, 0.46, 0.10]`
- 相对主标题字号：约为主标题的 18%-28%。
- 建议行数：0-2 行。
- 对齐关系：右下区域内右对齐或局部右对齐优先，形成底部收口感。
- 缺失规则：删除后保留右下留白，不将时间模块移至中间。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：是
- 位置：左下角，独立成组，与右下副标题形成对角平衡。
- 区域坐标：`[0.04, 0.83, 0.14, 0.12]`
- 排列方向：纵向分行或紧凑双行排布。
- 相对主标题字号：约为主标题的 20%-30%。
- 与主标题的关系：作为底部信息锚点，补足左下视觉重量，不参与上部标题结构。
- 缺失规则：删除后左下保留空白，整体仍成立；不建议将右下副标题挪至左侧填补。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：是
- 位置：主标题左侧与右侧边缘，各有一组窄列辅助信息。
- 区域坐标：`[0.03, 0.05, 0.08, 0.24]`、`[0.86, 0.04, 0.09, 0.24]`
- 建议行数：1-5 行，适合短词、短标识或系列名。
- 相对主标题字号：约为主标题的 16%-22%。
- 对齐关系：竖向排列或窄列排布，贴边放置，用于框定标题区边界。
- 缺失规则：可整体删除左右辅助信息；删除后主标题位置不变，仅增强极简感。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：两侧细长信息更多承担边框式节奏与补充识别作用，而非核心阅读内容。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：中部至下半部的大面积连续留白区域，是本版式的主视觉生成区。
- 区域坐标：`[0.00, 0.33, 1.00, 0.67]`
- 区域形状：完整纵向矩形区域。
- 建议主体位置：主体宜放在中部偏下、中下居中或下半部局部，不可侵入上方标题区和底部信息区。
- 建议主体占比：主体建议占画布面积的 25%-45%，占主视觉区面积的 35%-60%。
- 与文字的避让关系：必须避开上部标题块、左右辅助信息列、左下时间和右下副标题区域。
- 可否延伸至文字背后：仅允许低对比背景纹理、渐变、模糊体积或弱装饰延伸，不可影响文字清晰度。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：上部大标题。
2. 第二视觉：标题左右两侧辅助信息。
3. 第三视觉：左下时间与右下副标题/说明信息。
4. 主视觉主体与文字的观看关系：用户先读取上部信息结构，再进入中部主视觉区，主视觉承担承接和扩展氛围的作用，不能压过标题。

# 内容适配规则

## 主标题长度变化

- 短标题：可放大字面并增加字间留白，维持上部块面的张力。
- 中等标题：最适合该版式，保持 2 行编排即可。
- 长标题：可拆为 3 行，但需维持整体横向块面，不可变成窄长竖排。
- 超出容量时：优先缩小字号并调整换行；若仍过长，应由用户精简内容，禁止压缩到底部信息区或侵占主视觉区。

## 信息缺失

- 无副标题时：右下留白保留，底部改为单侧时间锚点结构。
- 无活动时间时：左下留白保留，右下副标题可单独存在。
- 无辅助信息时：删除两侧窄列，主标题维持原位置与尺度。
- 只有主标题时：保留上部大标题与中下部主视觉区，形成极简高留白版式。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：电影感海报、活动招募海报、品牌 campaign KV、设计展视觉、文艺类宣传物料。
- 不适合：信息密集促销页、电商详情页、强功能导向的运营卡片。
- 推荐主题：艺术展映、品牌项目、创意企划、节日专题、文化活动。
- 推荐信息量：1 个主标题 + 0-2 组辅助信息 + 0-1 组时间 + 0-1 组副标题。
- 推荐主体类型：人物、单体产品、抽象装置、场景剪影、低密度图像主体。
