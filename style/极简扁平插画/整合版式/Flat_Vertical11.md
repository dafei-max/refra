# 版式概述

竖向 3:4 画幅，文字组集中在顶部约 40% 高度。主标题由粗粝中文、衬线英文和大号中文共同构成多行编辑式拼贴，标题周围可保留用户提供的小型栏目名称。右上角设置年份或阶段胶囊，主标题下方是一条横向副标题或活动机制条。画面下半部为主要主视觉区域，适合旅行人物、路线场景、城市或产品组合。

# 文字视觉系统

## 主标题

- 位置：画面顶部偏左，形成多行叠置标题组。
- 区域坐标：[0.12, 0.06, 0.65, 0.30]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-12个中文字符，最多 15个中文字符。
- 字号与画布关系：最大中文行字高约占画布高度的 11%-16%，标题组总高约占 25%-30%，整体宽度约占画布宽度的 60%-65%。
- 字体类型：像素粗粝黑体、复古印刷体、机械衬线英文与粗宋黑混排。
- 字形特征：中文笔画粗、边缘呈毛刺或低分辨率颗粒；英文可用打字机衬线体或粗衬线体。不同语义单元尺寸差异明显，但整体保持黑白编辑感。
- 排列方式：两至三行叠置，上方可放小栏目名，中间为主标题，下方可有横向英文或第二语义块。
- 对齐方式：以左侧边界为主，内部采用不齐边拼贴和局部重叠；不得让重叠影响阅读。
- 与其他信息的比例：主标题字号约为横向活动条的 1.8-2.5 倍，为年份胶囊的 2.0-2.8 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题下方，以一条横向活动条或机制说明呈现。
- 区域坐标：[0.11, 0.34, 0.70, 0.08]
- 相对主标题字号：约为主标题字号的 35%-48%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐，宽度可接近主标题组总宽度；可使用细框或编辑框线，但不复制软件选框效果。
- 缺失规则：删除横向活动条和专属框线，主视觉上边界上移约 0.03。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右上角，以年份、阶段或期次放入圆角胶囊。
- 区域坐标：[0.68, 0.06, 0.22, 0.08]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 34%-45%。
- 与主标题的关系：与主标题并列，作为右上角锚点。
- 缺失规则：删除胶囊和文字，右上区域保持普通留白。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题上方的小型栏目名、类别或组织信息。
- 区域坐标：[0.31, 0.04, 0.18, 0.06]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 14%-22%。
- 对齐关系：左对齐，位于主标题上缘，不超过标题组宽度的三分之一。
- 缺失规则：删除小栏目名，不自动生成编辑部、机构或英文。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：粗糙边缘、框线和胶囊仅作为排版元素；不得自动生成品牌、年份或涨粉机制。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面下半部的大面积连续区域。
- 区域坐标：[0.05, 0.45, 0.90, 0.50]
- 区域形状：完整纵向矩形，从顶部信息组下方延伸至底边。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.70] 附近。
- 建议主体占比：单人、行李或产品占画布面积的 30%-46%；旅行场景或多人组合占 40%-58%。
- 与文字的避让关系：不得进入 y=0.42 以上顶部文字区；标题下方至少保留画布高度 0.03 的缓冲。
- 可否延伸至文字背后：纸纹、路线线条、低对比城市背景可跨越全画面；人物和产品核心不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部粗粝编辑式主标题。
2. 第二视觉：右上年份胶囊与顶部小栏目名。
3. 第三视觉：标题下方横向副标题或活动条。
4. 主视觉主体与文字的观看关系：顶部信息读完后向下进入旅行或产品主视觉，形成上文下图结构。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可保留 2 行并放大。
- 中等标题：6-12 个字时使用 2-3 行拼贴，为最优状态。
- 长标题：13-15 个字时减少英文插入，字号缩小 8%-12%。
- 超出容量时：优先精简，禁止向下侵入主视觉或压缩字宽。

## 信息缺失

- 无副标题时：主视觉上移，主标题组保持顶部。
- 无活动时间时：删除右上胶囊，标题可向右扩展少量。
- 无辅助信息时：删除小栏目名，顶部留白保留。
- 只有主标题时：主标题可置于 [0.12, 0.08, 0.73, 0.32]，略放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：旅行计划、编辑专题、城市活动、内容招募、社群计划。
- 不适合：柔美婚礼、儿童卡通、复杂参数或正式公文。
- 推荐主题：旅行、编辑部、城市、路线、扶持计划、内容创作。
- 推荐信息量：中等信息量，核心模块 3-4 组。
- 推荐主体类型：旅行人物、城市、行李、地图、交通工具或编辑式静物。
