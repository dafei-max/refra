# 版式概述

横向 16:9 画幅，文字组位于画面左侧偏中位置。主标题以两行粗粝书写字构成宽阔、不规则的黑色块面，上行较短，下行横向延展。主标题下方设置两列信息：左列为活动时间，右列为地点、场地或其他辅助说明。两列信息顶部接近对齐，并共同形成标题下方的稳定底座。右侧约 39%-42% 的连续大留白为主要主视觉区域；画面左下及标题内部空隙属于普通留白，不适合放置主体核心。

# 文字视觉系统

## 主标题

- 位置：画面左侧中上部，整体垂直中心略高于画布中线。
- 区域坐标：[0.02, 0.22, 0.55, 0.37]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：7-13 个中文字符，最多 16 个中文字符。
- 字号与画布关系：单行字高约占画布高度的 14%-20%；两行总高约占 30%-37%；下行宽度可达到画布宽度的 50%-55%。
- 字体类型：粗粝毛笔体、手刻书写体、具有干笔和墨迹边缘的展示字。
- 字形特征：笔画长短不一、横画可明显外伸、字形有轻微摇摆与倾斜；边缘允许毛边和断笔，但字腔、偏旁和关键词必须清晰。
- 排列方式：两行自由堆叠。上行居中偏右，下行从左侧起排并横向拉长；局部字可上下穿插，但不发生实质遮挡。
- 对齐方式：不采用严格左齐或居中，依靠整体轮廓形成视觉平衡；下行作为主要横向基准。
- 与其他信息的比例：主标题字号约为时间主行的 2.4-3.2 倍，为地点辅助信息的 2.8-3.8 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：不支持独立副标题模块。
- 位置：无固定副标题区域。
- 区域坐标：无。
- 相对主标题字号：不适用。
- 建议行数：0 行。
- 对齐关系：短说明应放入主标题下方右列辅助信息，而不是新增一条副标题。
- 缺失规则：标题下方仅保留用户提供的时间和辅助信息，不自动填入口号。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：主标题下方左列。
- 区域坐标：[0.09, 0.64, 0.22, 0.15]
- 排列方向：上下 2 行；第一行日期范围，第二行具体时段或补充时间。
- 相对主标题字号：约为主标题字号的 26%-36%。
- 与主标题的关系：位于标题下方约 0.03-0.06 的间隔，左边界略内缩，不超过主标题下行宽度的中点。
- 缺失规则：无活动时间时，右列辅助信息向左移动至 x=0.10-0.12，形成单列信息块；不得保留空列。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题下方右列，适合地点、场地、报名方式或一条短说明。
- 区域坐标：[0.32, 0.62, 0.26, 0.16]
- 建议行数：1-3 行。
- 相对主标题字号：约为主标题字号的 22%-32%。
- 对齐关系：左对齐；与时间列顶部接近对齐。可在第一行前使用地点、时间或类别图标，但只有对应信息存在时才启用。
- 缺失规则：无辅助信息时，时间列可向右扩展至宽度 0.30，仍保持标题下方左侧布局；不新增图标或文字补位。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：参考图不依赖额外装饰文案；小型位置图标仅用于明确地点信息，不属于独立文字内容。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面右侧连续大面积区域。
- 区域坐标：[0.58, 0.05, 0.39, 0.90]
- 区域形状：纵向近矩形，从右上贯穿至右下；左边界与标题下行末端形成清晰分区。
- 建议主体位置：主体视觉中心建议位于 [0.77, 0.50] 附近。
- 建议主体占比：单一人物、摊主或产品占画布面积的 28%-42%；摊位、场景组合占 36%-52%。
- 与文字的避让关系：主体核心不得进入 x=0.57 左侧；标题末端、地点信息右侧需至少保留画布宽度 0.02-0.03 的缓冲。
- 可否延伸至文字背后：不允许清晰主体延伸；低对比背景材质、纸纹、光影和统一环境色可跨越全画面。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：左侧两行粗粝书写主标题。
2. 第二视觉：标题下方左列活动时间。
3. 第三视觉：标题下方右列地点或辅助信息。
4. 主视觉主体与文字的观看关系：左侧标题先吸引视线，再由下方双列信息完成阅读，最后进入右侧主视觉；主体可向左形成互动，但不跨越文字分界。

# 内容适配规则

## 主标题长度变化

- 短标题：4-6 个字时可分为 2 行并放大，上行 2-3 字、下行 2-4 字。
- 中等标题：7-13 个字时使用两行自由错位，为最优状态。
- 长标题：14-16 个字时使用 3 行，字号缩小 8%-12%，下行仍保持最长。
- 超出容量时：优先精简文案；禁止拉伸字宽、侵入右侧主视觉区或压迫下方双列信息。

## 信息缺失

- 无副标题时：本版式默认无独立副标题，不做补位。
- 无活动时间时：辅助信息左移并形成单列。
- 无辅助信息时：时间列适度扩宽，仍保持左对齐。
- 只有主标题时：主标题可放置于 [0.03, 0.28, 0.54, 0.39]，整体略下移并放大 5%-8%，下方留白保留。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：市集招募、艺术空间活动、手作活动、独立展览、线下聚会、文化发布。
- 不适合：科技感强、金融商务、复杂价格体系或需要严密网格的内容。
- 推荐主题：独立市集、手作、艺术、文化、创意社群、非标准商业活动。
- 推荐信息量：低至中等信息量，核心模块 2-4 组。
- 推荐主体类型：摊位、手作产品、艺术家、空间场景、静物组合或人物半身。
