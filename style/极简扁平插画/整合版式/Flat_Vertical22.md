# 版式概述

竖向画幅，采用“上部居中文字标题组 + 中下部大面积主视觉区”的结构。标题组集中在画面上方约三分之一范围内，以大字主标题为核心，右上嵌入时间与辅助信息，下方再接一行短副标题。标题主体外侧存在一对括号/斜线式装饰笔画，用于形成包裹感与视觉聚焦，但不构成独立信息模块。画面中下部至底部为连续大留白，是明确的主视觉生成区域。阅读顺序为：主标题 → 右上时间与辅助信息 → 下方副标题 → 中下部主视觉区域。

# 文字视觉系统

## 主标题

- 位置：画面上部中央，略偏上，形成紧凑居中的标题块。
- 区域坐标：`[0.13, 0.10, 0.66, 0.30]`
- 信息层级：最高层级。
- 建议行数：2 行优先，最多 3 行。
- 建议字数：4-10 字，最多不超过 14 字。
- 字号与画布关系：标题整体高度约占画布高度的 22%-30%，宽度约占画布宽度的 55%-68%。
- 字体类型：手写感或拟手绘无衬线标题字。
- 字形特征：粗笔触、边缘圆润或不规则、字内空间夸张、识别性强，具有轻松亲和的情绪表达。
- 排列方式：多行为主，整体形成近矩形块面；单字大小允许略有变化。
- 对齐方式：整体居中对齐。
- 与其他信息的比例：显著大于副标题、时间和辅助信息；时间与辅助信息约为主标题字号的 18%-26%，副标题约为主标题字号的 16%-22%。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：是
- 位置：主标题下方，居中横向排布，作为一句话补充说明。
- 区域坐标：`[0.17, 0.41, 0.62, 0.06]`
- 相对主标题字号：约为主标题的 16%-22%。
- 建议行数：0-2 行，单行优先。
- 对齐关系：与主标题整体居中对齐。
- 缺失规则：删除后保留主标题下方留白，不用其他模块补位。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：是
- 位置：主标题右上方，嵌入标题组顶部边缘附近。
- 区域坐标：`[0.64, 0.08, 0.21, 0.10]`
- 排列方向：横向多行或紧凑双行排布。
- 相对主标题字号：约为主标题的 18%-26%。
- 与主标题的关系：作为顶部补充信息，依附主标题存在，不应独立放大。
- 缺失规则：删除后辅助信息可单独保留在右上；主标题仍保持居中不移动。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：是
- 位置：时间模块下方或其邻近区域，位于标题组右上侧。
- 区域坐标：`[0.64, 0.15, 0.18, 0.08]`
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题的 14%-20%。
- 对齐关系：与时间模块左对齐或块面对齐，共同形成右上补充信息组。
- 缺失规则：删除后仅保留时间模块，不新增其他补白信息。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：参考图中的外侧斜线/括号式元素属于视觉装饰框架，用于包裹主标题、强化聚焦，不属于应自动继承的文字内容。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中下部至底部的大面积连续留白区域。
- 区域坐标：`[0.00, 0.38, 1.00, 0.62]`
- 区域形状：完整纵向矩形区域。
- 建议主体位置：主体宜位于中部偏下或下半部中心，作为对上方标题组的视觉承接。
- 建议主体占比：主体建议占画布面积的 25%-45%，占主视觉区面积的 40%-65%。
- 与文字的避让关系：主体必须避开上部标题块、右上时间辅助区和主标题下方副标题区。
- 可否延伸至文字背后：仅可使用低对比背景肌理、色块或弱装饰延伸，不可影响标题识别。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：上部居中的主标题块。
2. 第二视觉：主标题右上角的时间与辅助信息。
3. 第三视觉：主标题下方副标题。
4. 主视觉主体与文字的观看关系：先读上方完整信息组，再进入中下部主视觉；主视觉只能承接内容，不可压过标题组。

# 内容适配规则

## 主标题长度变化

- 短标题：可放大字面并拉大行间，维持居中标题块的体量感。
- 中等标题：最适合该版式，保持 2 行即可。
- 长标题：允许拆为 3 行，但需维持整体居中块面，避免过于细碎。
- 超出容量时：优先微调字号与换行；若仍过长，应由用户精简内容，禁止向右上信息区或下方副标题区挤压。

## 信息缺失

- 无副标题时：保留下方留白，标题组整体更紧凑。
- 无活动时间时：右上仅保留辅助信息或完全留白，主标题不偏移。
- 无辅助信息时：仅保留时间模块，仍锚定在右上。
- 只有主标题时：上部居中主标题可独立成立，下方主视觉区完整保留。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：展览活动海报、品牌主题视觉、文化活动 KV、童趣或生活方式类宣传、教育或博物主题传播。
- 不适合：强商务发布会、严肃政务海报、信息量过大的运营长图。
- 推荐主题：展览、亲子活动、文化项目、生活方式 campaign、温和品牌表达。
- 推荐信息量：1 个主标题 + 0-1 组时间 + 0-1 组辅助信息 + 0-1 组副标题。
- 推荐主体类型：插画、文创物件、静物组合、轻场景、抽象图形主体。
