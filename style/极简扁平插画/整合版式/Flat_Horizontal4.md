# 版式概述

横向 16:9 画幅，主文字组集中在左侧中部，使用两至三行不规则手写标题作为核心。活动时间与副标题分别置于标题下方，以两个独立圆角胶囊形成横向错位。画面左上、标题右上和下方可出现少量非文字手绘图形，用于建立轻松记录感，但不承担信息。右侧约 43% 的连续区域为主要主视觉生成区，左侧文字组周围的留白用于手写节奏和图形呼吸，不是主体区域。

# 文字视觉系统

## 主标题

- 位置：画面左侧中部，整体略微向右上或左下倾斜。
- 区域坐标：[0.07, 0.33, 0.43, 0.28]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-12 个中文字符，最多 14 个中文字符。
- 字号与画布关系：单行字高约占画布高度的 10%-14%，标题总高约占 22%-28%；总宽度约占画布宽度的 36%-43%。
- 字体类型：粗头马克笔手写体、童趣手绘展示体、略带不规则笔触的中文标题字。
- 字形特征：笔画粗细略有变化，字面大小不完全一致，基线可轻微波动；允许少量倾斜和旋转，但整体必须清晰可读。
- 排列方式：两至三行自由排布，行与行之间可轻微错位；不得形成过度拥挤的涂鸦团。
- 对齐方式：整体以左侧文字组视觉中心对齐，不使用严格栅格齐边。
- 与其他信息的比例：主标题字号约为副标题的 2.2-2.8 倍，为时间信息的 2.5-3.2 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题右下方，以横向圆角胶囊承载。
- 区域坐标：[0.27, 0.63, 0.27, 0.09]
- 相对主标题字号：约为主标题的 34%-44%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：胶囊整体略向右偏移，可带 3°-8° 轻微倾斜；文字在胶囊内部居中。
- 缺失规则：无副标题时，删除整个胶囊，不保留空底形；时间胶囊可向右移动约 0.04 以平衡标题。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：主标题下方偏左，与副标题胶囊形成左右错位。
- 区域坐标：[0.14, 0.60, 0.15, 0.08]
- 排列方向：横向单行，置于圆角胶囊或手绘底形中。
- 相对主标题字号：约为主标题的 28%-38%。
- 与主标题的关系：靠近主标题左下边缘，但不与主标题笔画相碰。
- 缺失规则：无活动时间时，删除时间胶囊；副标题可向左移动约 0.04-0.06。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：不支持。
- 位置：不设置固定辅助文字区。
- 区域坐标：无。
- 建议行数：0 行。
- 相对主标题字号：不适用。
- 对齐关系：不适用。
- 缺失规则：默认删除，不得用英文、口号、品牌或说明句填补手绘图形附近空位。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：参考图不依赖额外装饰文字；相机、箭头、波浪线等属于非文字手绘图形。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面右侧连续大面积区域。
- 区域坐标：[0.54, 0.06, 0.43, 0.87]
- 区域形状：纵向近矩形，右边缘开放，可延伸至画布边界。
- 建议主体位置：主体视觉中心建议位于 [0.75, 0.50] 附近。
- 建议主体占比：单人或产品主体占画布面积的 30%-45%；场景组合占 38%-54%。
- 与文字的避让关系：主体核心不得进入 x=0.53 左侧；如有软边植物、云雾或光影，可低对比延伸至 x=0.50。
- 可否延伸至文字背后：不建议。仅允许低对比、低细节背景元素轻微延伸。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：左侧两至三行手写主标题。
2. 第二视觉：标题下方的副标题胶囊。
3. 第三视觉：时间胶囊及周围非文字手绘图形。
4. 主视觉主体与文字的观看关系：先读取左侧手写信息，再向右进入主视觉；主视觉可带记录、旅行、户外或互动动作，但不得压迫左侧文字。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可放大并分两行错位排列。
- 中等标题：6-12 个字时优先两行或三行，为最优状态。
- 长标题：13-14 个字时拆为 3 行，并将字号缩小 8%-12%。
- 超出容量时：优先精简；禁止将文字横向拉长至右侧主视觉区，禁止通过极度压缩字距硬塞。

## 信息缺失

- 无副标题时：删除右侧胶囊，时间胶囊略向右补位。
- 无活动时间时：删除左侧时间胶囊，副标题胶囊略向左补位。
- 无辅助信息时：保持默认，不生成任何补充文字。
- 只有主标题时：主标题放置于 [0.08, 0.35, 0.42, 0.30]，可适度放大并维持自由手写构图。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：户外活动、旅行记录、社群征集、年轻人互动活动、校园活动、生活方式品牌。
- 不适合：高端奢华、严肃政务、密集参数、正式金融或法律信息。
- 推荐主题：露营、旅行、自然、手作、体验征集、打卡、摄影记录。
- 推荐信息量：低至中等信息量，核心模块 2-3 组。
- 推荐主体类型：人物互动、户外场景、相机、帐篷、产品体验或自然物件。
