# 版式概述

竖向 3:4 画幅，左上角是一组纵向时间信息塔，画面下半部由两行巨型中文主标题构成主要文字重心。小型外文或短辅助信息位于主标题左侧空隙，底部设置一条横向副标题。上半部右侧至中部是主要主视觉区域，主体应避让左上时间塔；主标题上方和左右的空白共同形成宽阔视觉舞台。

# 文字视觉系统

## 主标题

- 位置：画面中下部，横跨画布约四分之三宽度。
- 区域坐标：[0.13, 0.56, 0.74, 0.29]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-10个中文字符，最多 12个中文字符。
- 字号与画布关系：单行字高约占画布高度的 13%-18%，两行总高约占 25%-29%，标题宽度约占画布宽度的 70%-74%。
- 字体类型：高对比现代宋体、窄长展示宋体、细锐衬线中文字体。
- 字形特征：竖画修长、撇捺锐利、横细竖粗对比明显，字面高挑；局部可有尖角或切口，但不使用粗重圆体。
- 排列方式：两行错位排列，上行从左侧开始，下行向右偏移并略放大。
- 对齐方式：整体以画面中轴偏左为基准，内部左对齐与错位结合。
- 与其他信息的比例：主标题字号约为底部副标题的 3.2-4.2 倍，为左侧辅助外文的 3.0-4.0 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题下方靠近底部，形成横向收束。
- 区域坐标：[0.23, 0.87, 0.58, 0.07]
- 相对主标题字号：约为主标题字号的 21%-28%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：居中或轻微左对齐，使用细黑体、轻宋体或规整无衬线体。
- 缺失规则：删除底部短句，主标题可整体下移约 0.02，底部保持留白。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面左上角，以年份、日期范围、星期和时段形成纵向信息塔。
- 区域坐标：[0.07, 0.04, 0.18, 0.31]
- 排列方向：上下多层堆叠，数字大于说明文字，可使用竖线分隔。
- 相对主标题字号：主日期约为主标题字号的 30%-42%，下方说明约为 15%-22%。
- 与主标题的关系：与主标题分离，承担左上角锚点和时间说明。
- 缺失规则：删除左上时间塔，上部主视觉可扩展到左侧边缘。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题左侧或两行之间的空隙，用于短外文、类别或翻译。
- 区域坐标：[0.14, 0.70, 0.20, 0.13]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 18%-26%。
- 对齐关系：左对齐或居中，宽度短于主标题单行宽度的三分之一。
- 缺失规则：删除小型信息，不保留占位；两行主标题保持原有错位。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：小太阳、点线或极简符号只用于强调季节，不生成额外文案。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：上半部右侧至中部的大面积连续区域。
- 区域坐标：[0.28, 0.05, 0.67, 0.47]
- 区域形状：右上为主体核心区，中部可向左下延伸，但左上需避让时间塔。
- 建议主体位置：主体视觉中心建议位于 [0.61, 0.30] 附近。
- 建议主体占比：单人或产品占画布面积的 28%-44%；场景或多人组合占 36%-52%。
- 与文字的避让关系：不得进入左上 [0.05, 0.03, 0.22, 0.33] 时间区，也不得下压至 y=0.54 以下的标题区。
- 可否延伸至文字背后：背景渐变、天空、柔光可延伸至标题背后，但高对比主体不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：中下部两行巨型主标题。
2. 第二视觉：左上时间塔。
3. 第三视觉：主标题左侧辅助信息与底部副标题。
4. 主视觉主体与文字的观看关系：主体位于上半部，形成先看画面、再落向下方标题的阅读关系；不得压迫时间塔。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可放大为一至两行，扩大字间距。
- 中等标题：6-10 个字时两行错位，为最优状态。
- 长标题：11-12 个字时拆为 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简，禁止将标题上移覆盖主视觉或时间塔。

## 信息缺失

- 无副标题时：标题略下移，底部保留普通留白。
- 无活动时间时：主视觉扩展至左上，标题位置不变。
- 无辅助信息时：删除小型外文，主标题无需补齐空隙。
- 只有主标题时：主标题可置于 [0.12, 0.58, 0.76, 0.31]，略放大并保持两行。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：夏季主题、护肤、美妆、生活方式、品牌宣言、节日活动。
- 不适合：长篇信息、流程表、复杂参数或强复古主题。
- 推荐主题：夏日、自由、清爽、表达、生活方式。
- 推荐信息量：中低信息量，核心模块 3-4 组。
- 推荐主体类型：人物、护肤产品、夏日静物、天空、海边或轻盈场景。
