# 版式概述

竖向 3:4 画幅，顶部左侧可配置一个非文字主题图标，右侧为一行横向手绘主标题。标题下方设置两条错位的信息飘带，用于活动规则或参与说明。画面中部保留大面积连续主视觉区域，底部居中放置活动时间胶囊。除用户明确提供的规则文字外，不生成额外副标题或口号。

# 文字视觉系统

## 主标题

- 位置：画面顶部偏右，与左侧主题图标并列。
- 区域坐标：[0.22, 0.08, 0.72, 0.18]
- 信息层级：一级核心信息。
- 建议行数：优先 1 行，最多 2 行。
- 建议字数：8-14个中文字符，最多 18个中文字符。
- 字号与画布关系：单行字高约占画布高度的 9%-14%，标题宽度约占画布宽度的 68%-72%。
- 字体类型：圆润手绘体、活泼线性字、略带不规则基线的游园会标题字体。
- 字形特征：笔画粗细略有变化，转折圆润，字形高低不一；可加入花朵、草丛或点状图形，但不得影响识别。
- 排列方式：优先单行横排；过长时拆为两行并保持整体靠上。
- 对齐方式：左对齐或视觉居中于右侧标题区。
- 与其他信息的比例：主标题字号约为信息飘带文字的 2.2-3.0 倍，为底部时间的 2.6-3.4 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：不支持独立副标题模块。
- 位置：无固定副标题区域。
- 区域坐标：无。
- 相对主标题字号：不适用。
- 建议行数：0 行。
- 对齐关系：不适用。
- 缺失规则：保持主标题、信息飘带和时间的原有关系，不使用口号补位。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面底部居中，以描边胶囊承载。
- 区域坐标：[0.34, 0.89, 0.32, 0.06]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 27%-36%。
- 与主标题的关系：与顶部文字组分离，作为底部中心锚点。
- 缺失规则：删除时间和胶囊底形，主视觉向下扩展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题下方，以一至两条错位飘带承载活动规则、资格或参与说明。
- 区域坐标：[0.10, 0.28, 0.80, 0.10]
- 建议行数：优先 2 行，最多 3 行。
- 相对主标题字号：约为主标题字号的 30%-42%。
- 对齐关系：文字在飘带内部居中或左对齐；不同飘带可轻微错位。
- 缺失规则：删除全部飘带和底形，主视觉上边界上移至 y=0.29 左右。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：左侧主题图标、花朵、草地和星点用于童趣氛围，不自动生成活动权益、商户或用户说明。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部的大面积连续区域。
- 区域坐标：[0.05, 0.40, 0.90, 0.45]
- 区域形状：完整纵向矩形，从信息飘带下方延伸至底部时间上方。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.63] 附近。
- 建议主体占比：人物、摊位或产品占画布面积的 32%-48%；游园场景或多人组合占 40%-58%。
- 与文字的避让关系：主体不得进入 y=0.38 以上标题和飘带区，底部 y=0.87 以下避让时间胶囊。
- 可否延伸至文字背后：草地、渐变、天空或轻纹理可跨越全画面；高对比主体不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部手绘主标题。
2. 第二视觉：标题下方活动规则飘带。
3. 第三视觉：中部主视觉与底部活动时间。
4. 主视觉主体与文字的观看关系：顶部文字说明玩法，中部主体展示游园体验，底部时间完成行动指引。

# 内容适配规则

## 主标题长度变化

- 短标题：4-7 个字时可放大并与图标保持并列。
- 中等标题：8-14 个字时单行或两行，为最优状态。
- 长标题：15-18 个字时使用 2 行，字号缩小 8%-12%。
- 超出容量时：优先精简；禁止压缩字宽或覆盖左侧图标。

## 信息缺失

- 无副标题时：本版式默认无独立副标题，不做补位。
- 无活动时间时：删除底部胶囊，主视觉向下扩展。
- 无辅助信息时：删除飘带，主视觉向上扩展。
- 只有主标题时：主标题可置于 [0.14, 0.09, 0.78, 0.20]，图标可保留为非文字装饰。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：游园会、市集、亲子活动、线下体验、互动快闪。
- 不适合：高端奢华、严肃会议、复杂数据或正式公文。
- 推荐主题：游园、打卡、互动、春日、体验、社群。
- 推荐信息量：中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物、摊位、饮品、互动装置、游戏场景或商户组合。
