# 版式概述

竖向 3:4 画幅，顶部约三分之一由两行超大中文标题构成，标题字形带纤维、刺绣或缠线质感。小型英文或类别信息贴附在标题右上侧。画面中部至下部保留大面积连续主视觉区域，底部左侧放置日期，右侧放置两行副标题或主题说明，形成左右双端锚点。标题内部的颜色与纹理变化只用于层级，不代表必须沿用参考色。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中偏左，横跨约 84% 宽度。
- 区域坐标：[0.08, 0.06, 0.84, 0.28]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：8-14个中文字符，最多 16个中文字符。
- 字号与画布关系：单行字高约占画布高度的 11%-16%，两行总高约占 23%-28%，整体宽度约占画布宽度的 80%-84%。
- 字体类型：高挑现代宋体、线性展示字、带刺绣或缠线纹理的中文字体。
- 字形特征：笔画细长、粗细反差明显，边缘可呈线圈、纤维、绳线或针脚纹理；不同语义单元可用明度区分，但字形结构必须统一。
- 排列方式：两行横向排布，上行略窄，下行更宽；括注、数字或短词可嵌入左侧或中间。
- 对齐方式：整体居中偏左，行内采用视觉对齐，不要求严格齐边。
- 与其他信息的比例：主标题字号约为底部副标题的 2.8-3.6 倍，为日期的 3.0-4.0 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面右下角，以两行主题说明或行动短句出现。
- 区域坐标：[0.61, 0.89, 0.34, 0.08]
- 相对主标题字号：约为主标题字号的 22%-30%。
- 建议行数：优先 2 行，最多 3 行。
- 对齐关系：右对齐或左对齐均可，但整体靠右下；关键词可通过字重或明度强调。
- 缺失规则：删除右下说明，主视觉可向右下扩展；日期仍保留左下。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面左下角，单行日期范围。
- 区域坐标：[0.04, 0.91, 0.28, 0.07]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 24%-32%。
- 与主标题的关系：与顶部标题分离，作为左下角平衡锚点。
- 缺失规则：删除左下日期，主视觉可向左下延伸。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：标题右上侧，用于短英文、类别、期数或翻译。
- 区域坐标：[0.77, 0.12, 0.17, 0.12]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 18%-26%。
- 对齐关系：左对齐，贴附标题右缘，不超过标题上行高度。
- 缺失规则：删除小型信息，标题右侧保持普通留白。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：刺绣纹理、括号或短英文只服务于用户已提供内容，不自动新增类别词。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部至下部的大面积连续区域。
- 区域坐标：[0.05, 0.34, 0.90, 0.53]
- 区域形状：完整纵向矩形，底部因左右信息形成窄幅避让。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.61] 附近。
- 建议主体占比：单人、配饰或产品占画布面积的 30%-46%；场景或多人组合占 38%-55%。
- 与文字的避让关系：主体不得进入 y=0.32 以上标题区，底部 y=0.87 以下避让日期和副标题。
- 可否延伸至文字背后：低对比背景、纸张或纤维纹理可跨越全画面；高对比主体不得进入标题区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部两行超大主标题。
2. 第二视觉：标题右上小型辅助信息。
3. 第三视觉：底部左侧日期与右侧主题说明。
4. 主视觉主体与文字的观看关系：标题先建立主题，中部主体作为主要画面，底部信息完成收束。

# 内容适配规则

## 主标题长度变化

- 短标题：4-7 个字时可一至两行放大，并减少括注。
- 中等标题：8-14 个字时两行横排，为最优状态。
- 长标题：15-16 个字时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简；禁止侵入中部主视觉或压缩字体纹理。

## 信息缺失

- 无副标题时：主视觉向右下扩展。
- 无活动时间时：主视觉向左下扩展。
- 无辅助信息时：删除标题右上小字，保持标题主体不变。
- 只有主标题时：主标题可置于 [0.08, 0.08, 0.84, 0.30]，略放大并保持顶部重心。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：配饰、穿搭、春日焕新、品牌主题、时尚专题。
- 不适合：长正文、密集促销、复杂流程或严肃政务。
- 推荐主题：春日、绿色、穿搭、配饰、灵感、城市漫游。
- 推荐信息量：中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物穿搭、配饰产品、植物、城市街景或编辑式静物。
