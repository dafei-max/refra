# 版式概述

横向 16:9 画幅，主文字组集中在画面右侧中部。主标题使用两至三行大幅毛笔书法，字形纵横穿插，形成右侧强重心。主标题下方配置一条较规整的副标题，副标题下方或右侧可放置少量辅助信息。活动时间独立位于左上角，与主标题完全分离。画面左侧约 55%-60% 的大面积连续空白为主要主视觉区，适合人物、文化场景、器物或空间；主标题右侧边缘和下方的小空隙属于文字组内部留白，不用于放置主体。

# 文字视觉系统

## 主标题

- 位置：画面右侧中上部，整体重心位于 x=0.74 附近。
- 区域坐标：[0.57, 0.17, 0.36, 0.49]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：5-9 个中文字符，最多 12 个中文字符。
- 字号与画布关系：最大单字字高约占画布高度的 18%-27%；两行总高约占 39%-49%；标题整体宽度约占画布宽度的 31%-36%。
- 字体类型：狂草、行草、现代水墨书法体、带飞白的手写展示字。
- 字形特征：笔画粗细变化强烈，允许飞白、干笔、墨团和长收笔；部分笔画可纵向贯穿或横向外伸，但核心字形必须可识别。避免统一粗细的黑体和机械复制感。
- 排列方式：两行不规则堆叠，上行略宽或向左伸展，下行可向右下收束；允许局部穿插，但不遮挡关键字。
- 对齐方式：以右侧视觉中心为基准，自由居中与错位结合，不采用严格齐边。
- 与其他信息的比例：主标题字号约为副标题的 2.7-3.6 倍，为活动时间的 4.0-5.5 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题下方偏左，以一行规整文字形成稳定底座。
- 区域坐标：[0.64, 0.65, 0.28, 0.09]
- 相对主标题字号：约为主标题字号的 28%-38%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐或与主标题下方视觉宽度居中；建议使用较粗的现代无衬线体、宋黑混合体或简洁衬线体，与书法形成强弱对比。
- 缺失规则：无副标题时，主标题可整体下移约 0.02，辅助信息上移至副标题位置；如辅助信息也缺失，则保留主标题下方留白。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面左上角。
- 区域坐标：[0.03, 0.05, 0.20, 0.07]
- 排列方向：横向单行，日期范围或短时间段优先。
- 相对主标题字号：约为主标题字号的 17%-24%。
- 与主标题的关系：与右侧文字组分离，作为左上角轻量锚点，不能向右延伸至主标题区域。
- 缺失规则：无活动时间时删除左上模块，左侧主视觉可延伸至顶部安全边距。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：主标题下方和副标题周围，可包含 1-3 行短说明、类别、署名或来源信息。
- 区域坐标：[0.67, 0.68, 0.26, 0.14]
- 建议行数：1-3 行。
- 相对主标题字号：约为主标题字号的 12%-20%。
- 对齐关系：以左对齐为主，可与副标题左右边界建立关系；主标题旁的小标签仅在用户明确提供时启用。
- 缺失规则：无辅助信息时删除相关小字，不改变左侧主视觉边界；副标题保持原位。不得自动生成外文、署名或文化说明。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：主标题旁的小型外文、印章式标识及下方细小说明用于建立新中式编辑层级，不属于默认内容。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面左侧大面积连续区域。
- 区域坐标：[0.03, 0.11, 0.57, 0.81]
- 区域形状：纵向完整的近矩形区域，从左侧延伸至画面中部；左上角需避让时间模块。
- 建议主体位置：主体视觉中心建议位于 [0.31, 0.51] 附近。
- 建议主体占比：单人或器物主体占画布面积的 30%-46%；场景或多人组合占 40%-58%。
- 与文字的避让关系：主体核心不得进入 x=0.58 右侧；左上角时间周围保留画布宽度 0.02、高度 0.03 的缓冲。
- 可否延伸至文字背后：仅允许低对比水墨晕染、环境光影、纸张纹理或统一背景色轻微延伸至右侧，不允许人物面部、产品核心或高对比轮廓进入书法区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：右侧大幅书法主标题。
2. 第二视觉：主标题下方副标题。
3. 第三视觉：左上活动时间和副标题下方辅助信息。
4. 主视觉主体与文字的观看关系：右侧书法先形成文化气质，视线随后进入左侧主视觉，再由左上时间与右下小字完成信息闭环；主体可朝右或与书法笔势呼应，但不得遮挡文字。

# 内容适配规则

## 主标题长度变化

- 短标题：3-4 个字时可放大为 1-2 行，增加长笔画与留白。
- 中等标题：5-9 个字时使用 2 行，为最优状态。
- 长标题：10-12 个字时使用 3 行，整体缩小 10%-15%，减少复杂穿插。
- 超出容量时：优先精简；禁止压缩字宽或将书法扩展至左侧主视觉中心。

## 信息缺失

- 无副标题时：辅助信息上移，或保留主标题下方留白。
- 无活动时间时：删除左上时间，主视觉向上扩展。
- 无辅助信息时：删除所有小型文字与标签，不自动补充外文或署名。
- 只有主标题时：主标题可放置于 [0.59, 0.24, 0.35, 0.49]，略放大并维持右侧重心。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：传统文化、国风设计、书法展、文化品牌、艺术项目、非遗活动。
- 不适合：科技促销、儿童卡通、密集参数、价格导向活动。
- 推荐主题：新中式、传统文化、书法、东方美学、艺术展览、文化焕新。
- 推荐信息量：低至中等信息量，核心模块 2-4 组。
- 推荐主体类型：传统服饰人物、器物、建筑、书法场景、艺术装置或东方静物。
