# 扁平 KV 参考图不变项契约

有参考图时先分析、再写契约、最后生成。最多选择一张主版式参考，再按需增加一张字体关系参考和一张表面风格或配色参考；不要平均融合冲突版式。

```text
reference_contract:
  locked:
    frame_topology: <上中下 / 左右 / 叠压 / 中心辐射>
    visual_weights: <标题 : 主视觉 : 行动信息>
    alignment_axis: <左 / 中 / 右，以及共享边线或基线>
    reading_path: <第一落点 -> 第二落点 -> 行动落点>
    anchors: <标题、主体、日期/价格/CTA 的锚点>
    overlap_crop: <谁遮挡谁、哪些元素出血或裁切>
    negative_space: <必须保留的连续空白>
    type_relationship: <中英文、括号、标签、箭头、日期的关系>
    palette_relationship: <同色 / 相邻 / 互补及面积关系>
    surface_system: <描边、边缘、颗粒与深度规则>
  replaceable:
    <主体、商品、具体文案、颜色值、背景内容、道具、装饰等>
  forbidden_to_copy:
    <参考人物身份、商品结构、品牌、原文案、Logo、独特装饰>
```

## 判断顺序

1. 空间拓扑与 30:60:10 等价权重。
2. 主对齐轴、稳定锚点和间距节奏。
3. 阅读路径与标题、主体、行动信息的相对位置。
4. 穿插、遮挡、裁切和连续留白。
5. 文字关系：中英文错位、括号、标签、箭头、日期和价格的附着方式。
6. 色彩关系与表面系统：迁移逻辑，不默认复制精确色值或独特字形。

`locked` 锁定设计语法，不锁定内容；`replaceable` 必须真正替换。若用户只要求参考字体和版式，不得迁移人物、商品、颜色或品牌。

## 失败判断

- 只复制颜色与涂鸦感，版式回到居中插画：构图不变项未写清。
- 换了文案但保留参考品牌、人物或独特装饰：可变项没有真正替换。
- 多张参考互相打架：减少到一张主版式参考，其余只限定单一职责。
- 只写“参考排版”而没有轴线、权重、锚点和穿插：描述不可执行，必须改成位置与关系。
