# 扁平 KV 关系与抽象规则

需要确定身份预算、比例、环境压缩或结构性修正时读取。按高层级到低层级做判断，低层级不得破坏高层级。

## 优先级

1. 唯一主焦点及画布占比
2. 主体与陪体的咬合关系
3. 方向轴、比例跳跃和整体轮廓
4. 前后层级、遮挡和负空间
5. 环境承托与连续留白
6. 主题符号与装饰节点
7. 五官、纹理和内部细节

## 身份预算

| 对象类型 | 默认预算 | 优先保留 | 必须删除 |
| --- | ---: | --- | --- |
| 普通场景与自然环境 | 0–1 | 方向、层级、密度、冷暖分区 | 完整树、建筑、人群、真实光影 |
| 标志性建筑与独特主体 | 1–3 | 外轮廓、负空间、檐线、收分、拱洞、尖顶、层叠节奏 | 窗户、砖石、雕刻、栏杆花纹 |
| 有机群体 | 0–1 | 聚集、扩散、上升、重叠与疏密 | 单体内部图案、真实高光、完整边界 |
| 线性结构 | 0–1 | 方向轴、节奏、少量中断 | 栏杆构件、车道细节、岸线纹理 |
| 小型代表物 | 2–3 | 核心外形、功能标记、方向标记 | 内部结构、真实材质、金属高光 |
| 人物 | 1–2 | 姿态、服装大色块、发型或道具之一 | 写实五官、肌肉、关节、衣褶 |
| 动物 | 1–2 | 体块比例、耳鼻尾中的一个品种标记 | 毛发、解剖、爪趾、复杂花纹 |

预算用完即停止增加特征。不要因为画面空而增加身份细节；用主体占比、方向、间隔和留白重建平衡。

## 抽象执行顺序

1. 将 brief 中的对象分为主焦点、陪体、环境和装饰。
2. 为主焦点写出一个主轮廓和 2–3 条方向轴。
3. 把陪体放进主焦点形成的负空间，用压、靠、抱、夹、穿、遮、托建立关系。
4. 把环境翻译成 1–3 个大色块、轴线或密度区。
5. 为需要辨识的对象分配身份预算并逐项写明保留特征。
6. 删除不影响主题、情绪、方向和辨识的内部细节。
7. 最后才选择风格的边缘、颗粒、描边与浅层厚度。

## 推荐占比与比例节奏

- 主体组合通常占画面约 55%–80%。
- 最大色块可达到次大色块的 1.5–3 倍。
- 至少保留约 20%–40% 的连续干净留白；有文字版式时按标题区调整。
- 至少包含一次显著放大和一次收缩，例如：小头 → 大躯干 → 超长手臂 → 小道具。
- 不要平均夸张所有部分。若所有元素同尺寸、同圆度、同完整度，结果仍会普通。

## 人物与动物

- 用头部小块、躯干大块、夸张肢体和道具色块组合人物。
- 让关节断开、重叠、合并或省略；不用真实骨骼解释动作。
- 让动作至少形成两个不同方向；步幅、抬手、俯仰和扭转必须在缩略图中可见。
- 五官默认删除；确需情绪时只用点、短线或单一弧线。
- 把服装当成大色块和轮廓工具，不优先表现褶皱。
- 先把动物定义为一个颜色、一个大小、一个方向和一个关系动词，再补品种特征。
- 若人物与动物可分别完整裁出且不影响构图，说明仍是拼装式关系。

## 场景与对象翻译

| 原始内容 | 保留关系 | 扁平表达 |
| --- | --- | --- |
| 草地与山丘 | 底部承托、起伏方向 | 1–2 块不规则横向色带 |
| 天空与光影 | 上下明暗或冷暖分区 | 纯色背景或大面积几何切分 |
| 水面 | 横向层级、轻微波动 | 2–4 条宽窄不同的水平色带 |
| 树林与人群 | 密度、朝向、前后层级 | 重叠团块或短竖形节奏 |
| 街道与道路 | 消失方向、分流、速度 | 1–2 条斜轴或楔形色块 |
| 云、灯光与气球 | 聚集、扩散、上升 | 大小不等的重叠有机色块 |
| 小型符号物 | 外形、功能、方向 | 2–3 个平面标记 |

## 标志性主体

- 先判断只剩剪影时能否辨认；能辨认时只保留外轮廓。
- 剪影不足时，再增加一个代表性负空间或结构节奏。
- 仍不足时，最多再加一个檐线、尖顶、拱洞、开口或收分。
- 不用窗户数量、砖石纹理、斗拱、雕刻、按钮或机械结构补救辨识。
- 陪体只承担尺度、方向与场所感，不与标志性主体争夺身份预算。

## 参考图迁移

- 先迁移主体占比、方向轴、遮挡和留白，再迁移形状类别。
- 只迁移参考图的抽象方法和表面系统，不复制人物身份、商品、文案、品牌或完整布局。
- 参考图含文字时，分析文字组的位置、面积、对齐轴、层级和穿插关系；完整海报任务迁移这些文字语法，但不复制原文案、品牌或字形作品。
- 用户明确要求的线条、颗粒或深度规则优先于参考图中的弱线索。

## 常见失败与结构修正

| 失败 | 根因 | 结构性修正 |
| --- | --- | --- |
| 普通矢量人物 | 使用标准头身、正常关节和完整轮廓 | 指定比例跳跃、关节省略和远端点 |
| 动作没张力 | 手脚与道具仍靠近躯干 | 拉开 2–3 条方向轴并扩大整体轮廓 |
| 人物与陪体拼装 | 只写在旁边 | 嵌进负空间并增加接触、遮挡或穿插 |
| 环境碎 | brief 中每个名词都完整生成 | 合并为 1–3 个承托色块或方向轴 |
| 画面空 | 只做减法，没有结构 | 用主体占比、比例跳跃和负空间重建平衡 |
| 颗粒显脏 | 把噪点当通用滤镜 | 只在所选风格规定的位置使用颗粒 |
| 线条冲突 | 同时使用无描边、彩边和黑边 | 锁定主风格的单一边缘系统 |
| 装饰喧宾夺主 | 为丰富自动加元素 | 装饰默认 0，每个元素说明构图职责 |
