# 扁平五风格自动路由

需要生成扁平 KV、分析参考图风格或检索风格库时读取。目标是从五种稳定风格中选择一个主风格，并输出可供图库检索的 style_id。

## 决策输出

组装提示词前先形成内部记录：

    subject_type: person | animal | landmark | scene | object | organic-group | mixed
    style_mode: explicit | reference-led | inferred
    primary_style: 五种 style_id 之一
    secondary_style: style_id 或 none
    style_reason: 一句可执行理由
    outline_policy: none | colored-edge | rough-black-marker
    texture_policy: none | edge-grain | full-grain | line-jitter
    depth_policy: flat | overlap-only | shallow-layer
    reference_query: style_id + subject_type + 构图/情绪标签

最终提示词必须包含几何形状、边缘、颗粒、深度、色彩和专属负向词。不要只写一个风格名。

## 选择顺序

1. 用户明确指定风格、线条、颗粒、边缘或深度时直接锁定，不自动覆盖。
2. 用户明确要求参考某图时，以主视觉面积判断主风格，不被少量局部描边、渐变、文字或配件误导。
3. 用户未指定时，依次判断主体类型、叙事方式、信息组织、情绪和是否需要手绘线条或浅层厚度。
4. 多种风格都可行时，优先选择能强化主体轮廓、主题语义和阅读方式的风格。
5. 只选择一个主风格。辅助风格最多一个，只承担单一局部职责，不改变全图的描边、颗粒或深度系统。

## 快速路由

按顺序匹配最明确的线索：

1. 出现“粗黑手绘轮廓、马克笔、涂鸦、拙趣、知识解释、办公、健康、界面符号、拟人图标” → marker-outline-doodle
2. 出现“干净矢量、无颗粒、治愈、儿童、幻想、留白、圆角几何、轻盈” → clean-vector-whimsy
3. 出现“桌面、食物、商品、生活物件、胶版、砂纸颗粒、浅层叠压、纸片厚度” → layered-print-relief
4. 出现“贴纸、符号合集、花草、节气、情绪板、柔和毛边、喷绘颗粒、多个独立模块” → sticker-collage-grain
5. 出现“人物行动、旅行、节庆、城市生活、巨大步幅、硬朗几何块、粗粝版画边缘” → blocky-grain-geometric

没有明确风格线索时：

- 人物行动、旅行或动态场景优先 blocky-grain-geometric。
- 商品、食物或桌面物件优先 layered-print-relief。
- 自然符号合集优先 sticker-collage-grain。
- 治愈幻想与儿童叙事优先 clean-vector-whimsy。
- 知识、效率、健康、办公和拟人符号优先 marker-outline-doodle。

不要只凭颜色选择风格。高饱和不必然是贴纸，米白背景也不必然是粗黑涂鸦。

## 五种风格规则

### blocky-grain-geometric — 粗粝几何块面

- 适合：人物行动、旅行、节庆、城市生活和动态叙事。
- 造型：用矩形、梯形、楔形和硬朗不规则块拼接人物与景物；用巨大步幅、远端手脚和不对称重心制造动势。
- 轮廓：默认无统一描边，依靠相邻色块边界建立形体。
- 色彩：3–5 个高饱和撞色，大面积平涂，色阶有限。
- 肌理：干刷毛边与轻至中度颗粒进入边缘和色块内部。
- 深度：纯平面或仅靠遮挡，不使用渐变阴影。
- 提示词核心：使用硬朗不规则块拼接主体，通过比例跳跃与多方向轴形成现代版画式动作；无统一描边，以粗粝边缘和有限撞色建立结构。
- 避免：标准矢量人物、正常关节、完整叶片、写实五官、光滑塑料硬边。

### sticker-collage-grain — 毛边贴纸拼贴

- 适合：春日、节气、自然主题、主题符号合集和多个意象并置。
- 造型：每个元素成为独立贴纸单元；主体贴纸最大，陪体按大小和间隔形成节奏。
- 轮廓：彩色毛边、噪点描边或底色衬边，不使用黑色统一勾线。
- 色彩：明亮浅底配高饱和贴纸色块；每个单元内部仍保持有限色彩。
- 肌理：边缘蓬松、喷绘或粉蜡笔噪点，可少量使用柔和斑驳。
- 深度：贴纸叠压，不画真实投影和立体厚度。
- 提示词核心：把主体与陪体组织为大小不同的独立贴纸模块，以彩色毛边、柔和喷绘颗粒和叠压建立节奏；每个模块都承担主题、连接或平衡职责。
- 避免：完整场景叙事、每个对象写实、厚重黑边、所有贴纸同尺寸、渐变塑料感。

### layered-print-relief — 浅层叠压胶版

- 适合：食物、餐具、商品、桌面物件、秋日和生活方式主题。
- 造型：用几何块面分层模拟物件，通过上层色块、窄侧面和轻微错位表达浅浅厚度。
- 轮廓：默认无黑色描边，局部通过深色侧面或邻接色区分。
- 色彩：暖色或主题色主导，3–5 个大色系，不追求真实固有色。
- 肌理：全图统一细腻砂纸、胶版或颗粒笔刷质感，边缘略粗糙。
- 深度：只允许浅层叠压、窄斜面和轻微投影色块。
- 提示词核心：用几何色块和轻微错位模拟胶版物件，以窄侧面、浅层叠压和统一细颗粒表现纸片厚度；保持有限色系，不追求真实材质与光泽。
- 避免：3D 渲染、厚重挤出、金属高光、真实食物纹理、摄影级阴影。

### clean-vector-whimsy — 清爽极简幻想矢量

- 适合：松弛、治愈、儿童、幻想、放空和轻量品牌叙事。
- 造型：用圆形、圆角矩形和干净几何块拼接；人物、云、树和设施可轻量拟人。
- 轮廓：光滑矢量边缘，仅少量细彩线或表情短线，不使用粗黑描边。
- 色彩：明亮清爽，3–5 个纯色，保留较大背景留白。
- 肌理：无颗粒、无纸纹、无毛边。
- 深度：纯平面，以色块叠压区分前后，不使用阴影。
- 提示词核心：使用圆形、圆角矩形和干净几何块拼接人物与环境；保持大面积留白、光滑边缘和纯平面叠压，允许现实逻辑轻微失效。
- 避免：砂纸噪点、马克笔抖线、写实人物、复杂场景、过多装饰。

### marker-outline-doodle — 粗黑马克笔涂鸦

- 适合：效率、健康、工作、情绪、知识解释、轻松社交和拟人符号。
- 造型：用不规则圆块、粗壮肢体和拟人图标组织平面拼贴。
- 轮廓：全图使用粗犷不均匀黑色外轮廓，保持粗细变化和手绘抖动。
- 色彩：内部纯色平涂，无渐变，黑边承担统一结构。
- 肌理：只来自线条自身的抖动、断续与压力变化，不额外覆盖颗粒滤镜。
- 深度：依靠轮廓交叠和色块遮挡，无真实透视与阴影。
- 提示词核心：使用粗犷不均匀的黑色马克笔轮廓和不规则圆块造型；颜色纯平涂，质感仅来自线条抖动、断续和压力变化。
- 避免：均匀描边、光滑贝塞尔曲线、砂纸噪点、写实比例、材质高光。

## 混合规则

- 主风格控制 80%–100% 的视觉语法。
- blocky-grain-geometric 与 layered-print-relief 可共享颗粒，但只能选择一种深度系统。
- sticker-collage-grain 可借用其他风格的单个符号造型，但所有单元必须统一为贴纸边缘。
- clean-vector-whimsy 不与任何颗粒或粗黑描边系统混用。
- marker-outline-doodle 不叠加砂纸颗粒；若需要背景纸感，只允许极弱底色变化，不能覆盖线条。
- 不在同一画面同时使用无描边、彩色毛边和粗黑描边。
- 辅助风格不得决定同一主体的完整表面，只能提供一个局部符号造型、构图模块或次要质感职责。
