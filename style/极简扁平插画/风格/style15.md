# 风格参考分析整理（style15）

## 1. 这张图具体能解决什么问题
这张图最能解决的是**“如何把功能型主题、产品卖点或服务信息，包装成高亲和、高识别、低年龄门槛的角色化插画画面”**的问题。

它具体解决的点包括：
- 能解决“功能信息太硬、太像说明书”的问题，通过把角色放进画面中心，把周边功能模块转成图标卡片，让信息看起来更像一个有趣的场景。
- 能解决“儿童 / 家庭 / 轻服务类内容缺乏记忆点”的问题，因为中心角色非常强，容易形成品牌识别。
- 能解决“多功能点并列时没有主次”的问题，这张图通过中央大角色 + 四周模块化信息块，建立了非常清楚的视觉主次关系。
- 能解决“画面既要有可爱感，又要保留一定功能说明属性”的问题。
- 能解决“如何把服务、课程、儿童产品、出行工具等主题，做成轻广告化、轻UI化的插画风格”的问题。

整体来看，它更适合做**儿童友好型服务插图、品牌辅助视觉、功能卖点页、活动海报、产品介绍模块图**。

## 2. 建议补充的信息
为了让这类风格参考更适合进入设计规范或提示词系统，建议补充以下信息：

### 媒介
- 是更偏**品牌插画 / 广告KV插画 / 页面功能插图**，还是可延展到贴纸和包装？
- 是否主要用于APP活动页、宣传页、海报、物料延展？

### 造型语言
- 是否固定为**中心大角色 + 四周功能图标块**的构图？
- 角色是否必须保持幼态、圆润、简化五官和大轮廓造型？
- 周边信息模块是偏图标化，还是可以加入更完整小场景？

### 色彩逻辑
- 是否固定为**高纯度但低压迫的红黄蓝绿糖果色系统**？
- 是否要求白底或浅暖底衬托高饱和主体？
- 是否允许更多渐变和层次，还是保持纯色色块优先？

### 材质
- 是否保持**纯平面数字插画**，还是允许轻微纸感 / 丝网印刷感 / 颗粒感？
- 线条是否必须是均匀描边，还是允许更明显的手绘抖动？

### 光影
- 是否明确为**弱光影 / 基本无真实体积塑造**？
- 是否只通过色块叠压和少量局部阴影建立层次？

### 空间复杂度
- 是否保持**低到中等空间复杂度**，即中央单主体 + 模块化外围信息？
- 信息图标数量是否有上限，避免外围过满？
- 是否允许背景增加更多纹理和装饰线？

### 情绪
- 更偏**可爱、活力、儿童友好、服务亲和、轻教育**，还是偏活泼促销感？
- 是否允许更潮流、更街头或更品牌化的版本？

### 适用主题
- 儿童产品、家庭服务、教育活动、品牌功能介绍、亲子出行、安全教育、轻科普是否适用？
- 是否适合作为UI插图或启动页视觉？

### 禁用场景
- 不适合严肃金融、专业医疗、法律、政务、公文型传播。
- 不适合需要真实质感、复杂透视或高级时尚感的项目。
- 不适合重文本、高信息密度、专业图表型内容。

## 3. 一句话总结
这张图主要解决的是**如何把功能信息或服务卖点转译为可爱、易懂、角色驱动的插画传播画面**，特别适合用于**儿童友好型产品、品牌活动页、功能介绍和轻广告视觉**。
