# 版式概述

横向 16:9 画幅，左侧约一半区域使用超大、超粗、紧凑的几何黑体构成垂直信息塔。时间模块位于最上方，主标题占据中部最大面积，底部为短副标题与小型辅助信息并排。所有核心文字以左边界为主要锚点，形成强烈、直接、现代的招聘或发布视觉。右侧约 43% 的连续空白为主视觉区域，可承载人物、产品或抽象图形；文字区域内部不预留主体穿插空间。

# 文字视觉系统

## 主标题

- 位置：画面左侧中部，位于大型时间模块下方。
- 区域坐标：[0.04, 0.29, 0.50, 0.43]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：4-8 个中文字符，最多 10 个中文字符。
- 字号与画布关系：单行字高约占画布高度的 15%-20%，两行总高约占 33%-43%；标题宽度可达到画布宽度的 46%-50%。
- 字体类型：超粗几何黑体、压缩型展示黑体、具有模块化结构的现代中文标题字。
- 字形特征：笔画极粗、字腔紧、横竖结构方正，可有切角、方形负形或局部几何改造；字面必须稳定，不使用纤细或书法字体。
- 排列方式：上下紧密堆叠，行距偏小；每行长度可不同，但左边界基本统一。
- 对齐方式：严格左对齐，必要时通过末端字形宽度形成块面。
- 与其他信息的比例：主标题字号约为底部副标题的 2.2-2.8 倍，为辅助信息的 3.0-4.0 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题下方左侧，以短句或状态标签形式出现。
- 区域坐标：[0.04, 0.74, 0.24, 0.13]
- 相对主标题字号：约为主标题的 36%-46%。
- 建议行数：1 行。
- 对齐关系：与时间和主标题共用左边界；可使用括号、方框或短线作为结构符号，但仅包裹用户实际提供的内容。
- 缺失规则：无副标题时，辅助信息左移至 x=0.04；若辅助信息也缺失，则主标题可下延约 0.06。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：文字组顶部，作为大号数字或年份模块。
- 区域坐标：[0.04, 0.12, 0.25, 0.16]
- 排列方向：横向单行；可为年份、日期、期数或短数字信息。
- 相对主标题字号：约为主标题单行字号的 70%-90%，字重与主标题一致。
- 与主标题的关系：与主标题严格左对齐，间距约为画布高度的 0.03-0.06。
- 缺失规则：无活动时间时，主标题整体上移至 y=0.15-0.18，并可适度放大 5%-8%。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：底部副标题右侧，构成横向信息条。
- 区域坐标：[0.28, 0.76, 0.19, 0.11]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题的 22%-30%。
- 对齐关系：与副标题垂直居中或顶部对齐，左边界从副标题右侧自然接续。
- 缺失规则：无辅助信息时，副标题可扩展至宽度 0.36；禁止用自动生成的英文或说明填补。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：底部小型外文仅用于补充信息层级和横向平衡，不属于固定装饰内容。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面右侧连续大面积区域。
- 区域坐标：[0.54, 0.05, 0.43, 0.90]
- 区域形状：完整竖向矩形，边界清晰，适合单一大主体。
- 建议主体位置：主体视觉中心建议位于 [0.76, 0.50] 附近。
- 建议主体占比：人物或产品主体占画布面积的 32%-48%；抽象图形或场景可占 40%-58%。
- 与文字的避让关系：主体左边缘不得越过 x=0.53；高对比轮廓与文字区之间至少保留画布宽度 0.03 的缓冲。
- 可否延伸至文字背后：不允许清晰主体延伸；背景渐变、低对比光影或统一纹理可跨越全画面。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：左侧中部超大主标题。
2. 第二视觉：顶部大号时间或数字模块。
3. 第三视觉：底部副标题与辅助信息。
4. 主视觉主体与文字的观看关系：左侧文字形成强势入口，右侧主体作为同等级视觉重心；两者以清晰分区并列，不发生遮挡。

# 内容适配规则

## 主标题长度变化

- 短标题：2-4 个字时放大并分为 1-2 行，确保块面宽度达到文字区的 60%-85%。
- 中等标题：5-8 个字时优先拆为 2 行，为最优状态。
- 长标题：9-10 个字时拆为 3 行，并缩小字号 8%-12%。
- 超出容量时：优先精简；不得横向侵入右侧主视觉区，不得压缩字宽超过 5%。

## 信息缺失

- 无副标题时：辅助信息左移，形成单一底部信息块。
- 无活动时间时：主标题整体上移并适度放大。
- 无辅助信息时：副标题可向右扩展，但仍保持单行。
- 只有主标题时：主标题放置于 [0.04, 0.20, 0.49, 0.55]，可使用两至三行超大黑体形成稳定块面。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：招聘、品牌发布、项目启动、校园活动、赛事招募、科技或潮流活动。
- 不适合：柔美婚礼、古典文化、儿童手绘、需要大量长正文的项目。
- 推荐主题：现代、年轻、直接、校园、科技、运动、人才招募。
- 推荐信息量：低至中等信息量，核心模块 3-4 组。
- 推荐主体类型：单人全身、多人组合、产品、几何装置或高对比抽象图形。
