# 版式概述

竖向 3:4 画幅，顶部由两行超大模块化中文标题构成，第一行包含一个超大关键词和若干小字，第二行是更宽的主语义块。小型外文或翻译位于标题左侧空隙。画面中部至下部为主要主视觉区域；底部左侧放置副标题，右侧放置活动时间。标题采用高度结构化的块面字形，文字区与主体区边界清晰。

# 文字视觉系统

## 主标题

- 位置：画面顶部，横跨接近整幅宽度。
- 区域坐标：[0.06, 0.05, 0.88, 0.24]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-12个中文字符，最多 15个中文字符。
- 字号与画布关系：最大字高约占画布高度的 14%-20%，两行总高约占 20%-24%；标题宽度约占画布宽度的 84%-88%。
- 字体类型：模块化几何黑体、像素化展示字、具有切角和拼块结构的中文字体。
- 字形特征：笔画粗、字腔方正、结构具有几何切角和模块拼接感；大小字可并置，但整体保持统一网格逻辑。
- 排列方式：两行横向组合，上行由大字与小字并列，下行使用更宽的超大字块；两行左边界接近。
- 对齐方式：整体左对齐，局部小字按主标题上缘或中线对齐。
- 与其他信息的比例：主标题字号约为底部副标题的 3.5-4.5 倍，为时间的 3.2-4.2 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面左下角，一条自然主题短句。
- 区域坐标：[0.05, 0.91, 0.58, 0.05]
- 相对主标题字号：约为主标题字号的 20%-28%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：左对齐，使用规整粗体无衬线或与标题呼应的简化字体。
- 缺失规则：删除左下短句，主视觉向左下扩展。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右下角，横向日期范围。
- 区域坐标：[0.72, 0.91, 0.24, 0.05]
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 20%-28%。
- 与主标题的关系：与顶部标题分离，作为右下角锚点。
- 缺失规则：删除右下时间，主视觉向右下扩展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：标题左侧或第一行下方的空隙，用于短英文、翻译或类别。
- 区域坐标：[0.06, 0.20, 0.19, 0.07]
- 建议行数：1-2 行。
- 相对主标题字号：约为主标题字号的 18%-25%。
- 对齐关系：左对齐，宽度短于标题总宽度的四分之一。
- 缺失规则：删除小型辅助信息，不自动生成英文。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：字形切角和模块负形属于字体结构，不代表额外装饰文案。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部至下部的大面积连续区域。
- 区域坐标：[0.05, 0.33, 0.90, 0.54]
- 区域形状：完整纵向矩形，底部因双端信息形成窄幅避让。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.61] 附近。
- 建议主体占比：人物、户外产品或植物占画布面积的 30%-46%；自然场景或多人组合占 40%-58%。
- 与文字的避让关系：主体不得进入 y=0.31 以上标题区；底部 y=0.88 以下需避让副标题和时间。
- 可否延伸至文字背后：天空、森林、渐变或低对比纹理可跨越全画面；人物面部和产品核心不得进入标题区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部两行模块化主标题。
2. 第二视觉：标题左侧辅助信息。
3. 第三视觉：底部副标题与活动时间。
4. 主视觉主体与文字的观看关系：标题先建立强传播主题，中部主体展开自然场景，底部信息收束。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可使用一至两行并放大。
- 中等标题：6-12 个字时两行组合，为最优状态。
- 长标题：13-15 个字时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简；禁止侵入主视觉或压缩模块字形。

## 信息缺失

- 无副标题时：主视觉向左下扩展。
- 无活动时间时：主视觉向右下扩展。
- 无辅助信息时：删除外文，不改变标题结构。
- 只有主标题时：主标题可置于 [0.05, 0.08, 0.90, 0.25]，略放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：自然、户外、露营、环保、运动生活方式、品牌季节主题。
- 不适合：古典书法、柔美浪漫、复杂促销或长正文。
- 推荐主题：自然、户外、治愈、露营、野趣、环保。
- 推荐信息量：低至中等信息量，核心模块 3-4 组。
- 推荐主体类型：人物、山野、植物、户外装备、露营或自然产品。
