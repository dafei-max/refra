# 版式概述

竖向 3:4 画幅，顶部由两行粗头手写主标题组成，标题笔画之间点缀少量彩色短线和圆点。主标题下方可放置一条阶段日期。画面中部保留大面积连续主视觉区域；底部居中放置副标题及主活动时间。若用户只提供一个时间段，默认使用底部主时间，标题下方日期模块关闭。

# 文字视觉系统

## 主标题

- 位置：画面顶部居中，略偏左。
- 区域坐标：[0.08, 0.08, 0.84, 0.28]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：7-13个中文字符，最多 16个中文字符。
- 字号与画布关系：单行字高约占画布高度的 11%-17%，两行总高约占 23%-28%；标题宽度约占画布宽度的 80%-84%。
- 字体类型：粗头马克笔手写体、圆润手绘展示字、带轻微毛边的治愈主题字体。
- 字形特征：笔画粗厚、转折圆润、字形大小略有变化；彩色短线和点状元素只作为非文字点缀。
- 排列方式：两行紧凑堆叠，上行较宽，下行居中或稍向右；字间可嵌入少量彩色装饰。
- 对齐方式：整体居中，内部自由错位。
- 与其他信息的比例：主标题字号约为底部副标题的 3.0-4.0 倍，为时间的 3.2-4.2 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：画面底部居中，一条治愈或生活方式短句。
- 区域坐标：[0.23, 0.89, 0.54, 0.05]
- 相对主标题字号：约为主标题字号的 20%-28%。
- 建议行数：优先 1 行，最多 2 行。
- 对齐关系：居中对齐，使用较规整的手写体或圆体。
- 缺失规则：删除底部短句，主时间上移至 y=0.91 左右。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：主时间位于底部副标题下方；可选阶段时间位于主标题下方。
- 区域坐标：底部主时间 [0.37, 0.93, 0.26, 0.04]；可选标题下时间 [0.44, 0.32, 0.28, 0.05]。
- 排列方向：横向单行。
- 相对主标题字号：约为主标题字号的 18%-27%。
- 与主标题的关系：底部时间作为正式行动信息；标题下时间只在用户提供独立预热或阶段周期时启用。
- 缺失规则：删除全部时间模块，不保留连接符或空标签。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：不支持。
- 位置：不设置固定辅助信息区。
- 区域坐标：无。
- 建议行数：0 行。
- 相对主标题字号：不适用。
- 对齐关系：不适用。
- 缺失规则：默认删除，不使用外文、品牌或徽章补位。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：彩色圆点、短线和小块面用于增加治愈感，不自动生成文字。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部至下部的大面积连续区域。
- 区域坐标：[0.05, 0.39, 0.90, 0.46]
- 区域形状：完整纵向矩形，底部因居中信息形成窄幅避让。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.63] 附近。
- 建议主体占比：人物、产品或宠物占画布面积的 30%-46%；生活场景或多人组合占 38%-55%。
- 与文字的避让关系：主体不得进入 y=0.37 以上标题和阶段时间区，底部 y=0.87 以下需避让副标题和主时间。
- 可否延伸至文字背后：低对比家居、光影、纸纹或渐变可跨越全画面；人物面部不得进入文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部彩点手写主标题。
2. 第二视觉：标题下方可选阶段时间。
3. 第三视觉：中部主视觉与底部副标题、主时间。
4. 主视觉主体与文字的观看关系：顶部标题建立温暖主题，中部主体承载生活故事，底部信息完成收束。

# 内容适配规则

## 主标题长度变化

- 短标题：4-6 个字时可使用一至两行并放大。
- 中等标题：7-13 个字时两行堆叠，为最优状态。
- 长标题：14-16 个字时使用 3 行，字号缩小 8%-12%。
- 超出容量时：优先精简；禁止向下侵入主视觉。

## 信息缺失

- 无副标题时：主时间上移并保持居中。
- 无活动时间时：删除顶部和底部全部时间。
- 无辅助信息时：本版式默认无辅助信息，不做补位。
- 只有主标题时：主标题可置于 [0.08, 0.11, 0.84, 0.29]，略放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：治愈主题、生活方式、家居、宠物、亲子、情感活动。
- 不适合：科技、金融、赛车、复杂数据或正式公文。
- 推荐主题：治愈、热爱、陪伴、日常、温暖、收藏。
- 推荐信息量：低至中等信息量，核心模块 2-4 组。
- 推荐主体类型：人物、家居、宠物、收藏品、手作、食物或温暖生活场景。
