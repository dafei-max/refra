# 版式概述

竖向画幅，整体采用极简的“顶部标题区 + 大面积下方主视觉区”结构。主标题位于上方偏中位置，横向展开，形成唯一强信息焦点；副标题位于主标题下方，体量显著减小并保持居中。除这两组文字外，画面没有独立时间或辅助信息模块。上方文字区占比很小，下方大面积连续留白是明确的主视觉生成区域，用于承载产品、场景或抽象视觉内容。阅读顺序为：主标题 → 副标题 → 下方主视觉。

# 文字视觉系统

## 主标题

- 位置：画面上部居中，略高于视觉中心。
- 区域坐标：`[0.08, 0.14, 0.84, 0.12]`
- 信息层级：最高层级，也是唯一核心文字焦点。
- 建议行数：1 行优先，最多 2 行。
- 建议字数：6-14 字，最多不超过 18 字。
- 字号与画布关系：标题整体高度约占画布高度的 8%-12%，宽度约占画布宽度的 65%-84%。
- 字体类型：书写感强的标题字、行书感字体或高识别手写风格字形。
- 字形特征：笔画具有明显粗细变化、舒展长尾、节奏流动，整体强调横向延展和书写气息。
- 排列方式：横向单行优先；若换行为 2 行，需保持整体居中并维持书写连贯感。
- 对齐方式：居中对齐。
- 与其他信息的比例：主标题显著大于副标题；副标题约为主标题字号的 22%-32%。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：是
- 位置：主标题正下方，居中排布，与主标题形成单轴结构。
- 区域坐标：`[0.33, 0.29, 0.34, 0.05]`
- 相对主标题字号：约为主标题的 22%-32%。
- 建议行数：1 行优先，最多 2 行。
- 对齐关系：与主标题中心轴严格对齐。
- 缺失规则：删除后不补其他信息，直接扩大上下留白，保持极简结构。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：否
- 位置：本参考图中无独立活动时间模块。
- 区域坐标：`[0.00, 0.00, 0.00, 0.00]`
- 排列方向：不适用
- 相对主标题字号：不适用
- 与主标题的关系：如项目必须添加时间信息，建议并入副标题区域，不新增第三层级大模块。
- 缺失规则：默认不设置该模块。
- 颜色规则：若启用，应与主标题保持一致。

## 辅助信息

- 是否支持：否
- 位置：本参考图中无独立辅助信息模块。
- 区域坐标：`[0.00, 0.00, 0.00, 0.00]`
- 建议行数：不适用
- 相对主标题字号：不适用
- 对齐关系：不适用
- 缺失规则：默认不设置该模块。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：参考图未出现需继承的装饰文案，重点在于主标题书写气质与留白关系。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：主标题与副标题下方的大面积连续区域。
- 区域坐标：`[0.00, 0.24, 1.00, 0.76]`
- 区域形状：完整纵向矩形区域。
- 建议主体位置：主体宜位于中部偏下、下半部中心或下半部偏上，形成对上方标题的承接。
- 建议主体占比：主体建议占画布面积的 30%-55%，占主视觉区面积的 40%-72%。
- 与文字的避让关系：主体必须避开顶部主标题和副标题的居中文字区，不得上侵文字区。
- 可否延伸至文字背后：不建议。仅允许极低对比背景色面、纹理或柔和光影轻微延伸。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部居中主标题。
2. 第二视觉：主标题下方副标题。
3. 第三视觉：下方主视觉主体。
4. 主视觉主体与文字的观看关系：文字先建立主题识别，主视觉随后承接情绪和产品信息，二者应保持上下分区清晰。

# 内容适配规则

## 主标题长度变化

- 短标题：可适当放大字面并保留充足左右留白，维持高级感。
- 中等标题：最适合该版式，保持单行居中即可。
- 长标题：允许拆为 2 行，但应控制行宽接近，避免破坏横向舒展感。
- 超出容量时：优先缩小字号并控制为 2 行；若仍超出，应由用户精简文案，禁止压缩副标题或侵占主视觉区。

## 信息缺失

- 无副标题时：保留主标题单独居中，下方留白增大，版式更极简。
- 无活动时间时：无需补位，本版式默认无独立时间模块。
- 无辅助信息时：无需补位，本版式默认无独立辅助信息模块。
- 只有主标题时：完全成立，可直接作为极简主 KV 使用。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：产品海报、礼盒或节令主题 KV、品牌主题视觉、东方气质宣传图、简洁型 campaign 主图。
- 不适合：大型活动信息海报、需展示多模块信息的促销海报、强数据说明型版面。
- 推荐主题：节令礼盒、自然健康、生活方式、品牌礼赠、雅致产品传播。
- 推荐信息量：1 个主标题 + 0-1 个副标题。
- 推荐主体类型：产品单体、礼盒、静物组合、花枝植被、轻场景陈列、柔和抽象背景。
