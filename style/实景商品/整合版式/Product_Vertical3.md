# 版式概述

竖向 3:4 画幅，主标题集中在顶部左侧，以两行自由书写字形成宽阔标题轮廓，长收笔向右延伸。小型外文或翻译位于标题左下，右上可出现用户提供的标签式信息或印章。画面中部是主要主视觉区域，底部左侧放置日期与时段，底部右侧放置一条辅助短句。右上标签和印章属于辅助模块，不应自动生成品牌或会员文案。

# 文字视觉系统

## 主标题

- 位置：画面顶部偏左，横跨约四分之三宽度。
- 区域坐标：[0.06, 0.07, 0.75, 0.38]
- 信息层级：一级核心信息。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-11个中文字符，最多 14个中文字符。
- 字号与画布关系：单行字高约占画布高度的 12%-18%，两行总高约占 31%-38%，标题最宽处约占画布宽度的 72%-75%。
- 字体类型：现代行书、香氛主题手写体、带水彩或干笔质感的自由书写字。
- 字形特征：笔画粗细变化明显，起收笔自然，长横和捺可向右延伸；字形松弛、具有呼吸感，局部可出现小爱心或点状装饰，但不得替代文字结构。
- 排列方式：两行错位，上行略靠左，下行向右展开；末端长笔画可形成下划线或弧线。
- 对齐方式：左对齐为主，内部自由错位。
- 与其他信息的比例：主标题字号约为副标题的 2.4-3.2 倍，为底部信息的 3.4-4.4 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：主标题左下方，使用短外文、翻译或类别名称。
- 区域坐标：[0.09, 0.30, 0.23, 0.08]
- 相对主标题字号：约为主标题字号的 25%-36%。
- 建议行数：优先 2 行，最多 3 行。
- 对齐关系：左对齐，字体可用粗衬线体、窄体或规整无衬线体。
- 缺失规则：删除左下小型信息，主标题下方保持普通留白。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面左下角，以日期和时段形成横向信息块。
- 区域坐标：[0.04, 0.90, 0.29, 0.08]
- 排列方向：左侧大日期，右侧上下两行时段。
- 相对主标题字号：日期约为主标题字号的 30%-40%，时段约为 18%-24%。
- 与主标题的关系：与顶部标题分离，作为左下角锚点。
- 缺失规则：删除左下时间块，主视觉向左下扩展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：底部右侧为一条短句；标题右上可另有用户明确提供的标签式信息。
- 区域坐标：[0.49, 0.90, 0.46, 0.07]
- 建议行数：底部优先 1 行，最多 2 行；右上标签最多 2 行。
- 相对主标题字号：底部约为主标题字号的 18%-25%，右上标签约为 14%-20%。
- 对齐关系：底部右对齐或左对齐均可，整体靠右；右上标签可带描边框，但只承载用户提供内容。
- 缺失规则：删除底部短句和右上标签，不保留空框、印章或会员信息。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：印章、标签框、爱心与长线用于情绪表达，但不自动生成品牌、权益或会员文案。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面中部的大面积连续区域。
- 区域坐标：[0.05, 0.47, 0.90, 0.40]
- 区域形状：从标题下方延伸至底部信息上方的完整纵向区域。
- 建议主体位置：主体视觉中心建议位于 [0.50, 0.66] 附近。
- 建议主体占比：单一人物或香氛产品占画布面积的 28%-44%；情境场景占 36%-53%。
- 与文字的避让关系：不得进入 y=0.44 以上标题区；底部 y=0.87 以下避让时间和短句。
- 可否延伸至文字背后：低对比香雾、纸纹、柔光或花影可跨越全画面；人物面部和产品核心不得进入标题区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：顶部自由书写主标题。
2. 第二视觉：标题左下副标题与右上标签（启用时）。
3. 第三视觉：底部时间和辅助短句。
4. 主视觉主体与文字的观看关系：顶部文字建立情绪，中部主体展开香氛或情感场景，底部信息收束。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时使用一至两行并放大。
- 中等标题：6-11 个字时两行错位，为最优状态。
- 长标题：12-14 个字时使用 3 行，缩小字号并减少长笔画。
- 超出容量时：优先精简，禁止下压到主视觉核心区。

## 信息缺失

- 无副标题时：删除左下小型信息，标题保持原位。
- 无活动时间时：主视觉向左下扩展。
- 无辅助信息时：删除所有标签与底部短句，不自动补文案。
- 只有主标题时：主标题可置于 [0.07, 0.12, 0.78, 0.39]，略放大。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：香氛、美妆、情感活动、生活方式、品牌故事。
- 不适合：科技、运动、复杂促销、严肃信息发布。
- 推荐主题：香味、爱情、记忆、花朵、日常、情绪。
- 推荐信息量：中低信息量，核心模块 3-5 组。
- 推荐主体类型：香水、花朵、人物、礼盒、柔和静物或情绪场景。
