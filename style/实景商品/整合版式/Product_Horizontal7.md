# 版式概述

横向 16:9 画幅，左侧约 45% 区域构成高密度文字系统：上部由小号辅助信息与第一层主标题组合，中部为超大第二层主标题，下部为两行副标题。底部左侧放置一条辅助短句，底部右侧独立放置活动时间，形成稳定的双端收束。右侧约一半画面为连续主视觉区域；中部右侧是最主要的主体生成空间，右下角须避让时间。主标题内部的小号外文或短词只用于建立层级与填补结构间隙，必须来自用户真实输入，不得自动生成。

# 文字视觉系统

## 主标题

- 位置：画面左侧上半部，由上方较小标题单元和下方超大标题单元共同组成。
- 区域坐标：[0.04, 0.07, 0.43, 0.49]
- 信息层级：一级核心信息；下方超大标题单元为第一视觉，上方标题单元为同一主标题的前导部分。
- 建议行数：优先 2 行，最多 3 行。
- 建议字数：6-12 个中文字符，最多 16 个中文字符。
- 字号与画布关系：下方最大字符字高约占画布高度的 19%-28%，整行宽度约占画布宽度的 40%-43%；上方标题字号约为下方的 52%-68%。
- 字体类型：现代无衬线黑体、窄体展示黑体、几何传播型字体。
- 字形特征：竖向笔画挺拔、字面修长、粗细较均匀；大标题字距紧凑，上方标题可适度疏朗。避免书法、复古磨损和高对比衬线。
- 排列方式：上下两层堆叠。上层可由 2-4 个字组成，下层由 3-6 个字组成；两层左边界接近，但允许上层轻微右移。
- 对齐方式：整体左对齐；下层大标题建立主边界，上层围绕其左上部组织。
- 与其他信息的比例：下层主标题字号约为副标题的 2.5-3.4 倍，为底部辅助信息与时间的 4.0-5.5 倍。
- 替换规则：参考该区域的字体样式和排版关系，将内容替换为用户输入的主标题。
- 颜色规则：不继承参考图颜色，由当前设计判断决定。

## 副标题

- 是否支持：支持。
- 位置：超大主标题下方，位于左侧中下部。
- 区域坐标：[0.06, 0.58, 0.38, 0.16]
- 相对主标题字号：约为最大主标题字号的 28%-38%。
- 建议行数：优先 2 行，最多 3 行。
- 对齐关系：整体居中于主标题宽度或轻微左对齐；第一行可更长，第二行回收，形成稳定梯形。
- 缺失规则：无副标题时，主标题可整体下移约 0.03，或保持原位并让主视觉向左下延伸，但不得用口号自动补位。
- 颜色规则：与主标题保持一致，通过字号、字重或明度形成次级层级。

## 活动时间

- 是否支持：支持。
- 位置：画面右下角。
- 区域坐标：[0.84, 0.89, 0.14, 0.07]
- 排列方向：横向单行，适合短日期范围或短时间段。
- 相对主标题字号：约为最大主标题字号的 17%-24%。
- 与主标题的关系：与左侧文字组分离，通过右下角位置平衡左侧高密度文字。
- 缺失规则：无活动时间时，删除右下角信息，主视觉可向右下延展。
- 颜色规则：与主标题保持一致。

## 辅助信息

- 是否支持：支持。
- 位置：可分为两类：一类是嵌入主标题上层周围的短词或翻译；另一类是画面左下角的一条短句。
- 区域坐标：[0.08, 0.15, 0.31, 0.13]；[0.03, 0.89, 0.26, 0.07]
- 建议行数：标题周围的微型信息为 1-3 个短词；底部辅助信息优先 1 行，最多 2 行。
- 相对主标题字号：微型信息约为最大主标题的 14%-20%；底部辅助信息约为最大主标题的 15%-22%。
- 对齐关系：微型信息可围绕上层标题的左右边缘贴附，不与大标题笔画相撞；底部辅助信息严格左对齐。
- 缺失规则：无微型信息时，上层主标题保持完整，不保留空位；无底部辅助信息时，删除左下模块，保留底部留白。若仅提供一项辅助信息，优先放在左下角。

## 装饰信息

- 默认状态：关闭
- 参考图中的装饰文字用途：标题周围的小号外文或短词用于解释、翻译或加强版面节奏，只有在用户明确提供对应内容时才启用。
- 启用条件：仅当用户明确提供装饰文字时启用。
- 禁止规则：不得根据主题自动编写英文、版权、口号、品牌或其他装饰文案。

# 主视觉画面区域

- 主要区域：画面右侧上部至中下部的连续区域。
- 区域坐标：[0.50, 0.05, 0.47, 0.79]
- 区域形状：纵向近矩形，右边缘开放；底部因活动时间形成局部避让。
- 建议主体位置：主体视觉中心建议位于 [0.74, 0.46] 附近。
- 建议主体占比：单人或产品主体占画布面积的 30%-46%；多人或场景占 38%-55%。
- 与文字的避让关系：主体核心不得进入 x=0.49 左侧；右下角 [0.82, 0.86, 0.17, 0.11] 为时间安全区。
- 可否延伸至文字背后：低对比背景渐变、柔和光影或统一纹理可跨越全画面；清晰人物、产品和高对比装饰不得进入左侧文字区。
- 背景规则：空白区域仅表示可生成区域，不代表最终背景必须为白色。
- 禁止事项：不得在文字安全区放置高对比主体、人物面部、产品核心结构或复杂装饰。

# 阅读顺序

1. 第一视觉：左侧中部超大主标题。
2. 第二视觉：上方前导标题与主标题周围的用户提供短信息。
3. 第三视觉：主标题下方副标题、左下辅助信息和右下活动时间。
4. 主视觉主体与文字的观看关系：先由左侧大字建立传播主题，再向右观看主视觉，最后由底部左右信息收束；主体可与左侧标题形成视线或动作呼应，但不得覆盖文字。

# 内容适配规则

## 主标题长度变化

- 短标题：3-5 个字时可将上层标题缩为 1-2 个字，下层放大至 2-4 个字。
- 中等标题：6-12 个字时拆成上下两层，为最优状态。
- 长标题：13-16 个字时拆为 3 行，最大字号缩小 10%-14%，仍保持下层最突出。
- 超出容量时：优先精简；禁止将大标题侵入 x=0.49 以右的主视觉区，不得压缩字宽。

## 信息缺失

- 无副标题时：删除中下部副标题，主视觉可向左下轻微延伸，主标题保持核心位置。
- 无活动时间时：删除右下时间，主视觉扩大至画面底部。
- 无辅助信息时：删除主标题周围微型信息和左下短句，主标题不需要重新填满空隙。
- 只有主标题时：主标题可置于 [0.04, 0.17, 0.44, 0.48]，上下两层放大 5%-10%，底部保留大面积留白。
- 禁止使用无关文字补齐空位。

# 适用条件

- 适合：品牌传播、公益议题、内容平台活动、直播主题、青年文化、公共事件。
- 不适合：复杂流程、长篇说明、价格密集促销、传统复古主题。
- 推荐主题：表达、观看、传播、连接、城市文化、社会议题、内容创作。
- 推荐信息量：中等信息量，核心模块 3-5 组。
- 推荐主体类型：人物肖像、多人群像、镜头或屏幕相关产品、城市景观、传播装置。
