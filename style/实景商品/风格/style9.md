# 参考图 09｜清凉家电的冰霜促销 KV

- **对应原图**：`style9(2).png`
- **预设定位**：季节促销 / 家电品类聚合 / 冷暖对撞 3D KV

## 这张图具体能解决什么问题

这张图解决的是“多个外形普通、颜色接近的清凉家电，如何在大型促销海报中被统一成一个有强季节感和价格冲击的品类场景”的问题。

画面通过冰块、结霜、冷气、水面和温度计等视觉符号，把空调、冰箱、风扇和颈部风扇统一到“降温”这一核心卖点。上方暖色热浪与下方冷色冰区构成强烈冷暖反差，使降温效果在视觉上被直接感知。左侧标题和折扣信息体量巨大，右侧商品生态形成稳定品类阵列。

## 媒介

- 写实 3D 商品渲染、冰雪特效合成。
- 可结合 Houdini 冰块、水体和霜冻效果。
- 适合横版会场头图、开屏、频道焦点图和大型促销 KV。

## 造型语言

- 左文右图的明确商业分栏。
- 商品以中央空调为主，冰箱、风扇和其他设备围绕排列。
- 大型冰块、水面和冷气形成基座，统一不同产品。
- 平台 IP 位于主商品上方，强化活动识别与情绪。
- 前景颈部风扇和冰块采用较大尺度，增加近景冲击。
- 温度计作为边缘信息图形，补充功能语义。

## 色彩逻辑

- 上方暖黄、橙色模拟高温环境。
- 中下部以蓝、青、白构成清凉核心区域。
- 冷暖之间通过浅绿或高亮过渡，避免生硬切割。
- 标题使用高对比蓝白结构，折扣数字使用暖色强调。
- 平台 IP 的品牌色成为场景中的第二视觉焦点。

## 材质

- 家电：白色或银色塑料、金属、玻璃面板。
- 冰块：高透明度、内部气泡、折射和湿润表面。
- 霜冻：附着于商品边缘和缝隙，但不能遮挡结构。
- 水面：高光反射与轻微波纹。
- IP：软胶或毛绒霜冻质感，与硬质家电形成对比。
- 重点是“硬质家电—透明冰—湿润水体”的材质层次。

## 光影

- 高亮商业棚光与冷色环境光结合。
- 商品正面保持清晰白色，不被蓝光染成灰蓝。
- 冰块和水面需要强高光、透射和反射。
- 上方暖光只用于环境对比，不能污染商品主体。
- 轮廓光沿商品外缘和冰霜边缘出现，强化清凉质感。
- 阴影需统一落在冰面或水体基座上。

## 空间复杂度

- **高复杂度**。
- 包含多商品、IP、冰雪、水体、温度计和大体量文字。
- 通过左文右图、主商品居中和统一冰面基座维持秩序。
- 适合大屏和横版，不适合缩小后仍需阅读大量规则的场景。

## 情绪

- 冰爽、刺激、降温、促销、即时、强利益感。
- 强烈季节节点气质。
- 同时表达高温压力与低温解决方案。

## 适用主题

- 空调、冰箱、风扇、制冰机、冷饮机、冷感穿戴。
- 夏日清凉节、家电品类日、降温季、618 或暑期促销。
- 需要突出折扣、温度、制冷、送风等功能的活动。
- 多品类家电联合促销。

## 禁用场景

- 不适合秋冬、温暖、烘焙、母婴柔护等主题。
- 不适合高端极简新品发布，促销感过强。
- 不应给所有商品覆盖厚重冰层，导致产品结构不可识别。
- 不应让暖色区域占据商品主体，削弱清凉卖点。
- 不应无节制堆叠冰块、水花和雪花，避免廉价特效感。

## 可共享的视觉规则

1. 用一个可感知的环境状态统一多品类商品。
2. 冷暖上下对撞可直接表达问题与解决方案。
3. 主商品需比其他设备更大、更亮、更居中。
4. 特效附着要服从商品结构，不能遮挡关键部位。
5. 促销文字与商品分栏，保证高密度信息仍然清晰。
