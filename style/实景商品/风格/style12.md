# 参考图 12｜手机产品的运动装备框景

- **对应原图**：`style12(2).png`
- **预设定位**：手机新品 / 运动生活方式 / 产品与装备混合框景

## 这张图具体能解决什么问题

这张图解决的是“手机背面外观和配色如何在生活方式场景中被完整展示，同时保持品牌发布海报的干净和高级”的问题。

画面将手机放在网球拍、运动包、毛绒球和眼镜等装备之间。运动包拉链和球拍弧线形成天然前景框架，手机以倾斜角度从中间突出，完整露出背部、镜头模组和颜色。上方与下方使用大面积白色品牌信息区，中间场景像一张编辑摄影作品嵌入版式，兼顾产品展示和发布感。

## 媒介

- 高质量产品摄影、棚拍搭景或写实 3D 合成。
- 推荐真实手机与运动道具拍摄，后期进行颜色和结构优化。
- 适合竖版新品海报、配色发布、品牌社交媒体和门店物料。

## 造型语言

- 中间大图 + 上下白边的编辑式版面。
- 手机以斜向竖立姿态成为中心主体。
- 球拍弧线、包口和拉链共同形成框景。
- 前景运动包遮挡手机底部，增加真实嵌入感。
- 上方边缘道具被裁切，形成画外延伸。
- 下方标题区与图片严格分离，保持高级秩序。

## 色彩逻辑

- 手机使用清爽浅色作为核心。
- 橙色运动球和配件形成强暖色对比。
- 蓝色球拍边缘、拉链和布料与手机色呼应。
- 大面积白色背景和版心留白稳定整体。
- 色彩明快但不高密度，强调新品配色的清洁感。

## 材质

- 手机：细腻磨砂玻璃或金属，镜头模组高光清晰。
- 球拍：喷漆金属 / 复合材料与紧绷网线。
- 运动包：尼龙、绗缝布、拉链和织带。
- 网球或毛绒球：粗糙纤维表面。
- 眼镜：高反射塑料或金属镜框。
- 材质重点是“精密光滑手机—粗糙柔软运动装备”。

## 光影

- 高位柔光与侧上方定向光结合。
- 手机背面需保持平整明亮，镜头模组通过高光明确结构。
- 运动包内部略暗，形成前景框景和深度。
- 橙色球体通过侧光展示绒毛，不应过曝。
- 整体阴影柔和、干净，符合新品广告的精致感。

## 空间复杂度

- **中等复杂度**。
- 图片区域内部有明显前中后层次。
- 版式整体因大面积白边而保持低噪声。
- 场景元素数量适中，全部围绕运动与出行语义。

## 情绪

- 清爽、运动、年轻、轻快、时尚、夏日。
- 有生活方式编辑摄影的真实感。
- 同时保持品牌新品发布的克制和高级。

## 适用主题

- 手机、运动耳机、智能手表、相机和潮流数码。
- 夏日运动、网球、校园、户外、轻旅行。
- 新配色发布、轻薄机身、运动抓拍、年轻用户沟通。
- 需要完整展示商品背面设计和镜头模组的海报。

## 禁用场景

- 不适合强调正面屏幕、系统界面或影像样张的核心诉求。
- 不适合大型促销、价格信息和复杂活动规则。
- 不适合与运动无关的严肃商务、医疗或家居主题。
- 不应让球拍网线或包口遮挡镜头模组和品牌标识。
- 不应使用过多装备造成户外用品广告感，削弱手机主体。

## 可共享的视觉规则

1. 利用运动器材的弧线和包口建立天然框景。
2. 手机以倾斜竖立姿态展示完整背面结构。
3. 场景摄影嵌入大面积白边，兼顾生活感和品牌感。
4. 通过冷色商品与暖色运动道具形成清晰主体分离。
5. 前景允许局部遮挡，但核心卖点区域必须完整可见。
