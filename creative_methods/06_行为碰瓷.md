# 行为“碰瓷”

## 图中正文

> 最后可以用物体本身的某个部分进行行为上的碰瓷，对这个部分进行新的联想，去赋予这个部分一个新的行为动机，比如这里我将水果的叶子的变成可以飞行的翅膀。

## 方法定义

从物体的某个部件出发，根据它的形态、位置或运动潜力，赋予其新的行为动机，使静态部件承担另一种动作功能。

## 适用条件

- 物体具有可被重新解释的突出部件。
- 需要通过动作增强角色感、生命感或故事性。
- 部件的新行为能够与原形态建立直观联想。

## 输入要求

- 主体物体及其关键部件。
- 部件原始功能与潜在动作。
- 目标行为：飞行、行走、拥抱、观察、发声、开合等。
- 行为动机与结果。

## 转化步骤

- 1. 选出主体上最有动作潜力的部件。
- 2. 列出该部件在形态上像什么。
- 3. 为其匹配一种新的行为和动机。
- 4. 调整部件姿态、数量或尺度，使动作可读。
- 5. 用运动轨迹、表情或场景反馈说明行为结果。

## 输出结构

- 主体 + 部件 + 新行为 + 行为动机 + 动作结果。
- 示例公式：水果叶片 + 翅膀联想 + 飞行动机 = 会飞的水果角色。

## 视觉记忆点

普通部件突然“活起来”；叶子变翅膀、把手变手臂、拉链变嘴等动作化转换最容易形成记忆。

## 适合的风格与比例

适合角色 IP、动画、黏土、软胶 3D、卡通插画、动态图形。3:4、9:16 适合表现完整动作；1:1 适合单一行为定格。

## 可以组合的方法

- 直接“碰”
- 形态“碰瓷”
- 感受异化
- 图形对画面的性格表达

## 优势

- 能以较小改造获得明显的角色化效果。
- 天然具备动作、动机和故事线。
- 适合视频分镜和系列 IP 延展。

## 风险

- 行为与部件形态缺少关联时会显得牵强。
- 动作过多会削弱主体原有识别度。
- 只增加表情而没有行为结果，故事性不足。

## 禁用条件

- 主体必须保持严格产品结构或品牌标准。
- 部件改造可能造成危险使用暗示。
- 严肃纪实、技术说明或真实操作演示。
