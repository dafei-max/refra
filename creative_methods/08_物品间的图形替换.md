# 物品间的图形替换

## 图中正文

> 其次，我们还可以把物品的图形进行相互的替换（相互替换的物品间会有些功能外形上的相似逻辑）来进行一些有趣的表达，比如这里我直接把水果变成饮料盒的外形，并加上了小动物给画面再加上一点故事性。

## 方法定义

在两个物品之间替换整体轮廓或关键部件，使一个物品保留原有身份与语义，同时获得另一个物品的外形、包装或结构。

## 适用条件

- 两个物品在功能、使用方式或轮廓上存在相似逻辑。
- 希望保留双重识别，而不是完全融合成新物种。
- 画面需要通过替换建立幽默、故事或产品联想。

## 输入要求

- 被替换对象与提供图形的对象。
- 需要保留的识别特征。
- 被替换的范围：整体轮廓、局部部件、开口、表面图案。
- 辅助角色或故事情境。

## 转化步骤

- 1. 确定两个对象之间的共同功能或结构。
- 2. 选择需要保留和需要替换的特征。
- 3. 先完成轮廓替换，再补足材质、比例和连接关系。
- 4. 保留至少一个原对象的强识别点。
- 5. 用角色、动作或使用场景解释替换后的用途。

## 输出结构

- 对象 A + 对象 B 的图形 + 保留特征 + 替换范围 + 使用故事。
- 示例公式：水果内容属性 + 饮料盒外形 + 吸管与叶片 = 水果饮料箱角色。

## 视觉记忆点

物品“穿上”另一个物品的轮廓；熟悉的内容与陌生外形形成可爱、荒诞或功能性的反差。

## 适合的风格与比例

适合包装概念、黏土、毛绒、3D IP、贴纸、插画。1:1 适合单品，3:4 适合角色与故事，横版适合系列陈列。

## 可以组合的方法

- 直接“碰”
- 形态“碰瓷”
- 用图形造个表达空间
- 行为“碰瓷”

## 优势

- 替换逻辑清晰，容易保持主体识别。
- 适合产品概念、包装创意和 IP 延展。
- 可通过统一规则快速生成系列。

## 风险

- 替换范围过大可能导致原物体身份消失。
- 功能与外形没有相似逻辑时会显得随意。
- 附加角色和装饰过多会冲淡替换关系。

## 禁用条件

- 包装或产品外形涉及法律、商标或安全规范。
- 需要准确呈现实物规格、结构和使用方式。
- 替换后可能造成食品、药品或功能认知误导。
